Tabela ASCII

Drukowalne znaki ASCII 33–126 wraz z kodami dziesiętnym, szesnastkowym, binarnym i ósemkowym. Kliknij dowolny znak, aby go natychmiast skopiować.

Tabela ASCII przypisuje 128 znaków American Standard Code for Information Interchange liczbom 0–127 — to podstawa nowoczesnego kodowania tekstu i pierwsze 128 punktów kodowych Unicode. To zestawienie obejmuje zakres drukowalny (33–126) pogrupowany według typu, a każdy znak opisano kodem dziesiętnym, szesnastkowym, binarnym i ósemkowym. Kody 0–31 to niedrukowalne znaki sterujące (jak 10, czyli wysuw wiersza), a 32 to spacja. Chcesz przekonwertować całe słowo lub wiadomość zamiast szukać pojedynczych znaków? Skorzystaj z interaktywnego konwertera ASCII, aby natychmiast zamienić tekst na kody dziesiętne, szesnastkowe, binarne lub ósemkowe (i z powrotem).

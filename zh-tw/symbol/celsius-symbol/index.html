攝氏度符號（℃）

℃ 和 °C 差在哪、怎麼打出來——點一下就複製。

攝氏溫度有兩種寫法：單一字元的 ℃（U+2103，DEGREE CELSIUS）和「度數符號＋大寫 C」組成的 °C。國際標準（SI）建議使用後者 °C，因為它在任何字型裡都能正確顯示，也比較好排版；℃ 是為了 CJK 直排和舊有編碼相容而保留的相容字元。實務建議：內文寫 °C，需要節省寬度的表格或直排再用 ℃。輸入方式：° 在 Windows 是 Alt+0176，Mac 是 Option+Shift+8。

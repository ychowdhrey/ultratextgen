Discord 文字格式，一次解密

你遇到的不是「字體」問題——是「三套系統」問題。Discord 用 Markdown、Unicode 字元、Nitro 樣式做完全不同的事。只要搞懂哪個欄位用哪一套，每個「為什麼這樣沒用？」都會自己有答案。

平台實戰 ⏱ 8 分鐘閱讀 三套系統模型

重點整理

  • Discord 有三套互不相干的文字系統：Markdown（訊息）、Unicode「字體」（到處的名字）、Nitro（付費的顯示名稱樣式）。
  • 像 **粗體** 這種 Markdown 只在訊息裡才會呈現——在使用者名稱、暱稱，或伺服器／頻道名稱裡都沒用。
  • Unicode「字體」在每個名字欄位都能用，但在某些裝置上可能顯示成方框，也會讓螢幕閱讀器出錯。
  • Nitro 會幫你的顯示名稱加上真正的顏色和特效——但在伺服器裡，你的身分組顏色會蓋過去，只剩字體看得到。
重新框架

這不是字體問題——是三套不同的系統

幾乎每個 Discord「為什麼我的文字沒用」的問題，都來自把三件本來毫無關係的事混在一起。Discord 在聊天裡教你 Markdown，於是你以為同一招也能拿來裝飾名字。它不行——名字跑的是完全不同的系統。

這裡用一張圖把整片地盤講清楚。搞懂每個欄位用哪一套系統，你就再也不會被搞得措手不及。

系統一

Markdown——給訊息用

Markdown 是 Discord 在顯示你的訊息時套上的格式。你在文字前後打上符號，Discord 就把它們換成真正的樣式。

  • **粗體** → 粗體
  • *斜體* → 斜體
  • ~~刪除線~~ → 刪除線
  • __底線__ → 底線
  • ||防雷|| → 點下去才看得到
  • > 引用 和 `程式碼`

這是格式化訊息的正確方式——它依然是真正的文字，所以能被搜尋、也對無障礙友善。陷阱是兩個會讓它「失效」的錯誤：

不會變粗體

** 文字 **——星號裡面有空格就會取消效果。要用 **文字**。

不會變粗體

在 `程式碼區塊` 裡，反引號會關掉 Markdown。把樣式移到區塊外面。

還有最大的一點：Markdown 在使用者名稱、暱稱、伺服器名稱或頻道名稱裡完全沒作用。那些不是訊息，所以 Discord 從不會對它們跑 Markdown。

系統二

Unicode「字體」——給名字用

要裝飾一個名字，你沒辦法叫 Discord 去呈現任何東西——所以你改用本身就長得像有樣式的字元。產生器把「Nova」變成 𝗡𝗼𝘃𝗮 或 𝓝𝓸𝓿𝓪，用的是特殊的 Unicode 字元，你再把做好的結果直接貼進欄位。不需要任何呈現，所以它能撐在 Markdown 撐不住的地方。

這在你的顯示名稱、伺服器暱稱、伺服器和頻道名稱、身分組名稱、個人簡介和訊息裡都能用。只有一個地方擋它：

@使用者名稱會拒絕它。你那個獨一無二的帳號代號（@ 後面那個小寫的）只允許 a–z、0–9、_ 和 .——為了提及、搜尋和路由。把花式字體貼進那裡，Discord 會拒絕存檔。改去裝飾你的顯示名稱吧。

兩個要誠實說的但書：Unicode 名字在某些裝置上（尤其是舊 Android）可能顯示成方框，而且對螢幕閱讀器不友善。挑一個安全的風格（粗體、斜體、小型大寫），保持有品味——許多大型伺服器會嚴格管理難讀或 Zalgo 名字。

系統三

Nitro 顯示名稱樣式——付費，而且比你想的更侷限

Discord 的付費方案 Nitro 提供「顯示名稱樣式」，這是 2025 年底新增的功能：把真正的字體、顏色，甚至動畫特效套到你的顯示名稱上。它在你的個人資料卡上看起來很棒。但有個很多人踩雷才發現的陷阱：

在伺服器裡，你的身分組顏色會蓋過 Nitro 顏色，特效也會被拿掉——所以其他成員通常只看到字體，看不到顏色或動畫。完整效果主要出現在你的個人資料上，而不是成員名單或聊天裡。

免費帳號可以打開選單預覽樣式，但要儲存就得有 Nitro——正是這種「先預覽再付費牆」，讓現在這麼多人問是不是一定要 Nitro 才能用字體。針對這個功能，這是合理的疑問；但它並不代表 Unicode 樣式有任何改變，Unicode 不管怎樣都是免費的。

所以，如果你想要一張精緻的個人資料卡，還有一個到處都不同的顯示字體，Nitro 值得。但它不是把彩色文字放進對話的方法——那是另一個工具（下一節）。

顏色問題

那訊息裡的彩色文字呢？

訊息裡的彩色文字是第四種、更窄的招式：ANSI 程式碼區塊。你把文字包在標了 ansi 的三重反引號區塊裡，再加上顏色的跳脫碼。要清楚它的限制：

  • 只有八種固定顏色——不能自訂十六進位色碼。
  • 只限程式碼區塊——沒辦法幫一句普通句子行內上色。
  • 手機上不可靠——對用手機的人常常顯示成純文字。

對以電腦為主的伺服器貼警告或紀錄還算好用；但不是通用的樣式工具。如果你有一半成員用手機，就當作他們看不到顏色。

因為它們用的是不同系統。在聊天裡，**粗體** 是 Markdown——Discord 在顯示你的訊息時會把它呈現出來。名字（使用者名稱、暱稱、伺服器、頻道、身分組）不跑 Markdown，所以星號只會照字面顯示。要裝飾名字，你需要 Unicode「字體」——本身就長得像粗體的特殊字元——直接貼進欄位裡。

不是。Unicode「字體」是免費的替代字元，你可以貼在任何允許名字的地方；它對所有人都有效，但在某些裝置上可能顯示成方框，也會讓螢幕閱讀器出錯。Nitro 顯示名稱樣式是付費功能，會把真正的字體、顏色和特效套到你的顯示名稱上——但顏色和特效在伺服器裡不會顯示，那裡是你的身分組顏色勝出；只有字體會延續過去。

用 ANSI 程式碼區塊：把你的文字包在標了「ansi」的三重反引號區塊裡，再加上顏色的跳脫碼。它只有八種固定顏色、只在程式碼區塊裡有效，而且在手機上不可靠（常常顯示成純文字）。它是給訊息用的，不是給名字用的。

兩個常見原因：星號和文字之間有空格（** 文字 ** 不會變粗體——**文字** 才會），或者文字在程式碼區塊裡（反引號會關掉 Markdown）。另外也要記得，Markdown 只在訊息裡有效，名字裡永遠沒用。

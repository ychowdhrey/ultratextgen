空白符號與隱形字元

Unicode 內建的所有空白與隱形字元——零寬空格、全形空格、點字空白、諺文填充字元，一次收藏。點一下任何符號就能立刻複製貼上。

空白符號（也叫隱形字元）是真正存在的 Unicode 文字，只是顯示出來完全看不到——是一格可以複製貼上的空白，用在那些不接受真正空欄位的地方。大家常拿來在 Discord 做隱形暱稱、幫 IG 簡介或貼文加一行看不見的空行、傳一則看起來空白的 LINE 或 WhatsApp 訊息，或是讓遊戲 ID 的間距更整齊。下面每個按鈕都是一個真正的空白或隱形字元：方塊看起來是空的，但標籤會清楚告訴你複製到的是哪一個。

想知道為什麼點字空白（U+2800）是最多人拿來做「空白名字」的首選字元？可以參考英文版的隱形字元詳細介紹。

常見問題

空白符號常見問題

什麼是空白符號／隱形字元？

空白符號（也叫隱形字元）是真正存在的 Unicode 文字，只是顯示出來完全看不到——可以複製貼到那些不接受真正空白欄位的地方。常見用法包括：把 Discord 暱稱變成看起來空白、在 IG 簡介或貼文加一行看不見的空行、傳一則看起來空白的 LINE 或 WhatsApp 訊息，或是幫遊戲 ID 留出乾淨的間距。這頁每個按鈕都是一個真正的空白或隱形字元，方塊看起來是空的，但標籤會清楚告訴你複製到的是哪一個。

空白符號要怎麼複製使用？

點一下想要的符號按鈕就會自動複製到剪貼簿，接著貼到暱稱、簡介、訊息欄位都可以。全部都是標準 Unicode 字元，不是圖片，貼到任何看得懂文字的地方都不會跑掉或變成方框。

遊戲暱稱要怎麼留空白、做隱形名字？

點選上面「填充與空白圖形字元」區的點字空白（U+2800）或諺文填充字元（U+3164），複製後貼到傳說對決、Free Fire、Mobile Legends 的改名欄。哪一個能用要看遊戲和版本：諺文填充字元（U+3164）在傳說對決和 PUBG 仍可使用，但玩家回報 Free Fire 自 OB43 版本起已不再接受，因此 Free Fire 請先試點字空白（U+2800）。如果遊戲要求名字不能重複，貼 2～3 次讓名字獨一無二，看起來仍然是空白的。

為什麼一般空白鍵會被拒絕，或顯示成方框？

大部分平台會自動裁掉欄位前後的空白，欄位變空之後就會顯示「必填」錯誤，所以按空白鍵通常沒有用。有些隱形字元則是手機或平台的字型沒有收錄，會顯示成方框 ▯ 或問號，這時候換一個字元試試——例如從零寬空格換成點字空白——通常就能解決。

Discord、IG、LINE 都能用這些空白符號嗎？

可以，Discord 的暱稱和伺服器名稱、IG 的顯示名稱和個人簡介、LINE 的狀態消息都接受這些字元貼上。但要注意：IG 開頭是 @ 的帳號 ID 只接受英文小寫字母、數字、句點和底線，空白或隱形字元在那裡會被拒絕，記得貼在顯示名稱或簡介，不要貼在帳號 ID。

免費嗎？需要註冊或下載 App 嗎？

完全免費，不用註冊也不用下載 App，所有複製都在瀏覽器裡完成，貼的內容不會被傳到伺服器。

遊戲名稱可以放幾個空白字元？

空白字元和看得見的字一樣，都會計入名稱的字數上限。Free Fire 可用 12 個字元、PUBG Mobile 14 個、Mobile Legends 與 Valorant 16 個、Roblox 20 個，所以完全空白的名稱會用掉全部額度，而放在字詞之間的空白也會縮短看得見的部分。由於改名通常需要鑽石或改名卡，建議先把字元貼到聊天框，確認在那裡真的顯示為空白，再花費改名。

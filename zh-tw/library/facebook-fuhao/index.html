常見問題

Facebook 符號常見問題

如何在 Facebook 貼文、留言或個人簡介加入符號？

點一下這頁的任何符號即可複製，接著貼到 Facebook 貼文、留言、「關於」/個人簡介欄位、粉絲專頁描述或 Messenger 訊息。Facebook 幾乎所有地方都能顯示標準 Unicode 文字，只有個人檔案的「姓名」欄位例外，該欄位有更嚴格的規則。

為什麼 Facebook 會拒絕我在個人檔案姓名裡使用符號？

Facebook 個人檔案的「姓名」欄位會依真實姓名政策審查，並移除大多數裝飾性 Unicode 字元，所以直接放在姓氏或名字裡的星星、愛心、括號通常會被拒絕或悄悄移除。粉絲專頁名稱、社團名稱以及企業粉絲專頁的使用者名稱則有更多裝飾空間——這正是上方「粉絲專頁與社團名稱符號」區塊的用途。

可以把 Facebook 的「讚」「大心」「哈」反應貼成文字嗎？

反應本身是 Facebook 專屬的動態貼圖，沒辦法直接打出來，但最接近的標準表情符號——👍 代表讚、❤️ 代表大心、😆 代表哈——可以完美貼進留言和貼文當作文字替代，這也是大多數人講「Facebook 反應表情符號」時真正想要的東西。

為什麼有些 Facebook 符號會顯示成空白方框？

空白方框代表瀏覽者的裝置或瀏覽器沒有那個字元的字型。廣泛支援的符號——愛心、星星、勾號和常見表情符號——幾乎到處都能顯示；比較罕見的 Unicode 字元則不一定。把顯示異常的符號換成這頁裡更常見的替代符號就好。

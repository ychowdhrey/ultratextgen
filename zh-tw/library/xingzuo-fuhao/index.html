星座符號常見問題

十二星座符號要怎麼複製使用？

點一下想要的符號按鈕就會自動複製，接著貼到 IG 簡介、Discord 暱稱、LINE 狀態、遊戲 ID 都可以。這些是標準 Unicode 字元，不是圖片，所以貼到任何看得懂文字的地方都不會跑掉。

十二星座符號跟十二生肖符號一樣嗎？

不一樣。十二星座（牡羊座到雙魚座）是西洋占星的太陽星座系統，依出生月份決定；十二生肖（鼠到豬）是中華文化的十二年循環，依出生年份決定。兩者都很常拿來裝飾暱稱和簡介，這頁把兩種都收錄了。

免費嗎？需要註冊嗎？

完全免費，不用註冊。星座符號都是標準 Unicode 字元，沒有版權問題，想複製幾次都可以。

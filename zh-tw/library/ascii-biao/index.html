ASCII 表

可列印的 ASCII 字元 33–126，附上十進位、十六進位、二進位與八進位代碼。點擊任一字元即可立即複製。

ASCII 表將 American Standard Code for Information Interchange 的 128 個字元對應到數字 0–127 — 這是現代文字編碼的基礎，也是 Unicode 的前 128 個碼位。本對照表收錄可列印範圍（33–126）並依類型分組，每個字元都標示十進位、十六進位、二進位與八進位代碼。代碼 0–31 是不可列印的控制字元（例如 10 是換行），32 則是空白。想轉換整個單字或訊息，而不是逐字查詢？使用互動式的 ASCII 轉換器，可將文字即時轉換為十進位、十六進位、二進位或八進位代碼（亦可反向）。

常見問題

國旗 Emoji 常見問題

為什麼看到的是「TW」而不是旗子？

國旗 emoji 是兩個地區指示字母組成的，這裡是 T 和 W。系統若沒有對應的圖，就直接顯示這兩個字母。這是規格上的預期行為，不是錯誤。

為什麼 Windows 上看不到國旗？

Windows 沒有內建國旗圖片，只會把字母組合顯示出來。字元本身沒問題，換到手機上就會顯示成旗子。

為什麼英格蘭、蘇格蘭的作法不一樣？

它們是次級地區的旗幟，用標籤序列而不是兩個字母組成，加入時間較晚，支援的系統也比較少。

暱稱可以放國旗嗎？

顯示名稱大多可以。不過有些平台基於審核考量會單獨移除國旗，處理方式跟其他 emoji 不同。

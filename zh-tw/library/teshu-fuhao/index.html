特殊符號

獨特 Unicode 符號的參考收藏——無限、和平、科學、法律標記、美感獨立符號與罕見珍稀符號。點一下符號就能立刻複製。

瀏覽並複製依意義分類的獨特特殊符號——從無限與永恆符號，到和平符號、科學記號、法律標記、美感裝飾符號，還有罕見的 Unicode 珍稀符號。

「特殊符號」指的是所有不屬於一般字母或數字的符號——像是 ∞、©、™、†、★ 和 ° 這些。它們跟一般文字一樣屬於 Unicode 標準的一部分，所以你可以直接在這裡複製，貼到文件、社群貼文、程式碼、使用者名稱和表單欄位裡，完全不需要特殊鍵盤、ALT 代碼或字元對照軟體。下面每一個符號都只要點一下就能複製。

用分類快速找到你需要的符號，或直接掃過整頁，找出那個你永遠記不住怎麼打的字形。每個字元都是純 Unicode 字元，所以貼到 Google 文件、Word、Notion、Gmail、Instagram 或聊天視窗都不會變。

想知道某個符號的完整故事——它的歷史、alt 代碼，以及哪裡適合使用？下面有四個符號各有專屬頁面（英文版）：at 符號（@）、連字號（&）、章節符號（§）、段落符號（¶）。

使用方式

如何在任何地方輸入特殊符號

要輸入特殊符號有好幾種方法——不過複製貼上是最快、在各種裝置上也最可靠的方式：

  • 複製貼上（最簡單）：點一下這頁上的任何符號就會複製，再貼上（Ctrl/Cmd + V）到你需要的地方，不用背任何代碼。
  • Windows ALT 代碼：按住 Alt，用數字鍵盤輸入數字（例如 Alt + 0169 可以打出 ©）。這個方法只在有實體數字鍵盤的鍵盤上才能用。
  • Mac 字元檢視器：按 Ctrl + Cmd + Space 打開表情符號與符號選擇器。
  • Unicode 輸入：在 Windows 上，部分應用程式可以先輸入十六進位代碼、再按 Alt + X（例如輸入 221E 再按 Alt + X 就會變成 ∞）。

因為這些符號都是 Unicode 標準字元，在 iPhone、Android、Windows 和 Mac 上都能穩定顯示。少數比較罕見的數學和裝飾符號，在較舊的系統上可能會顯示成缺字方框；如果發生這種情況，換成同類別中比較常見的符號就能解決。

常見問題

特殊符號常見問題

什麼是特殊符號？

特殊符號指的是基本英文字母（A–Z、a–z）和數字（0–9）以外的所有符號。包括 & 和 @ 這類標點符號、€ 和 £ 這類貨幣符號、∞ 和 ± 這類數學符號，還有 ★ 和 ✧ 這類裝飾符號。這些全部都屬於 Unicode 的一部分。

沒有 ALT 代碼要怎麼複製特殊符號？

只要點一下這頁上想要的符號，就會立刻複製到剪貼簿，接著用 Ctrl + V（Windows）或 Cmd + V（Mac）貼上即可，完全不用背任何數字代碼。

為什麼特殊符號會顯示成方框或問號？

這通常是因為該應用程式或裝置的字型沒有包含這個符號的字形，是顯示上的問題，不是複製錯誤——符號本身其實是正確的。換成同類別中比較常見的符號通常就能解決。

特殊符號可以安全用在密碼和使用者名稱嗎？

一般標點符號（! @ # $ % & *）能提升密碼強度，而且被廣泛接受。不過比較少見的 Unicode 符號常常會被使用者名稱和密碼欄位拒絕，建議這類欄位用常見的 ASCII 標點就好，裝飾性符號留給貼文和個人簡介使用。

為什麼我看到的是 [OBJ] 而不是表情符號或符號？

[OBJ] 是某些 Android 應用程式和舊版通訊軟體，在無法顯示某個表情符號或 Unicode 字元時出現的佔位符號，意思是「物件替代」。符號本身其實已經正確複製和傳送，只是接收端的應用程式還沒有對應的字形。這其實就是文字版的缺字方框，通常等應用程式或系統更新字型和表情符號集之後就會恢復正常。

哪些符號是鍵盤上沒有的？

除了字母、數字和鍵盤上印出來的標點以外的符號，像是愛心（♥ ♡）、星星（★ ☆）、勾勾（✓ ✔）、箭頭（→ ←）、無限（∞）、度數（°）和大部分貨幣符號都是。這些符號都存在於 Unicode 裡，只是沒有對應的按鍵，所以複製貼上是最快的使用方式。

要怎麼取得不是表情符號的愛心符號？

點一下上面的 ♥ 或 ♡ 就可以了。跟手機鍵盤上的表情符號不同，這些是文字符號——會跟著周圍文字的顏色和大小變化，而且在拒絕表情符號的使用者名稱欄位和表單裡也能正常使用。

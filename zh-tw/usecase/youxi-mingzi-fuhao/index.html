遊戲名字、遊戲ID、暱稱怎麼取？

不只是傳說對決——不管是哪一款遊戲的遊戲名字、遊戲ID，或單純想換一個更好記的暱稱，取名時抓住幾個原則就好上手：

1. 短、好記優先。大多數遊戲的暱稱欄位都有字數上限（8～16 字元不等），先想好一個喜歡的英文詞當核心，再加 1～2 個符號收尾，比硬塞一長串花樣好記也好唸。
2. 帶點主題性。用喜歡的星座、顏色、興趣、寵物名當靈感，比隨機亂打更容易記住，朋友也比較好認。想要主題化，可以直接借用現成符號組合，例如 十二星座符號大全 裡的 ♈♉♊ 這類星座符號。
3. 男生向、女生向可以從調性下手。男生向偏皇冠、暗黑、俐落線條的詞（像上面的 ᴛɪᴛᴀɴ、ꜱʜᴀᴅᴏᴡ）；女生向偏花朵、星星、糖果色詞彙（像 𝓟𝓮𝓪𝓬𝓱、𝓝𝓪𝓷𝓪）——上面「男生向暱稱」「女生向暱稱」的現成範例都可以直接借用。
4. 先查清楚那款遊戲的規則。每款遊戲的字數上限、能不能留空白都不一樣，貼上前先看這頁上方的字數檢查，照你選的遊戲即時計算，比貼上去才發現被拒絕省事得多。

如果暱稱不只是想用在遊戲裡，而是喜歡到想把它做成更有個人風格的視覺呈現，也可以試試 刺青字體產生器，免費預覽同一個名字做成刺青風格文字會長什麼樣子。

傳說對決暱稱怎麼改

改名步驟很單純：

1. 從上面的產生器或現成暱稱裡複製想要的暱稱。
2. 打開傳說對決，點頭像進入個人資料頁面。
3. 找到暱稱旁邊的改名功能——實際入口依版本可能不同，找不到時可以先在遊戲內搜尋「改名」或「暱稱」。
4. 貼上剛剛複製的暱稱，用改名卡確認。改名卡通常在遊戲商城用遊戲代幣購買，或透過活動、任務、簽到免費取得，確切花費和取得方式會隨版本調整，這裡不寫死一個數字，遇到活動時以遊戲內顯示為準。

暱稱上限是 12 個字元，符號跟一般字母一樣算 1 個字元（不像某些遊戲把符號算成 2 個）。要注意的是一般空白鍵通常無法輸入，想要名字中間留白，可以改用隱形字元代替——這頁上方的字數檢查會照遊戲規則即時計算，貼上前先確認過不會超過長度。

如果暱稱裡有個字顯示成方框 ▯，通常是手機或遊戲的字型沒有收錄那個少見的字元。換成 Bold（粗體）或 Small Caps（小型大寫）這類支援度高的字體，符號則挑常見的（꧁ ꧂ ༒ メ 彡 ★ ™），在傳說對決、Discord、PUBG Mobile 幾乎都能正常顯示。

Discord、Instagram 也能用

同一套 Unicode 字體不只限遊戲：可以貼到 Discord 的暱稱和伺服器名稱、Instagram 的顯示名稱和個人簡介、留言和貼文說明。因為是真正的文字，複製貼上不會跑掉，對方不用裝任何 App 也能看到一樣的樣子。

有一點要注意：開頭是 @ 的帳號 ID 欄位不一樣。Instagram 的帳號 ID 只接受英文小寫字母、數字、句點和底線，花式字體貼上去會被拒絕。把花式暱稱放在顯示名稱和簡介，帳號 ID 用一般文字就好。

Woher das Ungleichzeichen stammt

Das Ungleichzeichen (≠, U+2260) verbindet das Gleichheitszeichen mit einem diagonalen Schrägstrich — die Unicode-Zerlegung beschreibt es buchstäblich als ein „=“ gefolgt von einem kombinierenden Schrägstrich (U+0338), derselben Marke, die eine ganze Familie negierter Relationen erzeugt: ≁, ≉, ≢, ≮, ≯. Diese Konvention der Durchstreich-Negation ist eine eigene, spätere Geschichte als die Erfindung des „=“ selbst durch Robert Recorde im Jahr 1557: Der früheste bekannte schriftliche Gebrauch des ≠ geht auf Leonhard Eulers Korrespondenz im 18. Jahrhundert zurück — Mathematikhistoriker betonen jedoch, dass das Symbol von Euler verwendet wurde, ohne notwendigerweise von ihm erfunden worden zu sein.

Da ASCII dem ≠ nie einen Platz zuwies, ersetzten Programmiersprachen es durch eigene Entsprechungen — != in den Sprachen der C-Familie, <> in SQL und Pascal, ~= in Lua und MATLAB, /= in Fortran und Haskell —, weshalb das mathematische Symbol und das Zeichen, das man tatsächlich im Code tippt, fast nie dasselbe sind.

FAQ

Häufige Fragen

Das ≠ („ungleich“ oder „ist nicht gleich“) zeigt an, dass zwei Werte nicht gleich sind. Es ist die Negation des Gleichheitszeichens =, gebildet durch einen diagonalen Strich — dieselbe Durchstreichung, die eine ganze Familie negierter Relationen hervorbringt (≁, ≉, ≢, ≮, ≯).

Auf dem Mac drücke Option+= : das ≠ erscheint direkt. Unter Windows tippe 2260 und dann Alt+X in Word, oder kopiere es von dieser Seite. In HTML verwende die Entität &ne; oder &#8800;; in LaTeX \neq.

Weil ASCII dem ≠ nie einen Platz reserviert hat. Die Sprachen haben deshalb tippbare Behelfe übernommen: != in C, Python und JavaScript, <> in SQL und Pascal, ~= in Lua und MATLAB, /= in Fortran und Haskell. Deshalb sind das mathematische Symbol und das, was man tatsächlich im Code tippt, fast immer verschiedene Zeichen.

Die Konvention, ein Symbol zu durchstreichen, um es zu negieren, ist jünger als das Gleichheitszeichen selbst (1557 von Robert Recorde geschaffen). Der früheste bekannte schriftliche Gebrauch des ≠ geht auf Leonhard Eulers Korrespondenz im 18. Jahrhundert zurück — Mathematikhistoriker präzisieren, dass Euler es verwendet, aber nicht notwendigerweise erfunden hat.

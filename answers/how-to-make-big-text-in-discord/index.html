How to Make Big Text in Discord

Start a message line with # and a space for a big header, ## for medium, ### for smaller, and -# for subtext. That's for messages — a username can't be made bigger, so for a name that stands out, paste a Unicode font instead.

Short answer

To make big text in a message, start a new line with a hash and a space: # Big is the largest header, ## Medium is smaller, and ### Small is smaller still. Add -# before a line for subtext (smaller and greyer). The space after the hash is required, and it only works at the start of a line. This is built-in markdown — free, no Nitro, desktop, web, and mobile. Headers only work inside messages, though: a username, display name, or channel renders at a fixed size and can't be enlarged, so to make a name stand out you paste a Unicode font instead.

In messages

Headers and subtext with the hash

Discord's markdown added true headers. Put the marker at the very start of a line, always followed by a space:

  • # Heading → the biggest header (H1)
  • ## Heading → medium header (H2)
  • ### Heading → smaller header (H3)
  • -# Subtext → smaller, greyer subtext

Because a header takes a whole line, you can stack a big title over small print — a # header on one line and a -# caption on the next gives a clean title-and-description layout for announcements. A few gotchas: the space after the hash is mandatory (#Heading stays plain text), headers only work at line start (not mid-sentence), and they render identically on desktop, web, and mobile with no Nitro. Bold and other inline styles still work inside a header line.

Where big text can't reach

Names and channels: use a Unicode font to stand out

People often search for "big text" because they want a name that pops — a display name, a channel, a server title. Headers can't do that: markdown is message-only, and Discord renders every name and channel at a fixed size, so there's no way to make the letters literally bigger.

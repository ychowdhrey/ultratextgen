# UltraTextGen

UltraTextGen to szybki i przejrzysty generator tekstu Unicode, stworzony dla osób, które nie chcą tracić czasu.

- Żadnych ciężkich stron.
- Żadnego zbędnego ładowania.
- Żadnych rozpraszaczy.

Wpisz tekst, skopiuj go i działaj dalej.


## Dlaczego UltraTextGen

Większość generatorów ozdobnego tekstu jest wolna, zagracona i przeładowana efektami, których nigdy nie użyjesz.

UltraTextGen jest przeciwieństwem.

Ładuje się natychmiast  
Działa w całości w przeglądarce  
Bez rejestracji, bez wyskakujących okien  
Nic między tobą a przyciskiem kopiowania

Powstał po to, by oszczędzać czas, a nie go pochłaniać.


## Co Robi

**Stylizowany tekst, który wkleisz wszędzie.** UltraTextGen zamienia zwykły
tekst na style oparte na Unicode — jest ich 114 — działające w mediach
społecznościowych i komunikatorach. Wynikiem jest prawdziwy tekst, a nie obrazek:
kopiuje się, wkleja i przetrwa wszędzie tam, gdzie go umieścisz.

**Ozdobione nicki do gier i profili.** Warstwa ozdobników składa wokół nazwy
ramki, korony i separatory, a silnik reguł dla poszczególnych gier sprawdza
wynik względem limitu znaków, który gra faktycznie wymusi — zanim zużyjesz
zmianę nicku.

**Wydruki i grafika, gdy same znaki nie wystarczą.** Karty do ćwiczeń w piśmie
bąbelkowym i odręcznym, kolorowanki, tekst po łuku i po krzywej, liternictwo
tatuaży. Wszystko to powstaje jako SVG/PNG w twojej przeglądarce i jest krokiem
dalej tam, gdzie kopiuj-wklej nie wystarcza — obrysować, pokolorować,
wydrukować — nigdy odpowiedzią domyślną.

Wszystko powyższe działa po stronie klienta. Nic nie jest generowane na
serwerze i nie pobierane są żadne pliki czcionek, by to działało.

## Zbudowany Pod Szybkość

UltraTextGen jest celowo lekki.

- Bez frameworków
- Bez bundlerów
- Bez zależności w przeglądarce
- Bez zbędnych animacji

Wszystko zaprojektowano tak, by ładowało się szybko i działało płynnie nawet przy wolnym łączu.


## Filozofia Projektowa

- Szybko ważniejsze niż efektownie
- Przejrzyście ważniejsze niż sprytnie
- Użytecznie ważniejsze niż imponująco

Jeśli coś nie pomaga użytkownikowi działać szybciej, nie trafia na produkcję.

## Struktura Projektu

```
ultratextgen/
├── index.html               # Strona główna
├── style.css                # Globalny arkusz stylów
├── script.js                # Logika interfejsu — wejście, siatka, kopiowanie
├── styles.js                # Rejestr stylów Unicode (114 stylów)
├── renderer.js              # Silnik renderowania — rozgałęzia po style.type
├── header.js                # Wstrzykiwacz wspólnej nawigacji
├── sitemap.xml              # Generowany automatycznie — nigdy nie edytuj ręcznie
├── _redirects, _headers     # Konfiguracja Cloudflare Pages
├── _routes.json             # Routing Pages Functions (tylko `/` je wywołuje)
├── functions/               # Middleware Cloudflare Pages
│
├── js/                      # Moduły funkcji, po katalogu na każdy
│   ├── flair/               #   pakiety ozdobników do nicków
│   ├── gamename/            #   reguły nicków dla gier + walidator
│   ├── counter/             #   licznik znaków (z testami)
│   ├── printables/          #   silnik arkuszy do druku
│   ├── curved/  tattoo/     #   tryby wyjścia SVG/PNG
│   ├── vertical/  kaomoji/  #   …i około 20 innych
│
├── category/  usecase/      # Filary treści (zob. „Co jest w serwisie”)
├── guide/     answers/
├── library/   symbol/
├── updates/   embed/
│
├── <lang>/                  # 30 zlokalizowanych drzew serwisu (de/, es/, ja/, …)
│
├── discord/  instagram/     # Strony platform
├── linkedin/ tiktok/  …
│
├── data/                    # Rejestry i katalogi czytane przez narzędzia
├── docs/                    # Dokumentacja techniczna i procesowa
└── scripts/                 # Skrypty budowania, walidacji i generowania
```

`CLAUDE.md` w katalogu głównym repozytorium to pełny przewodnik techniczny —
zasady dotyczące treści, proces lokalizacji, bramki walidacyjne i konwencje.


## Stos Technologiczny

| Warstwa | Technologia |
|---|---|
| Frontend | HTML5, CSS3, czysty JavaScript (ES6+) — bez frameworków i bundlerów |
| Wyjście graficzne | Natywne Canvas/SVG, renderowane po stronie klienta |
| Narzędzia budowania | Node.js (mapa strony, walidatory), Python (generowanie zasobów) |
| CI/CD | GitHub Actions |
| Hosting | Cloudflare Pages + Pages Functions |

Frontend nie ma kroku budowania. Node i Python służą wyłącznie narzędziom
uruchamianym przed wdrożeniem, nigdy w przeglądarce.


## Rozwój

```bash
npm install            # Tylko narzędzia budowania — nic nie trafia do przeglądarki

npx serve .            # Serwuj lokalnie; albo: python3 -m http.server 8080
npm run prebuild       # Wygeneruj ponownie sitemap.xml
npm run sync-readme    # Odśwież generowane bloki w tym pliku
```

Dla frontendu nie ma kroku budowania — otwórz `index.html` bezpośrednio albo
udostępnij katalog dowolnym serwerem plików statycznych.

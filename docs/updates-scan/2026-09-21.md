### Candidate — Emoji 18.0 vendor rollout has quietly started (weak, do not build yet)

- Source: blog.emojipedia.org, "Classic Noto Color Emoji Lives On as Google Debuts
  Emoji 18.0 Support," verified via the article's own JSON-LD (`datePublished:
  2026-09-16T13:58:18Z`, `dateModified: 2026-09-19T11:29:08Z`, author Keith Broni),
  not a WebFetch summary.
- What it said: Google quietly shipped the 9 new Emoji 18.0 glyph designs into
  classic Noto Color Emoji/Noto Emoji on 2026-09-15, a day before formal approval,
  and per a cited Google blog post from 2026-09-17, the new emoji were also rolling
  out in the newer "Noto 3D" style across Pixel and OEM partners, via Google apps
  and Android, with no exact device date given. As of the article's last edit
  (09-19) the new glyphs were still not on the Noto Color Emoji GitHub repo or
  Gstatic — font-level, not yet visible to end users.
- Why this was not a build recommendation yet: single-sourced (the underlying Google
  blog post could not be independently reached), and the picture was explicitly
  still moving. The existing page (`updates/unicode-18-most-anticipated-emoji/`)
  already carried a sourced, methodology-based projection table (built 2026-09-01,
  applying the Emoji 17.0 platform-gap method) and already said plainly "no device
  supports them yet." This finding did not contradict that page or require an
  urgent correction — it was the first real, if partial and unconfirmed, data point
  ahead of the projection.
- Recommendation: hold. Re-check whether the Noto assets actually land on GitHub or
  Gstatic and whether any browser or OS renders the new emoji for real users —
  that is the point where updating the existing page's projection table (not a new
  entry) would be justified.

# Browser-observed SERP evidence, 2026-11-19

What this is: 21 ordinary Google web searches run by hand-equivalent browser
sessions (a real Chrome window driven through the Claude in Chrome extension), read
back as page text and result links. It raises the `competitorFootprintInLocale`
instrument in `data/locale_parent_gap_audit.json` from "not run" to "observed" for
the cells named below. It is not a rank tracker, not a keyword-volume source and not
authorization to build anything: **no verdict in the ledger was changed by it.**

## Method and limits (read before quoting any row)

| Item | Value |
|---|---|
| Engine | Google web search, google.com, one signed-out-equivalent Chrome profile |
| Market | set only through `hl=` and `gl=` URL parameters. The browser's IP is **not** in the target country, so local pack, personalisation and country-ranking effects are not excluded |
| When | 2026-11-19, 08:30 to 09:00 UTC, one session, one query at a time, no retries on a blocked page |
| What was read | the organic result links under `#search` (title anchor hosts and paths) in DOM order, page 1 only, plus whether an AI overview and a People-also-ask block were present |
| Order | DOM order of organic results. **Exact Google rank positions were not observed and are not claimed.** Ads, sitelinks and AI overview citations are not counted as organic results |
| Blocking | no CAPTCHA, consent wall or "unusual traffic" page appeared on any query. Nothing was done to avoid one; the stop rule was to halt on the first block |
| Not Google | no Bing, Brave or other engine was used for any row below. A row here says "Google" and means only that |
| Own pages | `ultratextgen.com` appeared in **no** page-1 result list for any of the 21 queries |
| Cost | free, but manual and rate-limited by Google's own bot detection. This is a spot-check instrument, not unlimited free SERP access, and it does not replace a keyword-volume source |

Result lists are shown as `host/path` with the path cut at 48 characters. Where a
list shows fewer entries than `n`, the remainder was not captured in that read.

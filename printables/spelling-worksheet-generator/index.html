Which sheet to use when

  • Look, say, cover, write, check The one to lean on. The child writes each word from memory and checks it at once, and a Fix it column catches the mistakes. A line at the bottom sets a day to test the words again.
  • Trace, write, remember For children still forming the letters. Tracing helps the hand, and the fold line turns the last step into writing from memory, which is what makes a spelling stick.
  • Missing letters Leaves out the part of each word that usually goes wrong, then asks for the whole word, so the child practises the hard bit and the full spelling.
  • ABC order A dictionary skill as much as a spelling one, so it finishes with three words written from memory.
  • Word shapes A puzzle for words children already know. Many words share one shape, so it is not a way to learn a spelling.

A simple week: Look, say, cover, write, check on Monday and Tuesday, Missing letters on Wednesday with a few words from earlier weeks mixed in, and a test on Friday.

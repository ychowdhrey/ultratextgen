How the puzzle is built

  • Traced from the letters Each letter you type is traced in your browser and turned into an outline; numbered dots are placed evenly around that outline.
  • Any name works There's no library of pre-made pictures — the puzzle is built from whatever you type, so a name, a nickname, or a short word all work the same way.
  • Adjustable difficulty Easy uses fewer, widely-spaced dots for the youngest children; Expert packs in far more dots for a real challenge.
  • Optional guide lines A faint outline through the dots helps beginners; turn it off for a harder puzzle.
  • Ready to hand out Add a heading and a name-and-date line so the sheet is finished for a class set — no editing app needed.

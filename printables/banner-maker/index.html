Printable Banner Maker

Type a word or phrase and build a printable letter banner — one cut-out flag per letter, each with a dashed cut line and string holes, ready to hang. Long phrases page automatically so every sheet prints clean. Free, no sign-up.

Build your banner

Type a word or phrase and the flags build live on the right, one per letter, in order. Print the sheets — they paginate automatically for long phrases — or download one PNG strip.

Each letter becomes its own flag. Spaces become a gap card in the layout — a reminder to leave a space when you string the flags together, not a flag to cut.

Live preview

Runs entirely in your browser — nothing is uploaded. Long phrases print across multiple sheets; cut and string the flags in page order to spell it out.

Ways to use a printable letter banner

  • Birthdays & parties Spell out a name or "HAPPY BIRTHDAY" and string the flags across a wall or mantel.
  • Welcome signs "WELCOME BABY" or "CONGRATS" flags for a shower, graduation, or homecoming.
  • Classrooms A name banner for a desk, cubby, or the first day of school.

How assembly works

Every flag has a dashed cut line and two dotted string-hole markers near the top corners. Cut along the dashed line, punch a hole at each dot, then thread string or ribbon through in order — each flag is numbered so a long phrase across several printed pages still comes together correctly.

Prefer copy-paste text?

This banner is for paper. For bold text you can paste into a post or bio, try the bold fonts generator. For cut-out stencils instead of hanging flags, see printable block letters.

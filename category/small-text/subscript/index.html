Subscript Text Guide

Subscript text uses small, lowered Unicode letters — like ₜₕᵢₛ — instead of a font size or HTML tag. Because each character is its own Unicode symbol, it copies and pastes as plain text and keeps its lowered look anywhere plain text goes, unlike an HTML <sub> tag, which only works inside the webpage that created it.
Subscript is used for chemical formulas (H₂O), footnote-style markers, mathematical notation, and small stylized flourishes on names and bios.
Unicode does not define subscript versions of any capital letter — the subscript block only covers lowercase and digits. Type capitals into the generator and they stay as standard A-Z so your text stays readable; only lowercase letters and numbers get the lowered subscript look.

Superscript Text Guide

Superscript text uses small, raised Unicode letters — like ᵗʰᶦˢ — instead of a font size or HTML tag. Because each character is its own Unicode symbol rather than CSS styling, it copies and pastes as plain text and keeps its raised look anywhere plain text goes. HTML's <sup> tag only works inside a webpage; paste it into a bio, a caption, or a chat app and the formatting vanishes. Unicode superscript doesn't have that problem.
Superscript is popular for bios and usernames, footnote-style asides next to a name or handle, math- and science-adjacent captions (exponents, ordinal suffixes, citations), and small stylized flourishes on an otherwise plain name.
Unicode does not define a true raised superscript glyph for every capital letter — most notably Q. Where no superscript version exists, the generator falls back to the standard capital so your text stays readable instead of dropping the letter. It's the same reason a few characters across small-text styles fall back to their normal form: Unicode's coverage isn't uniform across every letter.

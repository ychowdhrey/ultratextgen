What each code is actually used for

Each encoding here answers a different real job. Morse code is the language of early radio and telegraph signalling, still used in aviation identifiers, emergency signalling, and countless puzzles and escape rooms. Binary powers the popular "what is my name in binary" novelty, showing how any letter becomes an 8-bit byte a computer can store. ROT13 and the Caesar cipher are the go-to way to hide spoilers, punchlines, and answers in forums and comments — visible only to readers who choose to decode them. Braille raises accessibility awareness and helps people learn the tactile alphabet, while leetspeak delivers the classic gamer and hacker aesthetic for usernames, tags, and clan names.

Caesar Cipher — Pick Your Own Shift

ROT13 is a Caesar cipher locked to a shift of 13. The historical cipher Julius Caesar used shifted the alphabet by 3, and a real Caesar cipher lets you choose any shift from 1 to 25. Set a shift, toggle Encode or Decode, and the result updates as you type — only letters move, so digits, punctuation, and spaces pass through untouched.

Unlike the novelty and ancient-script lookalike styles elsewhere on the site, Morse, binary, ROT13, and Braille here are genuine, functioning, standard encodings: Morse follows the ITU standard, binary is standard 8-bit ASCII (one byte per character), ROT13 is a real Caesar-cipher shift of 13, and Braille uses the real Unicode Braille Patterns block matching the standard Grade-1 English alphabet. Only leetspeak is a stylistic meme convention, not a formal cipher.
ROT13 is self-inverse: run the encoded text through the ROT13 style again and it comes back to normal. For Morse, read each space-separated group of dots and dashes as one letter using a Morse chart. For binary, split the output into 8-digit groups and convert each byte from base-2 to its ASCII character. For Braille, match each dot pattern back to its letter using the Grade-1 alphabet. Leetspeak (or 1337) is the classic internet meme convention of swapping letters for lookalike numbers and symbols — A becomes 4, E becomes 3, O becomes 0, and so on. It is a stylistic gamer and hacker aesthetic, not a formal cipher, so there is no strict standard; letters with no common substitution are kept as-is.

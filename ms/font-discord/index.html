Font Discord: bagaimana ia berfungsi

Font Discord di laman ini bukan font yang dipasang atau imej: ini aksara Unicode — huruf sebenar, sama seperti pada papan kekunci, tapi bentuknya berbeza (𝗔, 𝘈, 𝓐, 𝔄). Sebab Discord menerima Unicode pada hampir semua ruangan teks, tulisan power terus melekat pada Display Name, nickname server, About Me, nama channel, sampai status dan mesej chat — tanpa Nitro, bot, atau aplikasi apa pun.

Contoh: «amir» → 𝗮𝗺𝗶𝗿 (tebal), 𝘢𝘮𝘪𝘳 (condong), 𝓪𝓶𝓲𝓻 (sambung), 𝔞𝔪𝔦𝔯 (gothic), ⓐⓜⓘⓡ (gelembung), ᴀᴍɪʀ (kapital kecil)

Caranya pantas: tulis nama dalam kotak di atas, penjana terus tunjukkan teks yang sama dalam pelbagai tulisan Discord, tekan «Salin», kemudian tampal dalam aplikasi. Nak huruf mentah abjadnya sahaja? Ada tepat di bawah ini.

Font power Discord untuk nama dan About Me

Cara terpantas buat profil menonjol ialah pakai satu font pada Display Name dan gabungan lain pada About Me (bio profil anda). Discord menerima Unicode pada kedua-duanya — malah anda boleh ada nickname berbeza setiap server, jadi guna gothic pada server game dan sambung pada server kawan, semua dengan nama yang sama.

Cara tampalnya:

— Display Name: User Settings › Profiles › edit Display Name kemudian tampal fontnya
— Nickname server: klik kanan nama anda dalam server › Edit Server Profile › tampal nick power
— About Me: User Settings › Profiles › ruangan About Me › tampal teksnya
— Nama channel: kalau anda admin, edit channel dan tampal font pada namanya

Tips daripada yang biasa susun profil: guna font power cuma pada nama, biarkan About Me huruf biasa — kontras itulah yang buat menonjol. Kalau semua distailkan, tak ada yang nampak menonjol.

Markdown Discord vs font Unicode — bila nak guna yang mana

Discord ada dua cara ubah teks, dan penting jangan sampai keliru. Satu ialah format Markdown asal; satu lagi font Unicode dari laman ini. Fungsinya berbeza.

— Markdown (asal): **tebal** → tebal, *condong* → condong, __garis bawah__, ~~coret~~, `kod`. Cuma berfungsi dalam mesej chat dan hilang kalau dicuba pada nama atau bio.
— Font Unicode (laman ini): 𝘁𝗲𝗯𝗮𝗹, 𝓼𝓪𝓶𝓫𝓾𝓷𝓰, 𝔤𝔬𝔱𝔥𝔦𝔠. Ini aksaranya sendiri yang sudah bergaya, jadi berfungsi di mana-mana — nick, About Me, nama channel, status, dan chat.

Peraturan mudah: untuk format mesej biasa (buat satu perkataan tebal di tengah ayat), guna Markdown Discord — lebih kemas. Untuk buat nick, bio, atau nama channel power, guna font Unicode, sebab Markdown tak melekat di situ. Satu amaran penting: tak ada yang berfungsi pada username (@), yang cuma menerima huruf kecil a–z, nombor, titik, dan garis bawah — tiada font, ruang, atau emoji. Kalau nak nama bergaya, ruangan yang betul ialah Display Name, bukan @.

Nick Discord power dengan bingkai & simbol

Nick yang paling menonjol dalam Discord memadukan font yang kuat (gothic atau gelembung) dengan bingkai dan simbol di kedua-dua sisi, jenis ꧁༒ ༒꧂. Tekan untuk salin lalu tampal pada nick server — selepas itu tukar dengan nama anda.

Nak nama mentah yang boleh terus dibingkai sendiri? Ambil hurufnya dari abjad di atas, guna font, kemudian bungkus dengan simbol dari tab Bingkai pada penjana di atas.

Di mana font Discord berfungsi (dan amaran kotak-kotak)

Sebab yang anda salin ialah Unicode tulen, tulisan Discord melekat pada hampir semua ruangan teks aplikasi:

— Display Name dan nickname server (satu untuk setiap server)
— About Me (bio profil anda)
— Nama channel (kalau anda ada kebenaran admin)
— Custom Status dan mesej chat
— Nama server (kalau anda pemiliknya)

Satu-satunya tempat yang tidak berfungsi ialah username (@), yang memang sengaja dihadkan. Selain itu, satu amaran jujur: kalau telefon orang yang melihat terlalu lama, sebahagian gaya jarang boleh jadi kotak-kotak (□) — itu font yang tiada pada peranti orang itu, bukan teks anda. Kalau anda kekal pada gaya utama (tebal, condong, sambung, gothic, gelembung, kapital kecil) perkara ini hampir tak pernah berlaku. Dan ingat: semua ini tanpa Nitro — Nitro cuma untuk warna dan gradien pada nama, bukan untuk buat tulisan power.

Font Power Letak Mana — Username Atau Display Name?

Anda tampal satu nama bergaya, ia ditolak sebagai "aksara tak sah", lalu anda anggap font power memang tak berfungsi di sini. Sebenarnya berfungsi — anda cuma letak pada ruangan yang salah.

Jawapan ringkas

Unicode bergaya patut letak pada display name / nickname / bio anda, bukan pada @username (handle) anda. Handle ialah alamat yang orang guna untuk cari dan @mention anda, jadi hampir setiap aplikasi hadkan ia kepada ASCII biasa sahaja — huruf kecil, nombor, titik dan garis bawah — dan tolak font yang ditampal dengan ralat "aksara tak sah". Display name pula sekadar label, jadi ia terima Unicode bergaya. Letak gayanya pada ruangan display name dan biarkan handle anda kekal biasa.

@username = ASCII biasa (tolak font power). Display name / bio = Unicode bergaya (terima).
Peraturan sebenar

Dua ruangan, dua peraturan yang sangat berbeza

Hampir setiap profil ada dua ruangan nama:

  • @username / handle — unik, digunakan dalam URL dan bila orang @mention anda. Terhad kepada huruf, nombor, . dan _. Tampal font power dan anda dapat "username cuma boleh guna huruf, nombor, garis bawah dan titik".
  • Display name / nickname / bio — label mesra untuk manusia baca, bukan alamat. Terima Unicode bergaya, emoji dan ruang.

Jadi penyelesaian untuk ralat "aksara tak sah" hampir selalu: alihkan teks bergaya itu daripada handle ke display name.

Ikut platform

Di mana font power patut diletakkan

Corak sama di mana-mana — gayakan ruangan yang betul, kekalkan handle biasa:

  • Instagram / TikTok — handle kekal biasa; gayakan Nama / Nickname dan bio.
  • Discord — username kekal biasa; gayakan display name dan nickname server.
  • WhatsApp — gayakan nama profil dan About (@username barunya kekal biasa).
  • X / YouTube / Telegram — handle kekal biasa; gayakan display name / nama saluran / nama pertama.

Nama dalam game pun ikut corak yang sama — gayakan display name dan biarkan mana-mana tag kekal biasa. Untuk peraturan aksara ikut setiap game, lihat panduan aksara dibenarkan dalam nama game dan kenapa nama game saya ditolak.

Pengecualian

Tempat font power memang langsung tak berfungsi

Beberapa ruangan tetap tolak teks bergaya walaupun ia sebenarnya display name:

  • Facebook — ruangan nama sebenar menyekat simbol, huruf besar/kecil luar biasa dan campuran skrip mengikut dasar (bio dan hantaran okay sahaja).
  • Twitch — display name Latin cuma boleh tukar huruf besar/kecil, bukan font.
  • LinkedIn — headline dah berhenti terima Unicode bergaya, dan nama bergaya boleh buat anda hilang daripada carian perekrut. Lihat adakah teks bold selamat pada LinkedIn.

Gayakan ruangan yang betul

Buat nama anda dalam gaya yang berfungsi pada display name dan bio, kemudian salin — kekalkan @handle anda biasa.

Soalan lazim

Soalan Yang Kerap Ditanya

Sebab anda tampal pada ruangan @username / handle, yang cuma benarkan huruf, nombor, titik dan garis bawah. Letak teks bergaya itu pada display name, nickname atau bio sebaliknya — ruangan itu terima Unicode.

Username (handle) ialah alamat unik anda, digunakan dalam URL dan bila orang @mention anda, dan terhad kepada ASCII biasa sahaja. Display name pula label mesra yang dipaparkan di atas hantaran anda, dan ia terima Unicode bergaya, emoji serta ruang.

Tak boleh. Handle pada Instagram dan TikTok terhad kepada huruf kecil, nombor, titik dan garis bawah. Gayakan ruangan Nama / Nickname dan bio sebaliknya — kedua-duanya terima font power.

Facebook menyekat simbol dan format luar biasa pada ruangan nama sebenar mengikut dasar mereka, Twitch cuma benarkan display name Latin tukar huruf besar/kecil sahaja bukan font, dan LinkedIn dah tak terima Unicode bergaya pada headline. Bio dan hantaran pada platform-platform ini biasanya okay sahaja.

Handle anda yang gerakkan carian dan @mention, dan ia sentiasa kekal biasa jadi itu tak terjejas. Display name yang terlalu bergaya boleh jadi lebih sukar untuk pembaca skrin dan carian nama, jadi kekalkan ia senang dibaca kalau orang lain menemui anda itu penting bagi anda.

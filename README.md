# UltraTextGen

UltraTextGen is a fast and clean Unicode text generator built for people who don't want to waste time.

- No heavy pages.
- No unnecessary loads.
- No distractions.

Type your text, copy it, and move on.


## Why UltraTextGen

Most fancy text tools are slow, cluttered, and overloaded with effects you'll never use.

UltraTextGen is the opposite.

Loads instantly  
Runs entirely in the browser  
No sign ups, no popups  
Nothing between you and the copy button

It's built to save time, not consume it.


## What It Does

**Styled text you can paste anywhere.** UltraTextGen converts normal text into
Unicode-based styles — 114 of them — that work across social platforms and
messaging apps. The output is real text, not an image: it copies, pastes, and
survives wherever you put it.

**Decorated names for games and profiles.** A flair layer composes frames,
crowns and dividers around a name, and a per-game rule engine checks the result
against the character limit the game will actually enforce — before you spend a
rename.

**Printable and visual output, when plain characters can't do the job.**
Bubble-letter and cursive practice sheets, coloring pages, curved and arc text,
tattoo lettering. These render as SVG/PNG in your browser and are the
higher-intent follow-up for jobs copy-paste can't serve — tracing, coloring,
printing — never the default answer.

Everything above runs client-side. Nothing is generated on a server, and no
font files are downloaded to make it work.


## Who It's For

Creators updating bios and captions  
Social media managers testing variations  
Discord and gaming communities  
Anyone who wants visual emphasis without friction

If speed matters, this tool fits.


## Built for Speed

UltraTextGen is intentionally lightweight.

- No frameworks
- No bundlers
- No browser-side dependencies
- No unnecessary animations

Everything is designed to load fast and stay responsive even on slow connections.


## Design Philosophy

- Fast over fancy
- Clean over clever
- Useful over impressive

If something doesn't help the user move faster, it doesn't ship.

## Project Structure

```
ultratextgen/
├── index.html               # Homepage
├── style.css                # Global stylesheet
├── script.js                # UI logic — input, output grid, copy, decorations
├── styles.js                # Unicode style registry (114 styles)
├── renderer.js              # Rendering engine — dispatches on style.type
├── header.js                # Shared nav injector
├── sitemap.xml              # Auto-generated — never edit by hand
├── _redirects, _headers     # Cloudflare Pages config
├── _routes.json             # Pages Functions routing (only `/` invokes one)
├── functions/               # Cloudflare Pages middleware
│
├── js/                      # Feature modules, one directory each
│   ├── flair/               #   name decoration packs
│   ├── gamename/            #   per-game nickname rules + name checker
│   ├── counter/             #   character counter (has tests)
│   ├── printables/          #   printable sheet engine
│   ├── curved/  tattoo/     #   SVG/PNG output modes
│   ├── vertical/  kaomoji/  #   …and ~20 more
│
├── category/  usecase/      # Content pillars (see "What's on the site")
├── guide/     answers/
├── library/   symbol/
├── updates/   embed/
│
├── <lang>/                  # 30 localized site trees (de/, es/, ja/, …)
│
├── discord/  instagram/     # Platform pages
├── linkedin/ tiktok/  …
│
├── data/                    # Registries and ledgers the tooling reads
├── docs/                    # Engineering and workflow documentation
└── scripts/                 # Build, validation and generation scripts
```

`CLAUDE.md` in the repository root is the full engineering guide — content
rules, localization workflow, validation gates and conventions.


## Tech Stack

| Layer | Technology |
|---|---|
| Frontend | HTML5, CSS3, vanilla JavaScript (ES6+) — no frameworks, no bundlers |
| Visual output | Native Canvas/SVG, rendered client-side |
| Build tooling | Node.js (sitemap, validators), Python (asset generation) |
| CI/CD | GitHub Actions |
| Hosting | Cloudflare Pages + Pages Functions |

The frontend has no build step. Node and Python are used only for tooling that
runs before deploy, never in the browser.


## Development

```bash
npm install            # Build-time tooling only — nothing ships to the browser

npx serve .            # Serve locally; or: python3 -m http.server 8080
npm run prebuild       # Regenerate sitemap.xml
npm run sync-readme    # Refresh the generated blocks in this file
```

There is no build step for the frontend — open `index.html` directly, or serve
the directory with any static file server.

WhatsApp Usernames: The New @Handle Rules, Explained

WhatsApp is rolling out an opt-in @username so people can message you without ever seeing your phone number. The rules are strict — 3 to 35 characters, lowercase only, no styled Unicode — and it's a brand-new locked field sitting next to the Display Name most fancy-text users already style.

WhatsApp Platform rules Reservations opened Jun 29, 2026
What shipped

An Optional @Handle, Sitting Below Your Existing Display Name

WhatsApp opened @username reservations globally on June 29, 2026, and has been switching reserved usernames on for users on a rolling basis since — some are already seeing their username go active. The stated goal is privacy: a username lets a new contact reach you without ever seeing your phone number, which WhatsApp confirms remains required to create and hold an account in the first place. This isn't a replacement for the phone number — it's an additional, optional layer on top of it.

WhatsApp also has no username directory or discovery search, so a username only works if the other person already knows it — closer to a Discord handle than a searchable social profile.

The rules for the username itself are strict: 3 to 35 characters, lowercase letters and numbers only, plus periods and underscores, and it must contain at least one letter (an all-numeric string isn't allowed). It also can't start with "www." or end in a domain-style suffix like .com or .net — guardrails against usernames masquerading as web addresses.

What's next

Watching the Rest-of-2026 Rollout

WhatsApp says broader availability keeps rolling out by country through the rest of 2026 rather than landing on one fixed global date, so reserved usernames not yet live should keep switching on progressively. We'll update this entry if the character rules change, if WhatsApp adds a username directory or discovery search, or if the rollout completes broadly enough to call this "done" rather than "in progress."

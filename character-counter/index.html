Platform character limits, explained

Character limits exist for two different reasons, and it's worth knowing which one you're up against. Hard limits — X/Twitter's 280, Discord's 32-character nickname, TikTok's 24-character username — are enforced by the platform itself: go over and the post or save simply gets rejected. Soft/practical limits — a Google meta description, a YouTube description before "Show more," a LinkedIn post before it gets truncated with "see more" — don't block you from typing more, but anything past that point gets hidden from most readers unless they click to expand. The checker above uses each platform's real hard or officially documented limit; for the soft-truncation ones (meta title/description, YouTube, LinkedIn) treat the number as "how much reliably shows," not a wall you can't cross.

One thing that trips people up: some platforms count more than you'd expect. A URL in an X post counts as ~23 characters no matter how long the actual link is. Emoji and accented characters can count as more than one "character" depending on how a platform's counter is implemented internally — this tool counts by Unicode code point, which matches how virtually every modern platform counts today.

FAQ

Character counter, answered

How do I count words and characters online?

Type or paste your text into the box above. Word count, character count (with and without spaces), sentence count, paragraph count, and estimated reading time all update live as you type — no submit button, and nothing you type is uploaded or stored.

Does this count characters with or without spaces?

Both, shown side by side: "Characters" includes every space, and "Characters (no spaces)" strips whitespace out. Most platform limits (Twitter/X, Instagram, Discord) count spaces as regular characters, so use the with-spaces number when checking a post or bio against a limit.

What is the X (Twitter) character limit?

280 characters per post for standard accounts, including spaces, links, and hashtags (a link still counts as roughly 23 characters even though it displays shorter). Select "X / Twitter post" in the platform checker above to see live whether your text fits.

What is the Instagram caption and bio character limit?

An Instagram caption can run up to 2,200 characters, though only the first couple of lines show before "more" truncates it. The bio field is much shorter: 150 characters. Both are available in the platform checker above.

What is the LinkedIn post and headline character limit?

A LinkedIn post allows up to 3,000 characters, though the feed truncates it with "see more" after roughly 200–700 characters depending on device. The headline field is capped at 220 characters. For a dedicated headline tool, see the LinkedIn headline font generator, which has its own 220-character live counter.

What is the TikTok caption and username character limit?

A TikTok caption fits up to 2,200 characters. The bio is capped at 80 characters, and a username can be up to 24 characters (letters, numbers, underscores, and periods only).

What is a good meta title and meta description length for SEO?

Google truncates by on-screen pixel width rather than a strict character count, but as a practical guideline, keep a meta title to around 60 characters and a meta description to around 155 characters so it doesn't get cut off in search results.

Is this counter free, and does it store or upload my text?

Yes, completely free with no signup. Every count runs client-side in your browser with plain JavaScript — nothing you type is uploaded, logged, or stored anywhere.

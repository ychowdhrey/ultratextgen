TikTok フォントの仕組み

このページの TikTok フォントは、インストールするフォントでも画像でもありません。正体は Unicode 文字です。キーボードの文字と同じ「本物の文字」で、見た目だけが違うように描かれています（𝗔, 𝘈, 𝓐, 𝔄）。TikTok はプロフィール・名前・キャプション・コメントで Unicode を受け付けるので、おしゃれ文字が自己紹介・自己紹介の上にある名前・キャプション・コメント・動画テキストにそのまま貼り付きます。追加のアプリもログインも不要です。

例:「mia」→ 𝗺𝗶𝗮（太字）、𝑚𝑖𝑎（斜体）、𝓶𝓲𝓪（筆記体）、𝔪𝔦𝔞（ゴシック）、ⓜⓘⓐ（バブル）、ᴍɪᴀ（スモールキャップス）

使い方はかんたんです。上の欄に文字を入力すると、同じ文字がたくさんの TikTok フォントで表示されるので、「コピー」を押してアプリに貼り付けます。普通のアルファベットだけが欲しいときは、そのすぐ下に並んでいます。ひとつのスタイルをじっくり試したいときは、筆記体変換で、やわらかく流れるようなプロフ向けの文字を作れます。

TikTok のプロフ・名前用フォント

プロフィールをいちばん早く目立たせるコツは、名前（自己紹介のすぐ上の欄）にひとつのフォントを、自己紹介には別の組み合わせを置くことです。TikTok はどちらでも Unicode を受け付けます。重要なのは、「名前」欄は @ユーザー名とは別物だということ。名前欄にはフォントや記号を入れられますが、@ハンドルには入れられません。

貼り付ける場所:

— 名前: プロフィールを編集 › 「名前」欄 › フォントを貼り付け（自己紹介の上に出る表示名で、@ユーザー名ではありません）
— 自己紹介（プロフ）: プロフィールを編集 › 「自己紹介」欄 › テキストを貼り付け
— キャプション: 投稿時のキャプション欄に貼り付け
— コメント・動画テキスト: コメント時、または動画のテキスト（ステッカー）に貼り付け

プロフィールを作り込む人のコツ: おしゃれ文字は名前欄や自己紹介の 1〜2 行だけに使い、残りは普通の文字にするのがおすすめです。目を引くのはこのコントラストで、大事なキーワードも読みやすいまま残ります。プロフの 1 行目にやわらかい手書き風を出したいときは、筆記体変換がよく合います。

TikTok に太字機能がない理由（と Unicode という近道）

ワープロと違って、TikTok には書式機能がありません。プロフ・キャプション・コメントに太字・斜体・下線のボタンは存在しません。だからこそ、このページの Unicode フォントが便利なのです。

— ネイティブ書式なし: TikTok は一部のアプリのような **アスタリスク**記法を理解しません。入力したアスタリスクやアンダースコアはそのまま文字として残ります。
— Unicode フォント（このページ）: 𝗕𝗼𝗹𝗱、𝓼𝓬𝓻𝓲𝓹𝓽、𝔤𝔬𝔱𝔥𝔦𝔠。これは書式ではなく装飾された文字そのものなので、プロフ・名前・キャプション・コメント・動画テキストのどこでもそのまま使えます。

目安: キャプション内の 1 語を強調したいときは、ここで太字スタイルとしてコピーして、その位置に貼り付けます。それが TikTok で「太字」テキストを出す唯一の方法です。ひとつ重要な注意点として、これらはすべて @ユーザー名では使えません。@ユーザー名は半角の英小文字 a〜z・数字・ピリオド・アンダースコアのみを受け付けます。プロフできれいな段落を作りたいときは、TikTok が空行をまとめてしまうため 透明文字（invisible character）が役立ちます。

枠や記号でつくる、おしゃれな TikTok の名前・プロフ

TikTok で映えるプロフィールの多くは、力強いフォント（かわいい系や筆記体）を、両側に置いた枠や記号（例: ✧˖° °˖✧）と組み合わせています。クリックしてコピーし、「名前」欄やプロフの 1 行目に貼り付けてから、自分の名前に置き換えてください。

名前をたまには縦に並べてみたいときは、縦書きジェネレーターで文字を上下に積み重ねられます。TikTok もこれを純粋な Unicode として表示します。

TikTok でフォントが使える場所（と四角の注意点）

コピーするのは純粋な Unicode なので、フォントは TikTok のほぼすべてのテキスト欄に貼り付きます:

— 名前（自己紹介の上の欄）と自己紹介（プロフ）
— 動画やリールのキャプション
— コメントと返信
— 動画テキスト（テキストステッカー）
— ダイレクトメッセージ（DM）

唯一使えないのは @ユーザー名で、これは意図的に半角の英小文字・数字・ピリオド・アンダースコアに限定されています。それ以外に正直な注意点として、見ている人の端末がとても古い場合、まれなスタイルは四角（□）になることがあります。これはその人の端末にフォントがないためで、あなたの文字の問題ではありません。主要スタイル（太字・斜体・筆記体・ゴシック・かわいい・スモールキャップス）を使えばほぼ起きません。キャプションや動画にグリッチ風の効果を出したいときは、縦書きやフォント変換もあわせて試してみてください。

TikTok フォントに関するよくある質問

このページ上部の入力欄に文字を入力してください。すると、太字・斜体・筆記体・ゴシック・かわいい・スモールキャップスなど、たくさんの TikTok 用フォントがすぐに表示されます。好きなスタイルの「コピー」を押し、TikTok アプリで「プロフィールを編集」を開いて「自己紹介」欄に貼り付けます。これは Unicode 文字なので、アプリを追加しなくてもおしゃれ文字がそのまま残ります。
使えません。@ユーザー名（プロフィールを見つけたりメンションしたりするための固有の @ハンドル）は、半角の英小文字 a〜z・数字・アンダースコア（_）・ピリオド（.）のみに制限されていて、おしゃれ文字・スペース・絵文字は入りません。ただし TikTok フォントは「名前（ニックネーム）」欄・自己紹介・キャプション・コメント・動画テキストで問題なく使えます。名前を目立たせたいときは @ハンドルではなく「名前」欄を使いましょう。
多くの場合、貼り付けた欄が原因です。@ユーザー名は特殊文字を一切受け付けず、「名前」欄でも保存時にまれな記号が除去されることがあります。一方、自己紹介・キャプション・コメントはほとんどの Unicode スタイルを受け付けます。スタイルが消えてしまう場合は、太字・斜体・筆記体・スモールキャップスなどの主要スタイルに切り替えると、どこでも安定して表示されます。
TikTok 自体には太字・斜体ボタンはありません（ワープロのような書式機能がありません）。そこで役立つのが Unicode フォントです。𝗕𝗼𝗹𝗱 や 𝘐𝘵𝘢𝘭𝘪𝘤 は書式ではなく文字そのものなので、キャプションやコメントに貼り付けるだけで太字・斜体のまま表示されます。上の欄に単語を入力し、太字や斜体のスタイルをコピーして貼りたい位置に挿入してください。
TikTok の自己紹介欄は空行や連続したスペースをまとめてしまい、レイアウトが崩れることがあります。その対策が「透明文字（見えない文字）」です。空にしたい行に見えない Unicode 文字を入れておくと余白が保たれます。透明文字のページから 1 文字コピーして、保存前に空行へ貼り付けてください。
見ている人の端末に、その文字を表示するためのフォントが入っていないためで、多くは古いスマホです。このサイトやコピー操作の不具合ではありません。太字・斜体・筆記体・ゴシック・かわいい・スモールキャップスといった主要スタイルは最も安全で、ほぼどこでも正しく表示されます。あるスタイルで四角（□）が出たら、これらの主要スタイルに切り替えてください。

よくある質問

国旗絵文字のよくある質問

旗ではなく「JP」と表示されるのはなぜ？

国旗の絵文字は地域指示子2文字（この場合 J と P）の組み合わせです。対応する画像を持たない環境では2文字がそのまま出ます。仕様どおりの動作で、不具合ではありません。

Windows で国旗が出ないのはなぜ？

Windows は国旗の画像を同梱しておらず、代わりに2文字を表示します。文字としては正しいので、スマートフォンでは旗として表示されます。

イングランドやスコットランドの旗が別扱いなのはなぜ？

これらは2文字ではなくタグ列で作られた地域の旗です。追加が新しく、対応している環境も少なめです。

名前に国旗を入れられますか？

表示名なら多くの場合入れられます。ただし運営方針として国旗だけを削除するサービスもあり、ほかの絵文字とは扱いが違うことがあります。

肩をすくめる顔文字

定番の ¯\_(ツ)_/¯ とそのバリエーション——「知らない」「まあいいか」を表す万能の顔文字です。クリックするだけでコピーできます。

肩をすくめる顔文字 ¯\_(ツ)_/¯ は、広げた両腕で「知らない」「まあいいか」という気持ちを伝える顔文字です。純粋なUnicodeテキストなので、プロフィールやコメント、チャットにそのまま貼り付けられます。定番の形やそのバリエーションを下から選んで、クリックするだけでコピーしてください。

肩をすくめつつ、文字もおしゃれにしませんか？

顔文字は表情担当。名前やフレーズを 𝓒𝓾𝓽𝓮 や 𝗕𝗼𝗹𝗱 のようなおしゃれフォントに変換して、顔文字と組み合わせてみてください。

フォント変換ツールを使う

英数字を100種類以上のおしゃれなUnicodeフォントに一瞬で変換。無料・登録不要で、顔文字との相性もばっちりです。

Roblox 記号（コピペ一覧）

Robloxの表示名・プロフィール・グループを飾る記号を集めました。名前フィルターを通りやすい文字だけを厳選 — クリックするだけでコピーできます。

RobloxはUnicodeの文字を表示名（Display Name）やプロフィールに使えますが、コンテンツフィルターに引っかかって保存できない記号もあります。このページでは、Robloxで実際に表示され、名前フィルターを通りやすい定番の記号 — 星・ハート・花・キラキラ — をまとめました。表示名、グループの説明、プロフィールの自己紹介に、コピペするだけで使えます。

ひとつ大切なのが「表示名」と「ユーザー名」のちがいです。記号を入れられるのはゲーム内で見える表示名のほう。@から始まるユーザー名（ログインID）は半角英数字とアンダースコア「_」1つだけで、記号や日本語は使えません。飾り記号は表示名・プロフィール側で使ってください。

アルファベット自体もおしゃれにしたいときは、フォント変換ツールで名前を筆記体や太字に変えて、記号と組み合わせるのがおすすめです。

本物のRobux・プレミアム・認証済みアイコンはコピペできる？

できません — ここは検索でよく誤解されるポイントです。RobloxのRobux・プレミアム・認証済みの本物のアイコンは、そもそもUnicodeのテキストではありません。公式のRoblox Developer Forumによると、これらのアイコンはPrivate Use Area（私用領域）のごく一部のコードポイント（U+E000〜U+E003）に割り当てられていて、Roblox独自のクライアントアイコンフォントのグリフとして表示される仕組みです。表示されるのはゲーム内UI — 開発者がRoblox Studioで作るTextLabel — の中だけで、表示名やプロフィール、チャットメッセージには表示されず、他のウェブサイトやアプリでも表示されません。それ以外の場所に貼り付けると、空白になってしまいます。見た目だけがほしいなら、上にある王冠・チェックマーク・ダイヤの記号がいちばん近い、貼っても安全な代用品です — ただし本物のプレミアムや認証済みバッジと間違われることはありません。

名前フィルターについて

Robloxの名前フィルターについて

Robloxは自動のコンテンツフィルターを使っていて、表示名やプロフィールの一部のUnicode文字がブロックされることがあります。いちばん安全なのは ★ ♡ ✦ ❀ ⋆ のような1文字の記号。複数文字のコンビや、めずらしいUnicodeブロックの文字は、ブロックされたり削除されたりしやすいです。もし記号が保存できないときは、上の「通りやすい定番記号」から、よりシンプルな1文字の記号に替えてみてください。

FAQ

Roblox記号のよくある質問

Robloxの表示名に使える記号は？

★ ♡ ✦ ❀ ⋆ ✧ のような1文字のUnicode記号がいちばん確実です。名前フィルターを通りやすく、ゲーム内でもきちんと表示されます。マイナーなUnicodeブロックや長いコンビ（複数文字の組み合わせ）は、はじかれることがあります。このページの「通りやすい定番記号」は、実際に表示名へ保存できることを確認した記号だけを載せています。

なぜRobloxで一部の記号はブロックされるの？

Robloxは名前を読みやすく安全に保つため、自動のコンテンツ／名前フィルターを動かしています。検証できない文字 — 装飾的でめずらしいUnicode文字、透明な文字、一部のコンビ — をはじきます。表示名に記号が保存できないときは、よりシンプルな1文字の記号に替えてみてください。

Robloxの表示名に記号を追加するには？

このページで記号をクリック（タップ）してコピーし、設定 → アカウント情報 → 表示名（またはグループ・プロフィールの入力欄）に貼り付けます。記号を受け付けるのは「表示名」で、@から始まる「ユーザー名」は半角英数字とアンダースコア1つだけです。

表示名とユーザー名（@）はどう違う？

ユーザー名（@から始まるログインID）は半角の英数字とアンダースコア「_」1つだけで、記号や日本語は使えません。一方の表示名は、ゲーム内で相手に見える名前で、ここにはUnicodeの記号を入れられます。だから飾り記号は表示名の側で使います。

これらのRoblox記号は使っても安全？

はい。ふつうのUnicode文字を装飾として使っているだけで、チートや裏技ではないので、表示名やプロフィールに使ってもRobloxのルール違反にはなりません。記号のまわりの言葉には通常どおりコンテンツフィルターが働くので、名前全体は健全に保ってください。

本物のRobux・プレミアム・認証済みアイコンはコピペできる？

できません。これらのアイコンは、公式のRoblox Developer Forumで説明されている通り、Roblox独自のクライアントアイコンフォントのグリフに割り当てられた私用領域（Private Use Area）のUnicodeコードポイント（U+E000〜U+E003）です。表示されるのは開発者がRoblox Studioで作るゲーム内UIの中だけで、表示名やプロフィール、チャット、その他プラットフォーム外のどこにも表示されません。それ以外の場所に貼り付けると空白になります。このページの王冠・チェックマーク・ダイヤの記号が、公式バッジを名乗らない範囲でいちばん近い、貼っても安全な見た目です。

同じ記号なのに、他の人は使えて自分だけ「サポートされていない文字」と表示されるのはなぜ？

Robloxの名前フィルターは完全に一定ではなく、アカウントの地域やアプリのバージョン、記号の前後にある文字によって挙動が変わることがあります。コンビがうまくいかないときは、まず記号1つだけを単体で貼り付けてみて、そこから1文字ずつコンビを組み立て直してみてください。「通りやすい定番記号」セクションの1文字記号から選ぶのが、いちばん確実な出発点です。

コピペ記号 一覧

コピペで使える記号をまとめた特殊文字ライブラリ。ハート ♡・星 ★・矢印 →・キラキラ ✨・ギリシャ文字・顔文字・絵文字コンボまで、記号をクリックするだけでコピーできて、インスタのプロフィールや名前、Discord、ゲームのIDにそのまま貼れます。

記号は、キーボードからふつうには打てないUnicodeの文字です。★ ♡ → ✓ のような特殊文字も、画像ではなくキーボードの文字と同じ「文字」なので、コピペするだけでインスタのプロフィール、Xの名前、TikTok、Discord、LINE、ゲームのIDまで、テキストが入る場所ならどこでも使えます。アプリも会員登録もいりません。

下のジャンルから探して、記号をクリック（タップ）すればそのままコピー完了。文字そのものも 𝓒𝓾𝓽𝓮 な筆記体や 𝗕𝗼𝗹𝗱 な太字にしたいときは、フォント変換ツールと組み合わせて、この記号で前後を飾るのがおすすめです。

1つの記号を詳しく

特定の記号を1つだけ調べたいなら

「この記号ってどういう意味？」「どうやって入力するの？」——数式や単位でよく使う記号は、意味・由来・コードポイント・入力方法・似た記号との違いまでまとめた記号の解説ページがあります。ジャンルをまるごと見たいときは上のライブラリを、1文字だけを詳しく知りたいときはこちらをどうぞ。

度の記号（°）

温度や角度の °。よく似た º（序数標識）との違いと入力方法。

掛け算の記号（×）

「かける」を表す × と、アルファベットの x はどう違うのか。

割り算の記号（÷）

「オベルス」÷ の由来と、分数スラッシュとの違い。

ルート記号（√）

1525年が起源の平方根記号と、上線（ヴィンクルム）の役割。

無限大（∞）

横向きの8「レムニスケート」がどこから来たのか。

2乗・3乗（² ³）

m² や cm³ で使う上付き数字。なぜこの2つだけどこでも表示されるのか。
コピーのしかた

記号のコピペのやり方

記号をクリック（タップ）すればコピー完了。あとは貼りたい場所で「ペースト」するだけ——スマホなら入力欄を長押しして「ペースト」、パソコンなら Ctrl+V です。インスタのプロフィール、名前、コメント、Discord、ゲームIDなど、テキストが入る場所ならどこでも貼れます。アプリのダウンロードも会員登録も不要です。

記号だけじゃなく、文字そのものも変えられます

記号で飾ったら、次はアルファベットを 𝗕𝗼𝗹𝗱 な太字や 𝓒𝓾𝓽𝓮 な筆記体に。UltraTextGenなら英数字を100種類以上のおしゃれなUnicodeフォントに一瞬で変換できます。無料・登録不要です。

FAQ

コピペ記号のよくある質問

記号をクリック（タップ）するだけで、そのままクリップボードにコピーされます。あとは貼りたい場所で「ペースト」するだけ。スマホなら入力欄を長押しして「ペースト」、パソコンなら Ctrl+V です。アプリのインストールも会員登録も不要です。

画像でもインストール型のフォントでもありません。★ ♡ → ✓ などはすべて、キーボードの文字と同じUnicodeの文字です。1文字ずつが世界共通の文字コードを持っているので、インスタのプロフィール、名前、コメント、Discord、ゲームのIDなど、テキストが入る場所ならどこに貼っても崩れません。

使えます。ハート・星・矢印・フレームなどの記号は、インスタ、TikTok、X、Discord、LINE、Snapchatのプロフィールや名前、キャプションで使えます。ゲームの名前欄でもUnicodeの記号を受け付けるものが多いです。もし特定の記号がはじかれたら、似た別の記号に変えてみてください。

見ている人の端末やアプリが、その記号を描くフォントを持っていないと □（いわゆる豆腐）で表示されます。自分側の不具合ではなく、相手の端末がその文字を知らないだけです。★ ♡ • → ✓ のような定番の記号はほぼすべての環境で正しく表示されるので、凝った記号を使うときは投稿前にスマホで見え方を確認すると安心です。

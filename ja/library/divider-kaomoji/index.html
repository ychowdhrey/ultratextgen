顔文字の区切り線

キラキラ、星、ハートを使ったかわいい区切り線をまとめました。プロフィールや投稿の段落分けにどうぞ。クリックするだけでコピーできます。

顔文字の区切り線は、キラキラした記号や星、ハート、小さな点をつなげて作る装飾的なテキストの線で、プロフィールや投稿、コメントの段落を区切るのに使います。｡･:*:･ﾟ★ や ˚₊‧꒰ა ✿ ໒꒱‧₊˚ のような区切り線は純粋なUnicodeテキストなので、どこにでもそのまま貼り付けられます。好きなスタイルを下から選んで、クリックするだけでコピーしてください。

区切り線と一緒に、文字も飾ってみませんか？

区切り線は装飾担当。名前やプロフィールの文字を 𝓒𝓾𝓽𝓮 や 𝗕𝗼𝗹𝗱 のようなおしゃれフォントに変換して、組み合わせてみてください。

フォント変換ツールを使う

英数字を100種類以上のおしゃれなUnicodeフォントに一瞬で変換。無料・登録不要で、顔文字との相性もばっちりです。

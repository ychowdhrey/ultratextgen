ハグ顔文字

両手を広げた抱っこやぎゅーを表すハグ顔文字をまとめました。クリックするだけでコピーできます。

ハグ顔文字は、っ や づ を使って両腕を広げ、ハグのために手を伸ばす顔文字です。(づ｡◕‿‿◕｡)づ や ⊂(・ω・*⊂) のようなハグ顔文字は純粋なUnicodeテキストなので、プロフィールやコメント、メッセージにそのまま貼り付けられます。スタイルにあわせて下から選んで、クリックするだけでコピーしてください。

フォント変換

ハグの気持ちを、文字でも伝えてみませんか？

顔文字は表情担当。名前やメッセージを 𝓒𝓾𝓽𝓮 や 𝗕𝗼𝗹𝗱 のようなおしゃれフォントに変換して、顔文字と組み合わせてみてください。

フォント変換ツールを使う

英数字を100種類以上のおしゃれなUnicodeフォントに一瞬で変換。無料・登録不要で、顔文字との相性もばっちりです。

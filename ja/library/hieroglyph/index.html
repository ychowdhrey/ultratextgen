ヒエログリフ 一覧

Unicode に収録されたエジプト象形文字を、ガードナー分類の順に1000字以上。タップでコピーできます。

ヒエログリフは画像ではなく Unicode の文字なので、コピーしてそのまま貼り付けられます。並び順はエジプト学で使われるガードナー分類（人・鳥・植物…）に従っています。目的の字が決まっていなくても、分類をたどれば探せます。各記号にはガードナー番号を付けています。アルファベットが記号の分類、数字がその分類内の位置を表します（A1 は分類 A の最初の記号、座る男性）。

ヒエログリフが Unicode に入っている理由

よくある質問

ヒエログリフのよくある質問

貼り付けても四角になるのはなぜ？

端末にヒエログリフを表示できるフォントが入っていないためです。文字自体は正しく、対応フォントのある環境では表示されます。Android では出ないことが多く、iOS と Windows では比較的表示されます。

名前をヒエログリフで書けますか？

一字一音の置き換えはできますが、正確な表記ではありません。ヒエログリフは表音と表意が混ざる文字体系で、現代の名前をそのまま綴る仕組みは持っていないためです。遊びとしては使えます。

𓂀 は「ホルスの目」ですか？

U+13080 は Gardiner D10、いわゆるウジャトの目です。「ホルスの目」と呼ばれるものにあたりますが、後世の護符の図像と古代の用法は必ずしも同じではありません。

ガードナー分類とは何ですか？

アラン・ガードナーが体系化した記号の分類で、A（人）B（女性）C（神々）…のように意味ごとにまとめたものです。このページの並びもそれに従っています。

SNS の名前に使えますか？

使える場所もありますが、表示できない端末では四角になります。相手の画面で読めない可能性が高いので、名前より投稿本文で使うほうが無難です。

特殊文字 一覧（かわいい記号コピペ）

かわいい特殊文字をジャンル別にまとめました。キラキラ・ハート・星・矢印・飾り括弧・音符まで — クリックするだけでコピーできて、インスタのプロフィールやゲームの名前にそのまま使えます。

ギリシャ文字 一覧（コピペ）

アルファからオメガまで、ギリシャ文字の大文字・小文字・数学で使う異体字をまとめてコピペ。数学・物理・統計のレポートから、SNSのプロフやニックネームの飾りまで — クリックするだけでコピーできます。

Windows Altコード

論文・脚注・引用や日本語の文書作成で使う特殊記号・外国語のアクセント文字・数式記号を、Windowsのキーボードで入力するためのAltコード一覧。テンキーがなくても、記号をクリックすればすぐにコピーできます。

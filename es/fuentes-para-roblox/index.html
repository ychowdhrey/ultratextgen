Fuentes compatibles con Roblox: qué se guarda de verdad

"Funciona en Roblox" son en realidad tres obstáculos distintos, y la mayoría de las guías los mezclan:

1. El dispositivo de quien lo ve. Un estilo se ve como cuadraditos (□) cuando el teléfono u ordenador de esa persona no tiene una fuente que cubra ese rango Unicode — es un problema del dispositivo, no algo que Roblox controle.

2. El validador del nombre para mostrar. Por separado, Roblox revisa el nombre para mostrar al guardarlo y rechaza ciertos caracteres con el error "caracteres no compatibles" — una comprobación real del servidor, no un problema de visualización.

3. El filtro de chat y moderación de Roblox. Es otro sistema distinto, pensado para detectar insultos, datos personales y texto usado para evadir el filtro en el chat. No es algo que convenga intentar sortear, y este generador no está pensado para eso — sirve para darle estilo al nombre, no para saltarse la moderación.

Para el nombre para mostrar, la bio y la descripción del grupo, lo más fiable son los estilos de sustitución Unicode simples — negrita, cursiva, versalitas, gótica — y los símbolos sueltos como los de abajo. Como el nombre para mostrar solo se refresca gratis una vez cada 7 días, revisa siempre el resultado dentro del juego antes de confirmarlo.

Letras de burbuja para imprimir A–Z y 0–9

Elige una letra o un número para obtener un contorno de burbuja grande y redondeado que puedes trazar, colorear, imprimir o descargar en PNG — o escribe un nombre para una hoja entera. Gratis, sin registro.

Elige una letra de burbuja

Toca una letra (A–Z) o un número (0–9) para ver su contorno de burbuja grande, imprimirlo, descargar un PNG o copiar los estilos de burbuja Unicode correspondientes.

Imprime un nombre en letras de burbuja

Escribe un nombre o una palabra corta y luego imprime una hoja de contornos de burbuja para trazar y colorear, o guárdala como un banderín en PNG.

Alfabeto de burbuja para imprimir

Todo el alfabeto de burbuja A–Z y 0–9 en contornos. Imprime la hoja entera para trazar o colorear, o toca cualquier letra para abrir sus opciones de impresión y descarga.

Formas de usar las letras de burbuja para imprimir

  • Trazar Imprime un contorno y repásalo para aprender la forma hinchada a mano.
  • Colorear El relleno blanco está listo para rotuladores, ceras o pintura — genial para niños y aulas.
  • Manualidades Recorta las letras para banderines, letreros de puerta, tarjetas de cumpleaños, álbumes y bullet journals.

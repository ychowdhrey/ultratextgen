Generador de banderines para imprimir

Escribe una palabra o frase y crea un banderín de letras para imprimir — un gallardete recortable por letra, cada uno con una línea de corte de puntos y agujeros para el cordel, listo para colgar. Las frases largas se paginan automáticamente para que cada hoja se imprima limpia. Gratis, sin registro.

Crea tu banderín

Escribe una palabra o frase y los banderines se crean en directo a la derecha, uno por letra, en orden. Imprime las hojas — se paginan automáticamente para frases largas — o descarga una única tira en PNG.

Cada letra se convierte en su propio banderín. Los espacios se muestran como una tarjeta de hueco en la composición — un recordatorio para dejar un espacio al atar los banderines, no un banderín para recortar.

Vista previa en directo

Funciona por completo en tu navegador — no se sube nada. Las frases largas se imprimen en varias hojas; recorta y ata los banderines en orden de página para formar la frase.

Formas de usar un banderín de letras para imprimir

  • Cumpleaños y fiestas Forma un nombre o «FELIZ CUMPLEAÑOS» y cuelga los banderines por una pared o una repisa.
  • Carteles de bienvenida Banderines de «BIENVENIDO BEBÉ» o «ENHORABUENA» para un baby shower, una graduación o un recibimiento.
  • Aulas Un banderín con el nombre para un pupitre, un casillero o el primer día de clase.

Cómo funciona el montaje

Cada banderín tiene una línea de corte de puntos y dos marcas de agujero para el cordel cerca de las esquinas superiores. Recorta por la línea de puntos, perfora un agujero en cada punto y luego pasa un cordel o cinta en orden — cada banderín está numerado, así que una frase larga repartida en varias páginas impresas sigue quedando bien montada.

¿Prefieres texto para copiar y pegar?

Este banderín es para papel. Para texto en negrita que puedas pegar en una publicación o biografía, prueba el generador de letras en negrita. Para letras recortables en vez de banderines colgantes, mira las letras de burbuja para imprimir.

Signo Micro (µ)

El signo micro (µ) usado para micras, microgramos y microsegundos — y por qué es un carácter completamente distinto de la letra griega mu, a la que se parece de forma idéntica. Haz clic en cualquier símbolo para copiarlo al instante.

Haz clic para copiar · U+00B5

El signo micro (µ, U+00B5) y la letra griega minúscula mu (μ, U+03BC) se representan como el mismo glifo exacto en casi cualquier fuente, pero Unicode los trata como dos caracteres distintos. Cuál de los dos pegues puede romper silenciosamente búsquedas, coincidencias de expresiones regulares y nombres de archivo sin que nunca se vea mal en pantalla.

Historia y Contexto

Por qué existen dos caracteres visualmente idénticos

El signo micro (µ, U+00B5) existe en Unicode puramente por compatibilidad retroactiva. Se heredó de ISO/IEC 8859-1 (Latin-1), la codificación de 8 bits anterior a Unicode que sigue integrada en incontables sistemas heredados, fuentes y formatos de archivo. La propia guía del Consorcio Unicode indica que la letra griega minúscula mu (μ, U+03BC) es el carácter preferido para el prefijo SI «micro» — µg, µm, µs —, pero el software debe seguir reconociendo también U+00B5, porque muchísimo texto existente ya lo usa.

Los dos caracteres son visualmente idénticos en casi cualquier fuente, y la propia regla de normalización NFKC de Unicode reduce automáticamente el signo micro a la mu griega. Eso suele ser invisible — hasta que deja de serlo: una búsqueda, una coincidencia de expresión regular, una comparación de nombres de archivo o una consulta a una base de datos pueden fallar en silencio cuando una cadena usa U+00B5 y la otra U+03BC, porque para una comparación a nivel de byte son caracteres distintos aunque ningún ser humano note la diferencia en pantalla. Es un tropiezo lo bastante común como para que los desarrolladores presenten informes de errores reales por esto — una pull request de Home Assistant en 2025, por ejemplo, propuso cambiar las cadenas de unidades del proyecto del signo micro a la mu griega específicamente para evitar este tipo de desajuste.

Preguntas frecuentes

Preguntas frecuentes sobre el signo micro

¿µ y μ son el mismo carácter?

No — son visualmente idénticos, pero Unicode les asigna puntos de código distintos (U+00B5 para el signo micro, U+03BC para la mu griega), y la diferencia puede romper en silencio búsquedas, coincidencias de expresiones regulares y comparaciones de cadenas aunque en pantalla no se vea nada raro.

¿Cuál debo usar para microgramos o micras?

Cualquiera de los dos se muestra correctamente para un lector humano, pero el Consorcio Unicode recomienda la mu griega (μ, U+03BC) para texto nuevo, ya que la normalización NFKC ya convierte automáticamente el signo micro en ella. Usa el signo micro solo cuando tengas que coincidir con un sistema heredado que lo espere específicamente.

¿Por qué mi búsqueda no encuentra «µg» cuando busco «μg»?

Porque son caracteres Unicode distintos. Una búsqueda de texto plano suele hacer una comparación exacta a nivel de byte y no tratará U+00B5 y U+03BC como equivalentes a menos que la búsqueda normalice el texto primero (NFKC).

¿Hay alguna diferencia visible entre µ y μ?

No — en prácticamente cualquier fuente se representan con el mismo glifo. La diferencia está por completo a nivel de codificación de caracteres, invisible hasta que entran en juego el código, la búsqueda o herramientas de coincidencia de archivos.

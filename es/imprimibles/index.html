Cómo funcionan los imprimibles

Cada imprimible viene de dos formas. Hay fichas listas para usar — planchas de alfabeto A–Z completas y páginas por letra para imprimir tal cual: letras burbuja para colorear, fichas de caligrafía en cursiva con líneas modelo para repasar, y abecedarios para colorear. Elige una letra y listo — nada que configurar.

Y hay un generador en cada página para crear tus propias fichas. Escribe una palabra o un nombre completo y la herramienta compone una ficha nueva al instante — una línea modelo completa, líneas atenuadas para repasar y líneas en blanco para practicar. Cuando el resultado te convenza, Imprímelo directamente desde tu navegador o Descarga el PNG para una imagen en alta resolución. Todo ocurre en el navegador: es gratis, instantáneo y sin registro.

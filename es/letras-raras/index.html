Letras raras Unicode

Un estilo distinto para cada mensaje

Las letras raras no son fuentes que tengas que instalar ni imágenes: son caracteres Unicode que se copian y pegan como cualquier texto. Aquí verás todos los estilos a la vez, desde negrita y cursiva hasta góticas, burbujas o texto al revés, para que elijas el que mejor encaje con tu bio, tu nombre de usuario o una publicación.

Relacionado

Combina tus letras raras con símbolos aesthetic o símbolos de corazón. Si buscas un estilo concreto, prueba letras góticas, letras negritas o texto al revés. También puedes usar el decorador de texto para dar el toque final.

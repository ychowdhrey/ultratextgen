How to Print Worksheets for a Whole Class

Type your class list once, give each child the level they are working at, and print every child's own sheet as one PDF. This guide shows which UltraTextGen worksheet tools take a class list and how to keep a class set short on paper and clear after photocopying.

Learn · Printing ⏱ 4 min read

Key takeaways

  • Type the class list once. Every UltraTextGen worksheet tool with a class set reads the same list, so thirty names are not retyped when you switch tools.
  • Add a number after a name, such as "Noah 2", to print that child's sheet at a different level in the same run.
  • Choose 4 sheets per page and a class set for 30 children fits on 8 pages instead of 30.
  • For a master you will photocopy, turn on High contrast so the guide lines survive the copier.
  • The whole class saves as one PDF, and tracing sheets come back labelled with a Name and Date line.

Step 1: type the class list once

Open any worksheet tool with a class set and open its Class set: one sheet per name panel. Paste your class list with one name per line, up to 60 names. Each name becomes its own sheet, and the preview shows how many sheets and pages the job will print before you press anything.

The list is saved in your browser on this device, and every class set tool reads the same saved list. A class you typed on the name tracing page is already there when you open the word search maker or the coloring page maker, so moving between worksheets does not mean retyping the class. On a different device or browser, type it once there.

Step 2: give each child their own level

A mixed ability class does not need one print run per level. On the handwriting worksheet generator and sight word tracing, add the level number after a child's name, separated by a space:

  • Noah 2 prints Noah's sheet at level 2.
  • Maya, with no number, gets the level selected on the page.
  • R2D2 stays a name, because the number has to stand on its own after a space.

The seven handwriting levels run from a solid model to trace over down to a blank line written from memory. From Tracing to Writing explains when a child is ready to move up a level. The word search and word scramble makers read a number after a name the same way, for their Easy, Medium and Hard levels.

Step 3: fit the set on less paper

Under Sheets per page, choose 1 or 4. With 4, each child's sheet shrinks to a quarter of the page, and the line below the choice updates to show the cost, for example "30 sheets · 8 pages". A class set for 30 children then uses 8 pages of paper instead of 30.

Four to a page suits older children, quick warm-ups and puzzles. Keep 1 sheet per page when children are tracing large letters for the first time, since a quarter-size sheet also means quarter-size letters.

Printing a master to photocopy

If you print one master and photocopy it for the class, open PDF settings and choose High contrast (for photocopying). Grey guide lines and pale tracing letters are the first things a copier drops, and the high contrast version prints them dark enough to survive. Avoid the Ink saver option on a master: it prints lines lighter, which is the opposite of what a copier needs. How to Save Printer Ink on Worksheets shows what our tests found about pages that are photocopied.

Left-handed children

A right-handed child writing from left to right can see the model letter at the start of the line all the way across. A left-handed child's writing hand covers it. On the name tracing page and the handwriting, letter and sight word tracing worksheets, tick Left-handed (model on both sides) to print the model at both ends of each line. From Tracing to Writing covers this in more detail.

Step 4: save the class as one PDF

Press Download PDF to get every child's sheet in one file, sized for the paper chosen in PDF settings (US Letter, A4 or Legal). Keep the PDF to reprint the same set next week without rebuilding it.

Name tracing, letter tracing, handwriting and sight word sheets print with a Name and Date line, so finished work comes back labelled. Every sheet also carries a small QR code: scanning the paper reopens the tool that made it. The QR code holds only the page address, never your class list.

A share link is different. When you share a class set with Copy link or Share, the names on the list are part of the link, so it reopens the same set for a colleague. Only send it to people who should see the class list.

Printing Worksheets for a Whole Class: FAQ

How many names can a class set take?

Up to 60. Paste one name per line, and each name becomes its own sheet in the same print job or PDF.

Do I have to retype the class list on every worksheet tool?

No. The list is saved in your browser, and every UltraTextGen tool with a class set reads the same list, so a class typed on the name tracing page is already filled in on the word search maker. On another device or browser you type it once more.

Can children in the same class work at different levels?

Yes. On the handwriting worksheet generator and sight word tracing, add the level number after a name, such as Noah 2, and that child's sheet prints at level 2 while everyone else gets the level you picked. The word search and word scramble makers read a number after a name the same way for their difficulty levels.

How do I use less paper for a class set?

Choose 4 under Sheets per page. Each child's sheet shrinks to a quarter of the page, so a set for 30 children fits on 8 pages instead of 30. Keep 1 when children need full-size letters to trace.

Does the QR code on a printed sheet contain the children's names?

No. The QR code opens the tool's page, not your class set. A share link is different: when you share a class set as a link, the names on the list are part of the link, so only send it to people who should see the class list.

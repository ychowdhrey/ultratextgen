Kode Alt

Semua kode tombol Alt Windows yang umum lengkap dengan karakter yang dihasilkan — atau tinggal klik untuk menyalin kalau kamu ingin melewati numpad. Klik karakter mana pun untuk langsung menyalinnya.

Kode Alt memungkinkan pengguna Windows mengetik karakter khusus dengan menahan tombol Alt sambil mengetik angka di numpad — Alt+0169 menghasilkan ©, Alt+3 menghasilkan ♥. Referensi ini mengumpulkan kode Alt paling berguna yang dikelompokkan per kategori, lengkap dengan kode dan nama tiap karakter. Tidak punya numpad? Tidak masalah: setiap karakter di halaman ini juga bisa langsung diklik untuk disalin, jadi tetap berfungsi di laptop, Mac, maupun HP.

Simbol Garis Vertikal

Apa arti |, sejarah pipe Unix-nya, dan cara mengetiknya — klik untuk langsung menyalin.

| sudah jadi bagian standar ASCII sejak tahun 1960-an, awalnya cuma karakter pembatas biasa. Makna paling terkenalnya datang dari dunia komputer: pada 1973, Doug McIlroy di Bell Labs memperkenalkan operator "pipe" untuk shell Unix, yang membuat command1 | command2 mengalirkan output satu program langsung jadi input program berikutnya. Ide sederhana itu — program-program kecil yang dirangkai bareng, bukan satu program raksasa yang mengerjakan semuanya — jadi salah satu konsep paling berpengaruh dalam desain perangkat lunak, dan itulah kenapa | masih dijuluki "pipe" puluhan tahun kemudian, tetap jadi inti scripting shell dan command-line tools di hampir semua sistem operasi modern. Di luar dunia komputer, | juga berperan ganda sebagai notasi matematika — membungkus angka untuk menandakan nilai mutlak (|-5| = 5), memisahkan syarat dalam notasi pembentuk himpunan ({x | x > 0}), dan menandakan keterbagian (a | b, "a membagi b") — sekaligus jadi pembatas visual biasa di menu, tagline, dan daftar (Nama | Jabatan | Lokasi).

FAQ

Simbol garis vertikal, dijawab

Apa arti simbol garis vertikal?

Tergantung konteksnya. Dalam tulisan sehari-hari, | adalah pembatas sederhana antar item (Nama | Jabatan | Lokasi). Dalam matematika, |x| berarti nilai mutlak dan {x | x > 0} dibaca "himpunan x sedemikian sehingga x lebih besar dari 0". Dalam dunia komputer, | adalah operator "pipe" Unix yang mengalirkan output satu perintah ke perintah lain.

Kenapa | disebut "pipe" dalam pemrograman?

Doug McIlroy memperkenalkan operator pipe di Bell Labs tahun 1973 untuk shell Unix. Menulis command1 | command2 langsung mengalirkan output perintah pertama ke perintah kedua, seperti air lewat pipa — salah satu ide paling berpengaruh dalam dunia komputer, dan masih jadi inti scripting shell serta command-line tools sampai sekarang.

Bagaimana cara mengetik simbol |?

Ini tombol keyboard standar — Shift+Backslash (\) di layout US, di Windows maupun Mac, biasanya persis di atas atau bawah tombol Enter/Return. Tidak perlu kode Alt, meski Alt+124 juga berfungsi di Windows.

홈 › 사용자 이름과 표시 이름

사용자 이름 또는 표시 이름 — 화려한 폰트는 어디에 써야 할까?

멋지게 꾸민 이름을 붙여넣었는데 “유효하지 않은 문자”라며 거부당하면, 이 앱은 화려한 폰트를 지원하지 않는구나 싶습니다. 아닙니다 — 그냥 엉뚱한 칸에 넣었을 뿐입니다.

간단한 답

화려한 유니코드는 표시 이름 / 닉네임 / 자기소개에 넣는 것이지, @사용자 이름(핸들)에 넣는 것이 아닙니다. 핸들은 사람들이 당신을 찾고 @멘션할 때 쓰는 주소이기 때문에, 거의 모든 앱이 소문자·숫자·마침표·밑줄 같은 일반 ASCII로만 제한하고, 붙여넣은 폰트는 “유효하지 않은 문자” 오류로 거부합니다. 표시 이름은 하나의 라벨일 뿐이므로 꾸며진 유니코드를 받아들입니다. 스타일은 표시 이름 칸에 넣고, 핸들은 평범하게 유지하세요.

@사용자 이름 = 일반 ASCII(폰트 거부). 표시 이름 / 자기소개 = 꾸며진 유니코드(허용).
규칙

두 개의 칸, 완전히 다른 두 가지 규칙

거의 모든 프로필에는 두 가지 이름 칸이 있습니다.

  • @사용자 이름 / 핸들 — 고유하며 URL과 @멘션에 쓰입니다. 문자·숫자·.·_로 제한됩니다. 폰트를 붙여넣으면 “사용자 이름은 문자, 숫자, 밑줄, 마침표만 사용할 수 있습니다”라는 메시지가 뜹니다.
  • 표시 이름 / 닉네임 / 자기소개 — 주소가 아니라 사람이 읽는 라벨입니다. 꾸며진 유니코드, 이모지, 공백까지 받아들입니다.

그러니 “유효하지 않은 문자” 오류의 해결책은 거의 언제나 하나입니다 — 화려한 텍스트를 핸들에서 빼서 표시 이름으로 옮기는 것.

플랫폼별로 보면

화려한 텍스트는 어디에 넣어야 할까

패턴은 어디서나 똑같습니다 — 오른쪽 칸을 꾸미고, 핸들은 평범하게 둡니다.

  • 인스타그램 / 틱톡 — 핸들은 평범하게. 이름 / 닉네임과 자기소개를 꾸미세요.
  • 디스코드 — 사용자 이름은 평범하게. 표시 이름과 서버 닉네임을 꾸미세요.
  • 왓츠앱 — 프로필 이름과 소개를 꾸미세요(새로 생긴 @사용자 이름은 평범해야 합니다).
  • X / 유튜브 / 텔레그램 — 핸들은 평범하게. 표시 이름 / 채널 이름 / 이름을 꾸미세요.

게임 이름도 같은 패턴을 따릅니다 — 표시 이름을 꾸미고 태그는 평범하게 둡니다. 게임별 상세한 문자 규칙은 allowed characters in game usernames(영문 가이드)와 게임 이름이 거부되는 이유에서 확인하세요.

예외

화려한 텍스트가 정말로 안 통하는 곳

표시 이름인데도 꾸며진 텍스트를 거부하는 칸이 몇 군데 있습니다.

  • 페이스북 — 정책상 실명 칸에서 기호, 부자연스러운 대소문자, 여러 문자 체계 혼용을 막습니다(자기소개와 게시물은 대체로 괜찮습니다).
  • 트위치 — 라틴 문자 표시 이름은 대소문자만 바꿀 수 있고 폰트는 바꿀 수 없습니다.
  • 링크드인 — 헤드라인은 더 이상 꾸며진 유니코드를 받지 않으며, 꾸며진 이름은 채용 담당자의 검색에서 당신을 찾기 어렵게 만들 수 있습니다.

올바른 칸을 꾸며보세요

표시 이름과 자기소개에서 잘 통하는 스타일로 이름을 만들어 복사하세요 — @핸들은 평범하게 유지하고요.

자주 묻는 질문

문자, 숫자, 마침표, 밑줄만 허용하는 @사용자 이름(핸들) 칸에 붙여넣었기 때문입니다. 꾸며진 텍스트는 표시 이름, 닉네임, 자기소개에 넣으세요. 그 칸들은 유니코드를 받아들입니다.

사용자 이름(핸들)은 URL과 @멘션에 쓰이는 당신만의 고유한 주소로, 일반 ASCII로 제한됩니다. 표시 이름은 게시물 위에 표시되는, 사람이 읽기 위한 라벨로, 꾸며진 유니코드 문자와 이모지, 공백까지 사용할 수 있습니다.

안 됩니다. 인스타그램과 틱톡의 핸들은 소문자, 숫자, 마침표, 밑줄로 제한됩니다. 대신 이름(닉네임) 칸과 자기소개를 꾸미세요. 그곳은 화려한 유니코드를 받아들입니다.

페이스북은 정책상 실명 칸에서 기호와 부자연스러운 표기를 막고, 트위치의 라틴 문자 표시 이름은 대소문자만 바꿀 수 있으며, 링크드인은 헤드라인에서 더 이상 꾸며진 유니코드를 받지 않습니다. 이들 플랫폼에서도 자기소개와 게시물은 대체로 문제없습니다.

검색과 @멘션은 핸들이 담당하며 핸들은 평범한 상태를 유지하므로 영향을 받지 않습니다. 다만 지나치게 꾸며진 표시 이름은 스크린 리더나 이름 검색에서 읽기 어려울 수 있으니, 사람들이 당신을 잘 찾길 원한다면 어느 정도 읽기 쉬운 스타일을 유지하세요.

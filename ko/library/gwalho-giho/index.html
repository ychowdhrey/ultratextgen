괄호 기호, 자주 묻는 질문

괄호 기호란 무엇인가요?

괄호 기호는 소괄호 ( ), 대괄호 [ ], 중괄호 { }처럼 텍스트를 감싸는 유니코드 문자입니다. 자판에 있는 기본 괄호 외에도 한국어에서 쓰는 낫표 「 」, 수학용 올림·내림 괄호, 감성 닉네임에 인기 있는 화살괄호·장식 괄호까지 유니코드에는 수십 가지 괄호가 있습니다.

괄호 기호는 어떻게 복사하나요?

이 페이지에서 원하는 괄호를 클릭(모바일은 탭)하면 클립보드에 바로 복사됩니다. 문서, 메시지, 프로필 등 원하는 곳에 붙여넣기만 하면 됩니다. 여는 괄호와 닫는 괄호는 각각 따로 복사해서 쓰세요.

「 」와 『 』는 어떻게 다른가요?

둘 다 한국어 문장부호입니다. 홑낫표 「 」는 소제목이나 글·노래·그림 같은 작품 이름, 또는 강조할 어구에 씁니다. 겹낫표 『 』는 책·신문 등 출판물의 제목에 쓰죠. 가로쓰기에서는 각각 홑화살괄호 〈 〉, 겹화살괄호 《 》로 바꿔 쓰기도 합니다.

괄호 기호는 모든 기기에서 잘 보이나요?

( ) [ ] { } 같은 기본 괄호는 어디서나 완벽하게 표시됩니다. 낫표 「 」나 전각 괄호 （ ）는 한중일 폰트가 있는 기기에서 잘 보이지만, 일부 앱에서는 글자 사이 간격이 넓게 나타날 수 있습니다. 장식·수학 괄호는 붙여넣은 뒤 실제 화면에서 한 번 확인하는 것이 좋습니다.

중괄호 { }는 키보드로 어떻게 입력하나요?

한국어 키보드에서 중괄호는 Shift를 누른 채 [ ] 키를 누르면 { } 로 입력됩니다. 낫표 「 」나 화살괄호처럼 자판에 없는 괄호는, 윈도우 한글 IME에서 자음 'ㄴ'을 입력한 뒤 한자 키를 눌러 특수문자 목록(괄호 모음)에서 찾을 수 있습니다. 다만 기기마다 동작이 달라, 이 페이지에서 바로 클릭해 복사하는 쪽이 더 빠르고 확실합니다.

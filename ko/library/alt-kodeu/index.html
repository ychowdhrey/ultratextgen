알트 코드 (Alt Code)

윈도우에서 특수문자를 입력하는 가장 흔한 Alt 키 코드 모음 — 닉네임을 꾸밀 때 자주 쓰는 기호부터 통화, 수학, 클래식 DOS 기호까지. 텐키(숫자 패드)가 없어도 괜찮아요, 모든 기호는 클릭 한 번으로 바로 복사할 수 있습니다.

알트 코드는 윈도우에서 Alt 키를 누른 채 숫자 패드로 번호를 입력해 특수문자를 입력하는 방법입니다 — Alt+0169는 ©를, Alt+3은 ♥를 만듭니다. 한글은 Alt 코드로 입력할 수 없지만(한글은 자모 조합 방식이라 별도의 유니코드 폰트 변환도 적용되지 않습니다), 이 페이지의 기호들은 게임 닉네임이나 SNS 프로필을 꾸밀 때 그대로 붙여 쓸 수 있습니다. 아래에는 먼저 닉네임 꾸미기에 자주 쓰이는 기호를 모았고, 그다음에 통화, 수학, 악센트 문자, 문장부호, 클래식 DOS 기호까지 전체 목록을 정리했습니다. 숫자 패드가 없다면? 이 페이지의 모든 기호는 클릭 한 번으로 복사할 수 있어 노트북, 맥, 휴대폰에서도 그대로 사용할 수 있습니다.

닉네임 꾸미기

닉네임 & 프로필 꾸미기에 좋은 기호

게임 닉네임이나 SNS 프로필을 꾸밀 때 특히 자주 쓰이는 기호만 먼저 모았습니다. 이 기호들은 아래 '자주 쓰는 기호', '문장부호', '클래식 DOS' 카테고리에도 각자의 알트 코드와 함께 다시 나옵니다 — 여기서는 꾸미기 용도로 한 번 더 모아 보여드립니다.

Alt+3 — 하트 (이름 앞뒤 장식용)
Alt+0171 — 왼쪽 프레임 (이름 감싸기)
Alt+0187 — 오른쪽 프레임 (이름 감싸기)
Alt+0149 — 구분점 (이름·태그 구분용)
Alt+16 — 화살표 포인터 (접두사 장식)
Alt+1 — 웃는 얼굴
Alt+13 — 음표 (음악·방송 닉네임용)

더 다양한 장식용 기호와 조합, 프레임이 필요하다면 디스코드 특수문자 모음도 참고해 보세요 — 닉네임과 서버 이름 꾸미기에 특화된 기호들을 정리해 두었습니다.

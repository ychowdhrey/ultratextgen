How Embedding Works

CopyOne iframe tag

Every widget page above has a ready-made embed code block. Copy it — there's nothing to configure.

PasteAnywhere in your HTML

Drop the iframe into a post, page, or sidebar. It's responsive from 320px to full width and loads its own CSS/JS, so it won't clash with your site.

Keep the linkWhat keeps it free

Each widget carries a small attribution link back to UltraTextGen. Leaving it visible is what keeps these tools free for everyone to embed.

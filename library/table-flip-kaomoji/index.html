Copy and paste table flip kaomoji — also known as table flip ASCII or flip table text — for the moments when you just have to flip the table. Click any face to copy it instantly.

Table flip kaomoji (also called table flip ASCII, table flip emoji, or rage quit ASCII) is the (╯°□°）╯︵ ┻━┻ gesture — a person hurling a table, written entirely in Unicode text. It's plain text, not an image, so it pastes cleanly into chats, comments, bios, and captions on any platform. Whatever you call it — table flip kaomoji, table flip ASCII, or flip table text — every piece below is free to copy and paste, plus the calmer ┬─┬ ノ( ゜-゜ノ) for putting the table back.

Lenny Face

Copy and paste the classic Lenny face ( ͡° ͜ʖ ͡°) and every variant — winking, happy, flexing, and gun-toting Lennys. Click any face to copy it instantly.

The Lenny face ( ͡° ͜ʖ ͡°) is a suggestive, knowing text face built from Unicode combining marks — the ͡ tilde arches the brows and the ͜ mark forms the smirk. Because a Lenny face is plain Unicode text, it pastes cleanly into Discord, chat, comments, bios, and usernames with no image needed.

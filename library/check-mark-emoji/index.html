Check Mark Emoji & Kaomoji

Every check mark from the green ✅ button to a plain ✓ glyph, plus cross marks, approval gestures, and ready-made done combos. Click any symbol to copy it instantly.

The check mark emoji ✅ is the colorful, task-done button you tap to mark something complete — distinct from the plain Unicode check ✓, which is a flat black glyph that blends into surrounding text. This page gathers the full ✅ ✔️ ☑️ emoji family, the contrasting cross and X marks (❌ ✖️ 🚫) people search alongside them, approval gestures like 👍 and 💯, and one-click combo sets for to-do lists, chats, and status updates. It also includes a row of plain text check marks (✓ ✗ ☒) for spreadsheets and documents where a simple glyph reads better than an emoji. If you want the bare Unicode checkmark character on its own — codepoints, history, and confusable neighbors — see the checkmark symbols hub and single checkmark symbol page linked below.

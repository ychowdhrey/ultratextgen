PUBG Mobile and BGMI (Battlegrounds Mobile India — same game, India release) don't render text with your phone's full system font. They ship a small bundled font that covers only a few thousand of Unicode's 150,000+ characters, which is why a symbol that looks fine everywhere else can show up as a blank square — or get flatly rejected — in your in-game name. Every character on this page is a single-character pick from the families players actually report working: katakana and CJK marks, Javanese frame brackets, and simple stars. Names are capped at 14 characters total, so a frame counts against your limit before you've typed a single letter — copy what you need and build around it.

Why Some Symbols Fail

About PUBG & BGMI's Character Filter

PUBG Mobile and BGMI don't use your phone's system font to render display names — they use a font bundled inside the game client, which covers only a fraction of Unicode's 150,000+ characters. A symbol can be completely valid Unicode and still fail here, not because it's "banned," but because the game's own font simply has no glyph drawn for it — it shows up as a blank box, or the game rejects the whole name outright. This is a different failure mode than a content filter, and it's why a symbol that works perfectly on Instagram or Discord can break specifically in PUBG. Single-character picks from the Battle-Tested Symbols section above are chosen because they're inside that smaller, actually-supported set — multi-symbol combos and rarer Unicode blocks carry more risk.

FAQ

PUBG & BGMI name symbols, answered

Which symbols actually work in PUBG Mobile / BGMI names?

Single-character CJK, katakana, and common decorative marks — ツ, 彡, 乂, 亗, 々, ム, ★, ✦ — are the most reliable, because PUBG Mobile and BGMI render text using a limited in-app font, not your device's full system font. Every symbol in the Battle-Tested Symbols section above is chosen from that reliably-rendering set.

What's the difference between PUBG Mobile and BGMI names?

BGMI (Battlegrounds Mobile India) is Krafton's India-market release of PUBG Mobile — same engine, same client font, same name-field behavior. A symbol that works in one works in the other. The names differ by region/publisher, not by rendering rules, so this page serves both without a separate list.

Why does PUBG show "invalid characters" for a symbol that works elsewhere?

PUBG Mobile and BGMI bundle their own client font, which covers only a few thousand of Unicode's 150,000+ characters — a symbol can be perfectly valid Unicode and still render as a blank box or get rejected outright if it's outside that set. This is different from an emoji or a font-styling problem; it's specific to which glyphs the game's own font ships with. If a symbol fails, try a simpler single-character pick from the Battle-Tested section above before assuming your name is the problem.

How many characters can a PUBG Mobile or BGMI name have?

14 characters, including any symbols. A frame like ꧁ ꧂ already uses 2 of those 14 before you type a single letter, so heavier decoration eats into how much of your actual name fits — count your symbols, not just your letters.

Can I preview a name before spending a rename card?

The game itself will reject invalid characters at the confirmation screen before it charges a rename card, so nothing here can get spent on a name that outright fails. What it won't warn you about is a symbol that saves but renders as a blank square for other players on a different device — that's a display-side risk, not a validation error, which is exactly why this page sticks to the smaller set of symbols with the most consistent real-world reports of working.

Do PUBG name symbols work the same on Android and iOS?

Mostly, since both platforms use the game's own bundled font rather than the device's system font — but player reports of edge-case differences (a rarer symbol rendering on one OS and not the other) show up often enough that it's worth treating as a real possibility, not a myth. Single-character picks from the Battle-Tested section are the safest bet across both.

# UltraTextGen

UltraTextGen est un générateur de texte Unicode rapide et épuré, conçu pour les personnes qui ne veulent pas perdre de temps.

- Pas de pages lourdes.
- Pas de chargements inutiles.
- Pas de distractions.

Tapez votre texte, copiez-le, et passez à la suite.


## Pourquoi UltraTextGen

La plupart des outils de texte stylisé sont lents, encombrés et surchargés d'effets que vous n'utiliserez jamais.

UltraTextGen est l'inverse.

Chargement instantané  
Fonctionne entièrement dans le navigateur  
Aucune inscription, aucune pop-up  
Rien entre vous et le bouton copier

Il est conçu pour faire gagner du temps, pas pour en consommer.


## Ce Qu'il Fait

**Du texte stylisé que vous pouvez coller partout.** UltraTextGen convertit le
texte normal en styles basés sur Unicode — 114 au total — qui fonctionnent sur
les réseaux sociaux et les messageries. Le résultat est du vrai texte, pas une
image : il se copie, se colle et survit partout où vous le mettez.

**Des pseudos décorés pour les jeux et les profils.** Une couche d'ornement
compose cadres, couronnes et séparateurs autour d'un nom, et un moteur de règles
par jeu vérifie le résultat face à la limite de caractères que le jeu appliquera
réellement — avant de dépenser un changement de pseudo.

**Des rendus imprimables et visuels, quand les caractères ne suffisent pas.**
Fiches d'écriture en lettres bulles et en cursive, coloriages, texte courbé et
en arc, lettrage de tatouage. Ces éléments sont générés en SVG/PNG dans votre
navigateur et constituent le prolongement — pour tracer, colorier, imprimer —
jamais la réponse par défaut.

Tout cela fonctionne côté client. Rien n'est généré sur un serveur, et aucun
fichier de police n'est téléchargé pour que cela fonctionne.


## Pour Qui

Créateurs mettant à jour bios et légendes  
Community managers testant des variantes  
Communautés Discord et gaming  
Toute personne cherchant une emphase visuelle sans friction

Si la rapidité compte, cet outil est fait pour vous.


## Conçu Pour La Vitesse

UltraTextGen est volontairement léger.

- Aucun framework
- Aucun bundler
- Aucune dépendance côté navigateur
- Aucune animation superflue

Tout est conçu pour charger vite et rester réactif, même sur connexion lente.


## Philosophie De Conception

- Rapide plutôt que sophistiqué
- Clair plutôt que malin
- Utile plutôt qu'impressionnant

Si quelque chose n'aide pas l'utilisateur à aller plus vite, cela ne sort pas.

## Structure Du Projet

```
ultratextgen/
├── index.html               # Page d'accueil
├── style.css                # Feuille de style globale
├── script.js                # Logique d'interface — saisie, grille, copie, ornements
├── styles.js                # Registre des styles Unicode (114 styles)
├── renderer.js              # Moteur de rendu — dispatch selon style.type
├── header.js                # Injecteur de navigation partagée
├── sitemap.xml              # Généré automatiquement — ne jamais modifier à la main
├── _redirects, _headers     # Configuration Cloudflare Pages
├── _routes.json             # Routage Pages Functions (seul `/` en invoque une)
├── functions/               # Middleware Cloudflare Pages
│
├── js/                      # Modules de fonctionnalités, un dossier chacun
│   ├── flair/               #   packs de décoration de pseudos
│   ├── gamename/            #   règles de pseudo par jeu + vérificateur
│   ├── counter/             #   compteur de caractères (avec tests)
│   ├── printables/          #   moteur de fiches imprimables
│   ├── curved/  tattoo/     #   modes de sortie SVG/PNG
│   ├── vertical/  kaomoji/  #   …et une vingtaine d'autres
│
├── category/  usecase/      # Piliers de contenu (voir « Ce que contient le site »)
├── guide/     answers/
├── library/   symbol/
├── updates/   embed/
│
├── <lang>/                  # 30 arborescences localisées (de/, es/, ja/, …)
│
├── discord/  instagram/     # Pages plateformes
├── linkedin/ tiktok/  …
│
├── data/                    # Registres et référentiels lus par l'outillage
├── docs/                    # Documentation technique et de processus
└── scripts/                 # Scripts de build, validation et génération
```

`CLAUDE.md` à la racine du dépôt est le guide technique complet — règles de
contenu, processus de localisation, contrôles de validation et conventions.


## Pile Technique

| Couche | Technologie |
|---|---|
| Frontend | HTML5, CSS3, JavaScript natif (ES6+) — aucun framework, aucun bundler |
| Rendu visuel | Canvas/SVG natifs, générés côté client |
| Outillage de build | Node.js (sitemap, validateurs), Python (génération d'assets) |
| CI/CD | GitHub Actions |
| Hébergement | Cloudflare Pages + Pages Functions |

Le frontend n'a aucune étape de build. Node et Python ne servent qu'à
l'outillage exécuté avant le déploiement, jamais dans le navigateur.


## Développement

```bash
npm install            # Outillage de build uniquement — rien n'atteint le navigateur

npx serve .            # Servir en local ; ou : python3 -m http.server 8080
npm run prebuild       # Régénérer sitemap.xml
npm run sync-readme    # Actualiser les blocs générés de ce fichier
```

Il n'y a aucune étape de build pour le frontend — ouvrez `index.html`
directement, ou servez le dossier avec n'importe quel serveur de fichiers
statiques.

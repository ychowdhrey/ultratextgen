# UltraTextGen

UltraTextGen — быстрый и аккуратный генератор Unicode-текста для тех, кто не хочет тратить время впустую.

- Никаких тяжёлых страниц.
- Никаких лишних загрузок.
- Никаких отвлечений.

Введите текст, скопируйте его и идите дальше.


## Почему UltraTextGen

Большинство генераторов «красивого текста» работают медленно, перегружены интерфейсом и завалены эффектами, которые вам никогда не понадобятся.

UltraTextGen — противоположность этому.

Загружается мгновенно  
Работает целиком в браузере  
Без регистрации и всплывающих окон  
Ничего между вами и кнопкой «копировать»

Он создан, чтобы экономить время, а не расходовать его.


## Что Он Делает

**Стилизованный текст, который можно вставить куда угодно.** UltraTextGen
превращает обычный текст в стили на основе Unicode — их 114 — работающие в
соцсетях и мессенджерах. На выходе настоящий текст, а не картинка: он
копируется, вставляется и сохраняется везде, куда вы его помещаете.

**Оформленные ники для игр и профилей.** Слой оформления собирает вокруг имени
рамки, короны и разделители, а движок правил для каждой игры сверяет результат
с тем лимитом символов, который игра действительно применит — до того, как вы
потратите смену ника.

**Печатный и графический вывод, когда одних символов мало.** Прописи
пузырьковыми и рукописными буквами, раскраски, текст по дуге и по кривой,
леттеринг для татуировок. Всё это генерируется как SVG/PNG прямо в браузере и
служит следующим шагом там, где копирования недостаточно — обвести, раскрасить,
распечатать — но никогда не ответом по умолчанию.

Всё перечисленное работает на стороне клиента. Ничего не генерируется на
сервере, и никакие файлы шрифтов для этого не загружаются.

## Структура Проекта

```
ultratextgen/
├── index.html               # Главная страница
├── style.css                # Глобальные стили
├── script.js                # Логика интерфейса — ввод, сетка вывода, копирование
├── styles.js                # Реестр Unicode-стилей (114 стилей)
├── renderer.js              # Движок рендеринга — ветвление по style.type
├── header.js                # Инжектор общей навигации
├── sitemap.xml              # Генерируется автоматически — не править вручную
├── _redirects, _headers     # Конфигурация Cloudflare Pages
├── _routes.json             # Маршрутизация Pages Functions (вызывает только `/`)
├── functions/               # Middleware Cloudflare Pages
│
├── js/                      # Модули функций, по каталогу на каждый
│   ├── flair/               #   наборы оформления ников
│   ├── gamename/            #   правила ников по играм + проверка
│   ├── counter/             #   счётчик символов (с тестами)
│   ├── printables/          #   движок печатных листов
│   ├── curved/  tattoo/     #   режимы вывода SVG/PNG
│   ├── vertical/  kaomoji/  #   …и ещё около 20
│
├── category/  usecase/      # Контентные разделы (см. «Что есть на сайте»)
├── guide/     answers/
├── library/   symbol/
├── updates/   embed/
│
├── <lang>/                  # 30 локализованных деревьев сайта (de/, es/, ja/, …)
│
├── discord/  instagram/     # Страницы платформ
├── linkedin/ tiktok/  …
│
├── data/                    # Реестры и справочники, которые читает оснастка
├── docs/                    # Техническая и процессная документация
└── scripts/                 # Скрипты сборки, валидации и генерации
```

`CLAUDE.md` в корне репозитория — полное руководство по разработке: правила
контента, процесс локализации, проверки валидации и соглашения.


## Технологии

| Слой | Технология |
|---|---|
| Фронтенд | HTML5, CSS3, чистый JavaScript (ES6+) — без фреймворков и сборщиков |
| Графический вывод | Нативные Canvas/SVG, рендеринг на стороне клиента |
| Инструменты сборки | Node.js (карта сайта, валидаторы), Python (генерация ассетов) |
| CI/CD | GitHub Actions |
| Хостинг | Cloudflare Pages + Pages Functions |

У фронтенда нет шага сборки. Node и Python используются только в оснастке,
которая работает до деплоя, и никогда в браузере.


## Разработка

```bash
npm install            # Только инструменты сборки — в браузер ничего не попадает

npx serve .            # Локальный сервер; или: python3 -m http.server 8080
npm run prebuild       # Пересобрать sitemap.xml
npm run sync-readme    # Обновить генерируемые блоки в этом файле
```

Для фронтенда шага сборки нет — откройте `index.html` напрямую или отдайте
каталог любым статическим файловым сервером.

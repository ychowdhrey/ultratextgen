🎮 Saan Gumagana ang Font sa Discord

Ang name mo, ang server name, ang channels at roles — aling field ang tumatanggap ng Unicode, at alin ang tumatanggi.

Ang field-by-field na permission map: kung ano ang tinatanggap ng bawat area, bakit lumalabas ang "invalid username," ang bitag sa channels (sapilitang lowercase), at kung saan talaga gumagana ang Markdown.

🛡️ I-istayl ang Discord Name nang Hindi Ma-filter

Ang "gumagana" ay hindi "safe": pwedeng bumagsak ang styled name sa member list, sa @mention, o sa impersonation filter.

Ang tatlong filter na dapat pasahan, bakit mas mabilis na-moderate ang Zalgo kaysa ibang style, at kung paano panatilihing readable ang name para sa screen readers.

🧩 Discord Text Formatting, Nilinaw

Hindi ito problema sa "fonts" — tatlong magkaibang system ito: Markdown, Unicode characters, Nitro styles.

Pag alam mo na kung aling field ang gumagamit ng aling system, sinasagot ng bawat "bakit ayaw gumana?" ang sarili nito.

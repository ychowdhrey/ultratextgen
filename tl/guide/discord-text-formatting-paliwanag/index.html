Discord Text Formatting, Nilinaw

Hindi ka may problema sa "fonts" — may problema ka sa tatlong system. Gumagamit ang Discord ng Markdown, Unicode characters, at Nitro styles para sa magkakaibang trabaho. Pag alam mo na kung aling field ang gumagamit ng alin, sasagutin ng bawat "bakit hindi ito gumagana?" ang sarili nito.

Platform Mastery ⏱ 8 min basahin Ang 3-System na Modelo

Mga Dapat Tandaan

  • May tatlong magkahiwalay na text system ang Discord: Markdown (mensahe), Unicode "fonts" (mga pangalan kahit saan), at Nitro (bayad na display-name styles).
  • Ang Markdown tulad ng **bold** ay nagre-render lang sa mensahe — hindi ito gumagana sa username, nickname, o server/channel names.
  • Gumagana ang Unicode "fonts" sa bawat name field pero pwedeng lumabas na boxes sa ilang device at sumira sa screen readers.
  • Nagdadagdag ang Nitro ng tunay na kulay at effects sa display name mo — pero sa loob ng server, ang role color mo ang nananalo at ang font lang ang lumalabas.
Ang Bagong Pananaw

Hindi Ito Fonts — Tatlong Magkaibang System Ito

Halos lahat ng "bakit ayaw gumana ng text ko" na tanong sa Discord ay galing sa paghahalo ng tatlong bagay na walang kinalaman sa isa't isa. Tinuturuan ka ng Discord ng Markdown sa chat, kaya inaakala mong ang parehong trick ang mag-i-istayl sa pangalan mo. Hindi — ibang system talaga ang pinapatakbo ng mga pangalan.

Narito ang buong larawan sa isang frame. Alamin kung aling system ang ginagamit ng bawat field at hindi ka na muling magugulat.

System 1

Markdown — para sa Mensahe

Ang Markdown ay ang formatting na inilalapat ng Discord kapag ipinapakita nito ang mensahe mo. Nagta-type ka ng mga symbol sa paligid ng mga salita mo at pinapalitan ito ng Discord ng tunay na styling.

  • **bold** → bold
  • *italic* → italic
  • ~~strikethrough~~ → strikethrough
  • __underline__ → underline
  • ||spoiler|| → nakatago hanggang i-click
  • > quote at `code`

Ito ang tamang paraan para i-format ang isang mensahe — nananatili itong tunay na text, kaya searchable at accessible. Ang catch ay ang dalawang mali na nagpapa-"hindi gumana" nito:

Hindi mag-bold

** text ** — kinakansela ito ng space sa loob ng asterisk. Gamitin ang **text**.

Hindi mag-bold

Sa loob ng `code block`, pinapatay ng backticks ang Markdown. Ilabas ang styling.

At ang pinakamalaki: walang ginagawa ang Markdown sa username, nickname, server name o channel name. Hindi mensahe ang mga iyon, kaya hindi kailanman pinapatakbo ng Discord ang Markdown sa mga ito.

System 2

Unicode "Fonts" — para sa mga Pangalan

Para i-istayl ang isang pangalan, hindi mo pwedeng hilingin sa Discord na mag-render ng kahit ano — kaya gumagamit ka ng characters na mukha nang styled. Ginagawa ng isang generator ang "Nova" na 𝗡𝗼𝘃𝗮 o 𝓝𝓸𝓿𝓪 gamit ang special na Unicode characters, at ipe-paste mo ang tapos nang resulta diretso sa field. Walang kailangang i-render, kaya nabubuhay ito kung saan hindi kaya ng Markdown.

Gumagana ito sa display name, server nickname, server at channel names, role names, bio mo, at mensahe. Iisang lugar lang ang naka-block dito:

Tinatanggihan ito ng @username. Ang unique handle mo (ang lowercase na kasunod ng @) ay tumatanggap lang ng a–z, 0–9, _ at . — para sa mentions, search at routing. Mag-paste ka ng fancy font doon at ayaw i-save ng Discord. I-istayl na lang ang display name mo.

Dalawang honest na paalala, parehong detalyado sa iba pang page: pwedeng lumabas na boxes ang Unicode names sa ilang device (lalo na sa mga lumang Android), at mahirap ito para sa screen readers. Pumili ng safe na style (bold, italic, small caps) at panatilihing malinis — maraming malalaking server ang nagmo-moderate ng mahirap basahin o zalgo na pangalan.

System 3

Nitro Display Name Styles — Bayad, at Mas Limitado sa Inaakala Mo

Ang bayad na Nitro tier ng Discord ay may Display Name Styles, isang feature na idinagdag noong huling bahagi ng 2025: tunay na font, kulay, at maging animated effects na inilalapat sa display name mo. Ganda ng itsura nito sa profile card mo. Pero may catch na nadi-discover ng mga tao sa mahirap na paraan:

Sa loob ng server, ang role color mo ang nag-o-override sa Nitro color, at tinatanggal ang effects — kaya kadalasang ang font lang ang nakikita ng ibang miyembro, hindi ang kulay o animation. Lumalabas ang buong effect pangunahin sa profile mo, hindi sa member list o chat.

Kaya ng free accounts na buksan ang menu at mag-preview ng style, pero Nitro-only ang pag-save nito — ang preview-tapos-paywall na iyon ang mismong dahilan kung bakit ngayon marami ang nagtatanong kung kailangan ba talaga ng Nitro para sa fonts. Patas na tanong iyon tungkol sa specific na feature na ito; hindi ito pagbabago sa Unicode styling, na libre pa rin kahit ano pa.

Kaya sulit ang Nitro kung gusto mo ng malinis na profile card at natatanging display font kahit saan. Hindi ito ang paraan para makapaglagay ng colored text sa isang usapan — ibang tool iyon (susunod na section).

Ang Tanong sa Kulay

Paano ang Colored Text sa Mensahe?

Ang colored text sa isang mensahe ay isang pang-apat at mas limitadong trick: ANSI code blocks. Ibinabalot mo ang text sa isang triple-backtick block na naka-tag na ansi at nagdadagdag ng escape codes para sa kulay. Maging malinaw sa mga limitasyon:

  • Walong fixed colors lang — walang custom hex.
  • Code-block lang — hindi nito makukulayan ang normal na pangungusap nang inline.
  • Hindi reliable sa mobile — madalas na plain text lang ang lumalabas para sa mga phone user.

Kapaki-pakinabang para sa warnings o logs ng desktop-first na server; hindi ito general styling tool. Kung nasa mobile ang kalahati ng mga miyembro mo, ipagpalagay nang hindi nila makikita ang kulay.

Mga Madalas Itanong

Kasi magkaibang system ang ginagamit nila. Sa chat, ang **bold** ay Markdown — nire-render ito ng Discord kapag ipinapakita ang mensahe mo. Ang mga pangalan (username, nickname, server, channel, role) ay hindi nagpapatakbo ng Markdown, kaya literal lang na lumalabas ang mga asterisk. Para i-istayl ang isang pangalan, kailangan mo ng Unicode "fonts" — special na characters na mukha nang bold — na diretsong ipe-paste sa field.

Hindi. Ang Unicode "fonts" ay libreng substitute characters na pwede mong i-paste kahit saan pinapayagan ang pangalan; gumagana ito para sa lahat pero pwedeng lumabas na boxes sa ilang device at sumira sa screen readers. Ang Nitro Display Name Styles ay bayad na feature na naglalagay ng tunay na font, kulay, at effects sa display name mo — pero hindi lumalabas ang kulay at effects sa loob ng mga server, kung saan ang role color mo ang nananalo; ang font lang ang dala-dala.

Gamit ang ANSI code blocks: ibalot ang text mo sa isang triple-backtick block na naka-tag na "ansi" at magdagdag ng escape codes para sa kulay. Walo lang ang fixed colors, gumagana lang sa loob ng code blocks, at hindi reliable sa mobile (madalas na plain text lang ang lumalabas). Para ito sa mensahe, hindi sa pangalan.

Dalawang karaniwang dahilan: may space sa pagitan ng asterisk at ng salita (hindi mag-bold ang ** text ** — ang **text** ang mag-bo-bold), o nasa loob ng code block ang text (pinapatay ng backticks ang Markdown). Tandaan din na sa mensahe lang gumagana ang Markdown, hindi kailanman sa mga pangalan.

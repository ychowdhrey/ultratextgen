Questions Fréquentes sur les Symboles Goth & Grunge

Existe-t-il un raccourci clavier pour ces symboles goth ?

Pour l'essentiel, non — et c'est bien la seule chose lumineuse ici. Deux exceptions héritées de l'ancienne table Windows : la dague † (Alt+0134) et la double dague ‡ (Alt+0135), à condition d'avoir un pavé numérique, absent de la plupart des portables. Les croix gothiques (♱), le pentagramme (⛧), le soleil noir 𖤐 et les emoji (💀 🕷) n'ont, eux, aucun code Alt : copie-les d'un clic depuis cette page, ou passe par le sélecteur d'emoji du système (Windows : touche Windows + point ; Mac : Cmd+Ctrl+Espace) pour les glyphes emoji.

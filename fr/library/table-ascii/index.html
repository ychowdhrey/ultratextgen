Table ASCII

Les caractères ASCII imprimables 33–126 avec leurs codes décimal, hexadécimal, binaire et octal. Cliquez sur un caractère pour le copier.

La table ASCII associe les 128 caractères de l’American Standard Code for Information Interchange aux nombres 0–127 — la base de tout encodage de texte moderne et les 128 premiers points de code d’Unicode. Cette référence couvre la plage imprimable (33–126), regroupée par type, chaque caractère étant étiqueté avec son code décimal, hexadécimal, binaire et octal. Les codes 0–31 sont des caractères de contrôle non imprimables (comme 10, le saut de ligne), et 32 correspond à l’espace.

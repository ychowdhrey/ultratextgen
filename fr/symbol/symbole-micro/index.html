Histoire

Pourquoi deux caractères identiques à l'œil coexistent

Le signe micro (µ, U+00B5) existe dans Unicode uniquement pour la rétrocompatibilité. Il a été hérité de l'ISO/IEC 8859-1 (Latin-1), l'encodage 8 bits antérieur à Unicode, encore ancré dans d'innombrables systèmes, polices et formats de fichiers hérités. La recommandation du Consortium Unicode est d'utiliser le mu grec minuscule (μ, U+03BC) comme caractère préféré pour le préfixe SI « micro » — µg, µm, µs — mais les logiciels doivent continuer à reconnaître U+00B5, car tant de textes existants l'emploient déjà.

Les deux caractères sont visuellement identiques dans presque toutes les polices, et la règle de normalisation NFKC d'Unicode replie automatiquement le signe micro sur le mu grec. C'est généralement invisible — jusqu'à ce que ça ne le soit plus : une recherche, une expression régulière, une comparaison de noms de fichiers ou une requête en base de données peut échouer silencieusement quand une chaîne utilise U+00B5 et l'autre U+03BC, car pour une comparaison au niveau des octets ce sont des caractères différents, même si aucun humain ne peut les distinguer à l'écran. Le piège est assez courant pour donner lieu à de vrais rapports de bugs : une pull request Home Assistant de 2025, par exemple, proposait de remplacer le signe micro par le mu grec dans les unités du projet, précisément pour éviter cette classe d'incohérence.

FAQ

Questions fréquentes

Le signe micro µ (U+00B5) représente le préfixe SI « micro » (un millionième). On l'emploie dans des unités comme µm (micron), µg (microgramme) et µs (microseconde). C'est un caractère hérité, conservé dans Unicode pour la compatibilité avec les anciens systèmes Latin-1 (ISO/IEC 8859-1).

Non — ils sont visuellement identiques mais Unicode leur attribue des points de code différents (U+00B5 pour le signe micro, U+03BC pour le mu grec). Cette différence peut silencieusement casser une recherche, une correspondance d'expression régulière ou une comparaison de chaînes, alors que rien ne paraît anormal à l'écran.

Les deux s'affichent correctement pour un lecteur humain, mais le Consortium Unicode recommande le mu grec (μ, U+03BC) pour les nouveaux textes, puisque la normalisation NFKC convertit déjà automatiquement le signe micro en mu grec. N'utilise le signe micro que pour rester compatible avec un système existant qui l'attend spécifiquement.

Sur Windows, maintiens la touche Alt et tape 0181 sur le pavé numérique (Alt+0181) pour le signe micro. Sur Mac, appuie sur Option+M. En HTML, utilise l'entité &micro; ou &#181; pour le signe micro, et &mu; ou &#956; pour le mu grec.

Le formatage de texte sur Discord, décodé

Ton problème, ce n'est pas les «polices» — c'est qu'il y a trois systèmes. Discord utilise le Markdown, les caractères Unicode et les styles Nitro pour des usages complètement différents. Une fois que tu sais quel champ utilise quel système, chaque «pourquoi ça ne marche pas ?» trouve sa réponse tout seul.

Maîtrise Discord ⏱ 8 min de lecture Le modèle des 3 systèmes

À retenir

  • Discord a trois systèmes de texte indépendants : le Markdown (messages), les «polices» Unicode (noms, partout) et le Nitro (styles de nom d'affichage payants).
  • Le Markdown comme **gras** ne s'affiche que dans les messages — jamais dans les noms d'utilisateur, les pseudos ni les noms de serveur ou de salon.
  • Les «polices» Unicode marchent dans tous les champs de nom, mais peuvent s'afficher en carrés sur certains appareils et gênent les lecteurs d'écran.
  • Le Nitro ajoute une vraie couleur et des effets à ton nom d'affichage — mais dans un serveur, la couleur de ton rôle l'emporte et seule la police reste.
Le cadre

Ce ne sont pas des polices — ce sont trois systèmes différents

Presque toutes les questions «pourquoi mon texte ne marche pas» sur Discord viennent d'une confusion entre trois choses qui n'ont rien à voir. Discord t'apprend le Markdown dans le chat, alors tu supposes que la même astuce va styliser ton nom. Non — les noms fonctionnent avec un tout autre système.

Voici tout le territoire en un seul schéma. Apprends quel système utilise chaque champ et tu ne seras plus jamais pris au dépourvu.

Système 1

Le Markdown — pour les messages

Le Markdown, c'est la mise en forme que Discord applique quand il affiche ton message. Tu tapes des symboles autour de tes mots et Discord les remplace par un vrai style.

  • **gras** → gras
  • *italique* → italique
  • ~~barré~~ → barré
  • __souligné__ → souligné
  • ||spoiler|| → masqué jusqu'au clic
  • > citation et `code`

C'est la bonne façon de mettre en forme un message — ça reste du vrai texte, donc c'est cherchable et accessible. Le piège, ce sont les deux erreurs qui font que «ça ne marche pas» :

Pas de gras

** texte ** — une espace à l'intérieur des astérisques annule tout. Utilise **texte**.

Pas de gras

Dans un `bloc de code`, les accents graves désactivent le Markdown. Sors le style du bloc.

Et le plus important : le Markdown ne fait rien dans un nom d'utilisateur, un pseudo, un nom de serveur ou de salon. Ce ne sont pas des messages, donc Discord n'y applique jamais le Markdown.

Système 2

Les «polices» Unicode — pour les noms

Pour styliser un nom, tu ne peux rien demander à Discord d'afficher — alors tu utilises des caractères qui sont déjà stylisés. Un générateur transforme «Nova» en 𝗡𝗼𝘃𝗮 ou 𝓝𝓸𝓿𝓪 à l'aide de caractères Unicode spéciaux, et tu colles le résultat directement dans le champ. Aucun rendu nécessaire, donc ça survit là où le Markdown échoue.

Ça marche dans ton nom d'affichage, ton pseudo de serveur, les noms de serveur et de salon, les noms de rôle, ta bio et les messages. Il y a exactement un seul endroit où c'est bloqué :

Le @nom d'utilisateur le refuse. Ton identifiant unique (celui en minuscules après le @) n'accepte que a–z, 0–9, _ et . — pour les mentions, la recherche et le routage. Colle une police fantaisie ici et Discord refuse de l'enregistrer. Stylise plutôt ton nom d'affichage.

Deux réserves honnêtes : les noms Unicode peuvent s'afficher en carrés sur certains appareils (surtout les vieux Android) et ils sont difficiles à lire pour les lecteurs d'écran. Choisis un style sûr (gras, italique, small caps) et garde-le sobre — beaucoup de gros serveurs modèrent les noms illisibles ou en zalgo.

Système 3

Les styles de nom Nitro — payants, et plus limités qu'on ne croit

L'abonnement payant Nitro de Discord propose les Styles de nom d'affichage, une fonction ajoutée fin 2025 : une vraie police, une couleur et même des effets animés appliqués à ton nom d'affichage. Ça rend très bien sur ta carte de profil. Mais il y a un piège que les gens découvrent à leurs dépens :

Dans un serveur, la couleur de ton rôle l'emporte sur la couleur Nitro, et les effets sautent — les autres membres ne voient donc en général que la police, pas la couleur ni l'animation. L'effet complet apparaît surtout sur ton profil, pas dans la liste des membres ni dans le chat.

Les comptes gratuits peuvent ouvrir le menu et prévisualiser un style, mais l'enregistrer est réservé au Nitro — c'est exactement cet «aperçu puis paywall» qui pousse tant de gens à se demander si le Nitro est carrément obligatoire pour les polices. C'est une question légitime sur cette fonction précise ; ça ne change rien au stylage Unicode, qui reste gratuit dans tous les cas.

Donc le Nitro vaut le coup si tu veux une carte de profil soignée et une police d'affichage distincte partout. Ce n'est pas le moyen d'obtenir du texte coloré dans une conversation — ça, c'est un autre outil (section suivante).

La question de la couleur

Et le texte coloré dans les messages ?

Le texte coloré dans un message, c'est une quatrième astuce, plus étroite : les blocs de code ANSI. Tu entoures ton texte d'un bloc à triples accents graves marqué ansi et tu ajoutes des codes d'échappement pour la couleur. Sois lucide sur les limites :

  • Seulement huit couleurs fixes — pas de code hex personnalisé.
  • Uniquement en bloc de code — impossible de colorer une phrase normale en ligne.
  • Peu fiable sur mobile — s'affiche souvent en texte brut pour les utilisateurs sur téléphone.

Utile pour les avertissements ou les logs d'un serveur orienté bureau ; ce n'est pas un outil de stylage général. Si la moitié de tes membres sont sur mobile, pars du principe qu'ils ne verront pas la couleur.

FAQ

Questions fréquentes

Parce qu'ils utilisent des systèmes différents. Dans le chat, **gras** c'est du Markdown — Discord l'interprète au moment d'afficher ton message. Les noms (nom d'utilisateur, pseudo, serveur, salon, rôle) n'exécutent pas le Markdown, donc les astérisques s'affichent littéralement. Pour styliser un nom, il te faut des «polices» Unicode — des caractères déjà en gras — collés directement dans le champ.

Non. Les «polices» Unicode sont des caractères de substitution gratuits que tu peux coller partout où un nom est autorisé ; elles marchent pour tout le monde mais peuvent s'afficher en carrés sur certains appareils et gênent les lecteurs d'écran. Les Styles de nom d'affichage Nitro sont une fonction payante qui applique une vraie police, une couleur et des effets à ton nom d'affichage — mais la couleur et les effets ne s'affichent pas dans les serveurs, où la couleur de ton rôle l'emporte ; seule la police est conservée.

Avec les blocs de code ANSI : entoure ton texte d'un bloc à triples accents graves marqué «ansi» et ajoute des codes d'échappement pour la couleur. C'est limité à huit couleurs fixes, ça ne marche que dans les blocs de code et c'est peu fiable sur mobile (souvent affiché en texte brut). C'est pour les messages, pas pour les noms.

Deux raisons courantes : il y a une espace entre les astérisques et le mot (** texte ** ne met pas en gras — **texte** oui), ou le texte est dans un bloc de code (les accents graves désactivent le Markdown). Souviens-toi aussi que le Markdown ne marche que dans les messages, jamais dans les noms.

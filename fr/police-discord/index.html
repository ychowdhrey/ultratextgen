Changer la police sur Discord : comment ça marche

Discord n'a aucun réglage «police d'écriture» — mais il accepte l'Unicode à peu près partout. Les styles de cette page sont de vraies lettres, dessinées autrement que celles du clavier. Quand tu copies, le style voyage dans le texte ; Discord l'affiche comme n'importe quel message. Et surtout : ça marche sans Nitro, parce que les caractères eux-mêmes font partie du standard Unicode, pas d'une fonction payante.

Exemple de nom d'affichage : ꧁ 𝗡𝗼𝘃𝗮 ꧂ · 𝔡𝔞𝔯𝔨 𝔰𝔬𝔲𝔩 · ᴀꜰᴋ ᴘʟᴀʏᴇʀ

Les étapes : tape en haut → choisis le style → «Copier» → dans Discord, colle où tu veux. L'Unicode passe dans le message du chat, le pseudo (nom d'affichage), la section «À propos» (bio), le nom de serveur ou de salon et le statut personnalisé. La seule zone verrouillée, c'est le nom d'utilisateur @ — on y revient plus bas. Pour styliser tout ton serveur — nom, salons et rôles, pas seulement ton pseudo —, suis le guide styliser ton pseudo et ton serveur Discord.

Markdown Discord ou police Unicode : quand utiliser quoi

Discord a son propre système de formatage, le Markdown, à ne pas confondre avec les polices Unicode. Les deux stylisent du texte, mais pas au même endroit ni de la même façon.

— Markdown (intégré, chat uniquement) : **texte** → gras, *texte* → italique, __texte__ → souligné, `texte` → code monospace, ||texte|| → spoiler. L'astérisque disparaît à l'envoi.
— Unicode (cette page, partout) : de vraies lettres stylées (𝗴𝗿𝗮𝘀, 𝔤𝔬𝔱𝔥𝔦𝔮𝔲𝔢, 𝓬𝓾𝓻𝓼𝓲𝓿𝓮) qui voyagent dans le pseudo, la bio, le nom de serveur et le statut.

La règle : utilise le Markdown pour mettre en forme un message dans le chat (gras, code, spoiler), et l'Unicode pour styliser un nom d'affichage ou une bio, là où le Markdown ne fonctionne pas. Point important sur l'identité : le nom d'utilisateur (@) est restreint — il n'accepte que les lettres minuscules a–z, les chiffres, le tiret bas (_) et le point (.), donc ni Markdown ni police stylée. Réserve les polices au nom d'affichage, qui, lui, accepte tout.

Où la police Discord fonctionne — et où elle ne fonctionne pas

La règle est simple : les champs de texte prennent le style, le nom d'utilisateur non.

✔ Ça marche : messages du chat, nom d'affichage, pseudo de serveur, «À propos» (bio), nom de serveur et de salon, statut personnalisé, embeds de bot
✘ Ça ne marche pas : nom d'utilisateur (@) — que des lettres minuscules a–z, chiffres, tirets bas et points

Un aviso honnête sur la visibilité : le gras et l'italique s'affichent le plus fidèlement sur tous les appareils ; les styles très rares peuvent sortir en carrés (▯) sur un vieux téléphone ou un appareil qui n'a pas la police correspondante. Ce n'est pas ton copier-coller qui bugue, c'est l'appareil d'en face. Pour un pseudo lisible chez tout le monde, reste sur le gras, l'italique, la cursive ou le gothique.

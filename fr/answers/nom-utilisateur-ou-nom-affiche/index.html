Nom d'Utilisateur ou Nom Affiché — Où Fonctionnent les Polices Stylées ?

Tu colles un nom stylé, il est rejeté comme « caractères invalides », et tu penses que les polices stylées ne marchent pas ici. Si, elles marchent — tu les as juste mises dans le mauvais champ.

Réponse courte

Le Unicode stylé va dans ton nom affiché / pseudo / bio, pas dans ton @nom d'utilisateur (handle). Le handle est l'adresse que les gens utilisent pour te trouver et te mentionner, donc presque toutes les applis le limitent à l'ASCII simple — lettres minuscules, chiffres, points et underscores — et rejettent les polices collées avec une erreur « caractères invalides ». Le nom affiché est une étiquette, donc il accepte le Unicode stylé. Mets le style dans le champ du nom affiché et laisse le handle simple.

@nom d'utilisateur = ASCII simple (rejette les polices). Nom affiché / bio = Unicode stylé (les accepte).
La règle

Deux champs, deux règles très différentes

Presque tous les profils ont deux champs de nom :

  • @nom d'utilisateur / handle — unique, utilisé dans ton URL et dans les mentions @. Limité aux lettres, chiffres, . et _. Colle une police stylée et tu obtiens « le nom d'utilisateur ne peut contenir que des lettres, des chiffres, des underscores et des points ».
  • Nom affiché / pseudo / bio — une étiquette lisible pour les humains, pas une adresse. Accepte le Unicode stylé, les emoji et les espaces.

Donc la solution pour « caractères invalides » est presque toujours : sortir le texte stylé du handle et le mettre dans le nom affiché.

Par plateforme

Où va le texte stylé

Même schéma partout — stylise le bon champ, garde le handle simple :

  • Instagram / TikTok — handle simple ; stylise le Nom / Pseudo et la bio.
  • Discord — nom d'utilisateur simple ; stylise le nom affiché et le pseudo du serveur.
  • WhatsApp — stylise le nom de profil et l'À propos (son nouveau @nom d'utilisateur reste simple).
  • X / YouTube / Telegram — handle simple ; stylise le nom affiché / nom de la chaîne / prénom.

Les pseudos de jeu suivent le même schéma — stylise le nom affiché et garde le tag simple. Pour les règles de caractères par jeu, voir les caractères autorisés dans les pseudos de jeu et pourquoi mon pseudo de jeu a été refusé.

Exceptions

Où le texte stylé ne fonctionne vraiment pas

Quelques champs rejettent le texte stylé même quand ce sont des noms affichés :

  • Facebook — le champ du vrai nom bloque les symboles, les majuscules inhabituelles et les scripts mixtes par politique (la bio et les publications sont acceptées).
  • Twitch — le nom affiché en latin ne peut que changer de casse, pas de police.
  • LinkedIn — le titre n'accepte plus le Unicode stylisé, et un nom stylé peut te rendre invisible pour la recherche des recruteurs. Voir le texte en gras est-il sûr sur LinkedIn.

Comment Renommer un Groupe WhatsApp, Instagram ou Discord

Copie ton nom stylé depuis le générateur ou les listes ci-dessus, puis :

WhatsApp : ouvre le groupe, touche le nom du groupe en haut, touche l'icône crayon/modifier à côté du nom, colle, puis touche la coche pour enregistrer.
Groupe de discussion Instagram/Messenger : ouvre la discussion, touche le nom en haut, touche Modifier le Nom, colle, puis confirme.
Discord (nom de serveur ou de salon) : ouvre les Paramètres du Serveur (ou clic droit sur un salon → Modifier le Salon), colle dans le champ du nom, puis enregistre.

Les trois stockent le nom en texte Unicode standard, donc le style reste exactement identique.

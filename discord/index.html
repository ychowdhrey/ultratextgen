Where to Use Fonts on Discord

Display Name (32 characters)

Your display name is the cosmetic name shown across all of Discord and fully supports Unicode. Generate a styled version, then paste it in User Settings > My Account > Profiles. Up to 32 characters; some decorative Unicode characters count as more than one — measure a styled name's real cost with the character counter.

Server Nickname (32 characters, per server)

Server nicknames override your display name in a specific server only. Right-click your avatar in any server and choose Edit Per-server Profile, then paste a styled name. You can run a different font in every server you're in.

About Me / Bio (190 characters)

Your Discord bio supports Unicode text up to roughly 190 characters. For a generator with a live 190-character counter and gaming-flavored About Me templates, visit the Discord Bio Font Generator, and add aesthetic decorations like ✦ ⊹ ⋆ from the Discord Symbols library. See also Stop the Scroll with Font Variation for mixing weights to build hierarchy.

Chat Messages

Paste any Unicode-styled text into channels, DMs, or group chats. The styled text appears exactly as copied for everyone on desktop and mobile — no Markdown needed.

Server, Channel & Role Names

Server owners and moderators can use styled text and symbols in server names, channel names (100-character limit), category names, and role names. Common pattern: a clean Unicode style for headline channels and a symbol prefix for sub-channels.

Usernames — Not Supported

Discord usernames (the @handle) only accept lowercase a–z, numbers 0–9, underscores, and periods — see Discord Allowed Characters for the full per-field rules. Use your display name instead — it supports all font styles and is what other users see in servers and DMs.

Make Small Text on Discord

In a chat message, use Discord's own subtext formatting — it's the right tool and needs no copy-paste. Start a new line with -# followed by a space, then your text. The whole line renders smaller and lighter, the way a caption or disclaimer reads.

-# this whole line shows as small subtext

Three things to know: it works only at the start of a line (not on a single word mid-sentence), it shrinks the entire line, and you need a space between -# and your text. It's ideal for captions, timestamps, disclaimers and asides — and it works on desktop and mobile.

Where -# can't reach — display names, nicknames, your bio, and channel or server names — Discord has no built-in formatting, so Unicode subscript or small caps characters are the way. Generate them above and paste them in; the styling lives in the characters themselves, so no Markdown is needed and they look the same for everyone.

Discord Display Name

Your username is your unique identifier (the @handle), used for friend requests and identity verification. It only allows lowercase letters, numbers, underscores, and periods. Your display name is the cosmetic name shown in servers and DMs — it supports uppercase, spaces, emojis, and Unicode font styles like bold, cursive, and gothic.
Display names support almost anything: uppercase and lowercase letters, spaces, special characters, emojis, Unicode font styles, and non-Latin characters — as long as the name follows Discord's Community Guidelines. You can use a font generator to create styled display names with bold, cursive, gothic, or decorated text.
Display names must be at least 1 character and at most 32 characters long. Note that some Unicode font characters may count as more than one character toward the limit.

Discord Username

Usernames only allow lowercase letters, numbers, underscores, and periods — no spaces, emojis, or Unicode fonts, and no two users can share one. Styling and decoration belong in your display name instead, which supports every font on this page. For the full character-limit and per-field rules, see Discord Allowed Characters.

Discord Nicknames

A server nickname is a name set within a specific Discord server. It overrides your display name in that server only. For example, if your display name is "Phibi" but your server nickname is "Wumpus", members of that server see "Wumpus". Server nicknames support Unicode characters, so you can use styled fonts in them.
Yes. Server nicknames accept Unicode characters just like display names. Generate a styled version of your name using the tool above and paste it as your server nickname. Server admins can also set styled nicknames for members.
A friend nickname is a name you assign to another user. It overrides their display name in your view only — no one else sees it. You can set a friend nickname by right-clicking on their profile avatar and selecting Add Friend Nickname.
The priority order from highest to lowest is: Friend nickname (if set by you for that user), then Server nickname (if set in that specific server), then Display name, then Username.

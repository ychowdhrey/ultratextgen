How to Rename a WhatsApp, Instagram, or Discord Group

Copy your styled name from the generator or the lists above, then:

WhatsApp: open the group, tap the group name at the top, tap the pencil/edit icon next to the name, paste, then tap the checkmark to save.
Instagram/Messenger group chat: open the chat, tap the chat name at the top, tap Edit Name, paste, then confirm.
Discord (server or channel name): open Server Settings (or right-click a channel → Edit Channel), paste into the name field, then save.

All three store the name as plain Unicode text, so the styling stays exactly as it appeared here.

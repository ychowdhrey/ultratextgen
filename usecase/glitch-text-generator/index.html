What is glitch text?

Glitch text is regular text stacked with Unicode combining marks — the accent-style characters that attach above, through, and below a letter. One mark is how é or ñ is built; pile on dozens per character and the word looks corrupted, cursed, and broken, bleeding into the lines around it. It is a pure visual effect — the letters underneath never change, so it is always safe to paste.

People call it a lot of things — glitch text, cursed text, hacked text, corrupted text — but it is all the same trick, first popularized as Zalgo in a 2004 web comic gag where wholesome strips were "corrupted" by an eldritch entity. Use it for horror posts, spooky captions, meme replies, and anywhere a broken-data look fits.

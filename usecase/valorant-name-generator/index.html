How to Change Your Riot ID in Valorant

Riot IDs are managed from your Riot account, not an in-game rename menu like Free Fire's Name Change Card:

1. Copy your name from the generator or the ready-made list above.
2. Open the Valorant client → your profile icon, or go to riotaccount.riotgames.com in a browser.
3. Find Riot ID / Edit Name.
4. Paste the name, choose a 3-5 character tag, and save — if that exact name#tag combination is still free.

Riot enforces a cooldown between Riot ID changes, so run your final choice through the Riot ID check above before you use it — it's the same check running live as you type, not a separate step.

Why Valorant Names Aren't Like Free Fire or Mobile Legends Names

Free Fire and Mobile Legends accept most Unicode ornaments — umbrella frames ꧁꧂, crowns ♛, katakana メ彡 — as long as the name stays under the character limit. Valorant's Riot ID is more moderated, and accounts of exactly what gets through are inconsistent: some players report elaborate styled names sticking for months, others see the same kind of character stripped or blocked after a client update. Nobody outside Riot can promise a fixed list of "safe" symbols will hold up indefinitely.

That's why this page runs a live check instead of only listing symbols. Under the hood, Valorant is flagged in our engine the same way Fortnite is — any non-plain-letter character (a styled font, an ornament, an emoji) gets marked for a second look, not just symbols. The check above is exactly that: it flags every character in your name that falls outside plain ASCII, so you know precisely what you're risking before you paste it into your actual Riot ID — not a guess based on someone else's name working last patch.

Emoji de Meteoro

Um meteoro riscando o céu, se separando da crise de identidade que o Cometa carrega há uma década — proposto para o Emoji 18.0, previsto para junto do Unicode 18.0 em setembro de 2026. Ainda é só rascunho: nenhuma fonte o renderiza ainda. Clique para copiar o código mesmo assim.

Meteor (🪋, U+1FA8B) é um emoji candidato proposto para o Emoji 18.0, o complemento de emoji do Unicode 18.0, com finalização prevista para setembro de 2026. Ele retrata uma bola de fogo riscando a atmosfera — e existe especificamente para corrigir uma divisão de renderização entre fabricantes que persegue o emoji Cometa (☄️) já existente desde sua estreia: algumas plataformas desenhavam o Cometa como uma bola de gelo azul e brilhante, enquanto outras o redesenharam como uma rocha incandescente em pleno impacto — dois conceitos genuinamente diferentes dividindo um único código. O próprio anúncio do Unicode foi direto: «desejar um sonho olhando para uma estrela e testemunhar um evento de nível de extinção são duas energias completamente diferentes». O Meteor assume o significado de bola de fogo, para que o Cometa possa se firmar num design consistente de gelo azul em toda parte. Como ainda é um rascunho, nenhum sistema operacional, teclado ou fonte o renderiza atualmente; espere uma caixa em branco ou um glifo substituto até o Emoji 18.0 ser aprovado e as plataformas lançarem suporte, provavelmente em algum momento de 2027.

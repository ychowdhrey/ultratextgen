Emoji de Rosto Rachado

Um rosto no meio de uma expressão, rachando sob pressão — proposto para o Emoji 18.0, previsto para junto do Unicode 18.0 em setembro de 2026. Ainda é só rascunho: não aprovado, e nenhuma fonte o renderiza ainda. Clique para copiar o código mesmo assim.

Cracking Face (🫫, U+1FAEB) é um emoji candidato proposto para o Emoji 18.0, o complemento de emoji do Unicode 18.0, com finalização prevista para setembro de 2026. Ele retrata um rosto no meio de uma expressão, com uma rachadura visível, lido pela maior parte da cobertura como tensão emocional ou «quebrando» ainda sorrindo — um encaixe perfeito para o meme geracional do «tô de boa», em que alguém parece composto por fora enquanto está sobrecarregado por dentro. Seu código tem uma história específica: o U+1FAEB era originalmente reservado para outro emoji proposto, «Face With Squinting Eyes» (rosto de olhos semicerrados), antes que o Grupo de Trabalho de Padrão e Pesquisa de Emoji do Unicode recomendasse substituí-lo por Cracking Face em janeiro de 2026. Até o momento desta publicação, a própria documentação do pipeline do Unicode ainda lista esse código sob o nome original, sinalizado como pendente de uma resolução de troca de nome — o que significa que até o nome «Cracking Face» ainda não está totalmente travado, apesar da ampla cobertura de imprensa que já o usa. Como ainda é um rascunho, nenhum sistema operacional, teclado ou fonte o renderiza atualmente; espere uma caixa em branco ou um glifo substituto até o Emoji 18.0 ser aprovado e as plataformas lançarem suporte, provavelmente em algum momento de 2027.

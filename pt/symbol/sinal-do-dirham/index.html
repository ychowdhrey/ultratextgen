Sinal do Dirham

O novo símbolo monetário do Banco Central dos Emirados Árabes Unidos, com o código U+20C3, congelado para publicação no Unicode 18.0 — mais consolidado que os emojis rascunho deste mesmo lançamento, mas ainda impossível de digitar em qualquer teclado.

O sinal do dirham (⃃, U+20C3) é o novo símbolo monetário do Banco Central dos Emirados Árabes Unidos, revelado em março de 2025 junto com uma marca complementar para o dirham digital. Foi submetido ao Consórcio Unicode para codificação, aprovado e publicado na versão beta pública do Unicode 18.0 em 27 de maio de 2026, ao lado dos sinais do rial omanense e do rufiyaa maldivo. Até o momento desta publicação, carrega status «white» na própria documentação do pipeline do Unicode — o que significa que está congelado para publicação, faltando apenas a aprovação da ISO, um estado na verdade mais consolidado do que os emojis candidatos deste mesmo lançamento (vários dos quais ainda carregam sinalizações pendentes de mudança de nome). O próprio Unicode 18.0 deve ser publicado como definitivo em setembro de 2026. Só a publicação, porém, não coloca o símbolo num teclado: nenhum sistema operacional, fonte ou método de entrada oferece suporte nativo no momento, e a própria recomendação do guia de estilo do Banco Central dos EAU (a tecla numérica 6) é só isso, uma recomendação, até que os fabricantes de dispositivos ajam. Enquanto isso, desenvolvedores já construíram ferramentas reais em torno do código confirmado: um pacote npm de código aberto, uma web font e componentes para CSS, React, Vue, Angular e Svelte (publicados como «dirham» no npm e no GitHub) permitem codificar o caractere correto hoje, por meio de uma camada de renderização temporária, pensada para ser descartada assim que o suporte nativo do sistema operacional chegar.

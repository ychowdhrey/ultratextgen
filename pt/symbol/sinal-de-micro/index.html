História

Por que existem dois caracteres idênticos a olho nu

O sinal de micro (µ, U+00B5) existe no Unicode apenas por retrocompatibilidade. Ele foi herdado do ISO/IEC 8859-1 (Latin-1), a codificação de 8 bits anterior ao Unicode, ainda enraizada em incontáveis sistemas, fontes e formatos de arquivo legados. A orientação do Consórcio Unicode é usar o mu grego minúsculo (μ, U+03BC) como caractere preferido para o prefixo SI «micro» — µg, µm, µs —, mas os programas devem continuar reconhecendo o U+00B5, porque tantos textos existentes já o usam.

Os dois caracteres são visualmente idênticos em quase toda fonte, e a regra de normalização NFKC do Unicode reduz automaticamente o sinal de micro ao mu grego. Isso costuma ser invisível — até que deixa de ser: uma busca, uma expressão regular, uma comparação de nomes de arquivo ou uma consulta a banco de dados pode falhar silenciosamente quando um texto usa U+00B5 e o outro usa U+03BC, porque, para uma comparação em nível de bytes, são caracteres diferentes, mesmo que nenhum humano os distinga na tela. É uma pegadinha comum o bastante para gerar relatos de bug reais — um pull request do Home Assistant, de 2025, por exemplo, propôs trocar o sinal de micro pelo mu grego nas unidades do projeto justamente para evitar essa classe de incompatibilidade.

Perguntas frequentes

Perguntas frequentes sobre o sinal de micro

O sinal de micro µ (U+00B5) representa o prefixo SI «micro» (um milionésimo). É usado em unidades como µm (mícron), µg (micrograma) e µs (microssegundo). É um caractere herdado, mantido no Unicode por compatibilidade com os antigos sistemas Latin-1 (ISO/IEC 8859-1).

Não — eles são visualmente idênticos, mas o Unicode lhes dá pontos de código diferentes (U+00B5 para o sinal de micro, U+03BC para o mu grego). Essa diferença pode quebrar silenciosamente uma busca, uma correspondência de expressão regular ou uma comparação de textos, mesmo que nada pareça errado na tela.

Os dois são exibidos corretamente para um leitor humano, mas o Consórcio Unicode recomenda o mu grego (μ, U+03BC) para textos novos, já que a normalização NFKC converte automaticamente o sinal de micro para ele. Use o sinal de micro apenas para manter compatibilidade com um sistema existente que o exija especificamente.

No Windows, segure a tecla Alt e digite 0181 no teclado numérico (Alt+0181) para o sinal de micro. No Mac, pressione Option+M. Em HTML, use a entidade &micro; ou &#181; para o sinal de micro, e &mu; ou &#956; para o mu grego.

Fontes para Discord: como funciona

As fontes para Discord deste site não são fonte instalada nem imagem: são caracteres Unicode — letras de verdade, iguais às do teclado, só que com outro desenho (𝗔, 𝘈, 𝓐, 𝔄). Como o Discord aceita Unicode em quase todo campo de texto, a letra estilosa gruda direto no seu nome de exibição, no apelido de servidor, no «Sobre mim», no nome de canal e até nas mensagens — sem precisar de Nitro, plugin ou app.

Exemplo: «gabriel» → 𝗴𝗮𝗯𝗿𝗶𝗲𝗹 (negrito), 𝑔𝑎𝑏𝑟𝑖𝑒𝑙 (itálico), 𝓰𝓪𝓫𝓻𝓲𝓮𝓵 (cursiva), 𝔤𝔞𝔟𝔯𝔦𝔢𝔩 (gótica), ⓖⓐⓑⓡⓘⓔⓛ (bubble), ɢᴀʙʀɪᴇʟ (small caps)

Usar é rápido: escreve o nome na caixa lá em cima, o gerador mostra o mesmo texto em várias letras para Discord, você clica em «Copiar» e cola dentro do app. Quer só as letras cruas do alfabeto? Elas estão logo abaixo. Se preferir explorar mais estilos, a página de letras diferentes tem o gerador completo.

Fontes para nick e «Sobre mim» do Discord

O jeito mais rápido de destacar o perfil é aplicar uma fonte no nome de exibição e outra combinação no «Sobre mim» (a bio do perfil). O Discord aceita Unicode nos dois — e ainda dá pra ter um apelido diferente por servidor, então você usa a gótica num servidor de jogo e a cursiva num servidor de amigos, tudo com o mesmo nome.

Como colar:

— Nome de exibição: Configurações de Usuário › Perfil › edita o nome de exibição e cola a fonte
— Apelido de servidor: clica com o botão direito no seu nome dentro do servidor › Editar Perfil do Servidor › cola o apelido estiloso
— «Sobre mim»: Configurações de Usuário › Perfil › campo «Sobre mim» › cola o texto
— Nome de canal: se você é admin, edita o canal e cola a fonte no nome

Uma dica de quem monta perfil: usa a letra estilosa só no nome e deixa o resto do «Sobre mim» em texto normal — o contraste é o que dá destaque. Quando tudo é estilizado, nada chama atenção. Pra símbolos e brilhos avulsos que enfeitam a bio, veja a página de símbolos para copiar.

Markdown do Discord vs fontes Unicode — quando usar cada um

O Discord tem dois jeitos de mexer no texto, e é bom não confundir. Um é a formatação Markdown nativa; o outro são as fontes Unicode deste site. Servem pra coisas diferentes.

— Markdown (nativo): **negrito** → negrito, *itálico* → itálico, __sublinhado__, ~~riscado~~, `código`. Só funciona dentro das mensagens do chat e some se você tentar no nome ou na bio.
— Fontes Unicode (este site): 𝗻𝗲𝗴𝗿𝗶𝘁𝗼, 𝓬𝓾𝓻𝓼𝓲𝓿𝓪, 𝔤𝔬́𝔱𝔦𝔠𝔞. É o próprio caractere estilizado, então funciona em todo lugar — nick, «Sobre mim», nome de canal, status e chat.

Regra prática: pra formatar uma mensagem normal (deixar uma palavra em negrito no meio da frase), use o Markdown do Discord — é mais limpo. Pra deixar o nick, a bio ou o nome de canal estiloso, use a fonte Unicode, porque o Markdown não pega ali. E um aviso importante: nada disso funciona no nome de usuário (@), que só aceita letra minúscula de a a z, número, ponto e underline — nem fonte, nem espaço, nem emoji. Se quer estilo no nome, o campo certo é o nome de exibição, não o @.

Onde as fontes para Discord funcionam (e o aviso do quadradinho)

Porque o que você copia é Unicode puro, as letras para Discord grudam em praticamente todo campo de texto do app:

— Nome de exibição e apelido de servidor (um por servidor)
— «Sobre mim» (a bio do seu perfil)
— Nome de canal (se você tiver permissão de admin)
— Status personalizado e mensagens do chat
— Nome de servidor (se você for o dono)

O único lugar onde não funciona é o nome de usuário (@), que é restrito de propósito. Fora isso, um aviso honesto: se o aparelho de quem está vendo for muito antigo, alguns estilos raros podem virar quadradinhos (□) — é a fonte que falta no dispositivo da pessoa, não o seu texto. Ficando nos estilos principais (negrito, itálico, cursiva, gótica, bubble, small caps) isso quase nunca acontece. E lembra: nada disso precisa de Nitro — o Nitro só entra pra cor e degradê no nome, não pro texto estiloso. Pra combinar o nick com emojis dos lados, dá uma olhada nos combos de emoji.

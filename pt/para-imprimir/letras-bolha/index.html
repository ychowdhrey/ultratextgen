Letras bolha para imprimir A–Z e 0–9

Escolha uma letra ou número e veja um contorno bolha grande e fofinho para traçar, colorir, imprimir ou baixar em PNG — ou digite um nome para uma folha inteira. Grátis, sem cadastro.

Escolha uma letra bolha

Toque em uma letra (A–Z) ou número (0–9) para ver o contorno bolha grande, imprimi-lo, baixar um PNG ou copiar os estilos bolha Unicode correspondentes.

Imprima um nome em letras bolha

Digite um nome ou uma palavra curta e imprima uma folha de contornos bolha para traçar e colorir, ou salve como um banner em PNG.

Alfabeto bolha para imprimir

Todo o alfabeto bolha A–Z e 0–9 em contornos. Imprima a folha inteira para traçar ou colorir, ou toque em qualquer letra para abrir as opções de imprimir e baixar.

Formas de usar as letras bolha para imprimir

  • Traçar Imprima um contorno e trace por cima para aprender o formato fofinho com a mão.
  • Colorir O interior branco está pronto para canetinhas, giz de cera ou tinta — ótimo para crianças e para a escola.
  • Artesanato Recorte as letras para bandeirolas, plaquinhas de porta, cartões de aniversário, scrapbooks e bullet journals.

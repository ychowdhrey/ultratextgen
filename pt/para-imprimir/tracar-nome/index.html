Nome para traçar

Digite um nome e imprima uma atividade de escrita: um modelo cheio, linhas pontilhadas para traçar por cima e linhas em branco para praticar. Mais as letras A–Z e números 0–9 para traçar. Grátis, sem cadastro.

Adiciona um ponto de partida numerado e setas em cada letra traçada, para mostrar em que sentido desenhar cada traço — opcional, porque crianças em fases diferentes precisam de apoios diferentes.

Criar uma atividade de nome para traçar

Digite um nome ou uma palavra curta, veja a prévia abaixo e imprima — ou baixe um PNG. A folha oferece um modelo cheio para seguir, linhas pontilhadas para traçar por cima e linhas em branco para praticar livremente.

Letras e números para traçar A–Z, 0–9

Toque em uma letra ou número para traçá-lo sozinho, imprimir um caractere grande ou baixar um PNG.

Folhas para traçar A–Z e 0–9 para imprimir

Imprima uma folha pautada A–Z e 0–9 — um modelo e espaço para traçar em cada linha — ou imprima o alfabeto em contorno abaixo para traçar letras inteiras.

Aproveitar melhor o nome para traçar

  • Primeiro o modelo Mostre a linha cheia de cima e diga o nome antes de começar a traçar.
  • Traçar devagar Incentive a criança a ficar dentro do contorno — o controle importa mais que a velocidade.
  • Depois, à mão livre Termine nas linhas em branco escrevendo o nome sem apoio.

Quer aumentar a dificuldade conforme a criança evolui? Para um estilo mais decorativo, experimente as letras bolha para colorir, ou transforme o nome em um quebra-cabeça do nome para montar.

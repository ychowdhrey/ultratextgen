Alfabeto cursivo — Fichas de caligrafia para imprimir

O alfabeto cursivo completo A–Z. Imprima uma folha de treino com letras-modelo e espaço para traçar, baixe qualquer letra em PNG, ou crie uma ficha de nome em cursiva. Grátis, sem cadastro.

Ficha de caligrafia cursiva para imprimir

Um clique imprime uma página A–Z onde cada linha mostra as letras-modelo em cursiva mais um espaço para traçá-las e repeti-las — pronta para a sala de aula, o ensino em casa ou seu próprio treino.

Letras cursivas A–Z

Toque em uma letra para ver sua forma cursiva em maiúscula e minúscula, imprimir uma letra única grande, baixar um PNG ou copiar os estilos cursivos Unicode correspondentes.

Ficha de nome para traçar em cursiva

Digite um nome para vê-lo em cursiva na prévia, depois imprima uma ficha com uma linha-modelo e linhas pontilhadas para cobrir — ideal para assinaturas e o treino do nome.

Aprender cursiva com a folha de treino

Imprima a folha de treino e cubra cada letra-modelo até as ligações ficarem naturais, depois passe para o espaço em branco para escrevê-la sozinho. Observe como cada maiúscula se liga, e mantenha sessões curtas e frequentes — algumas letras por dia valem mais que uma sessão longa.

Cursiva para imprimir vs. cursiva para copiar e colar

Estas fichas são feitas para o papel — o traço e a escrita. Se você quer texto cursivo para colar em uma bio do Instagram, uma legenda ou um documento, use o gerador de letra cursiva, que transforma suas palavras em script Unicode para copiar e colar. Para um nome decorativo para colorir, experimente as letras bolha.

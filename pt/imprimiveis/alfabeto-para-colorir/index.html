Páginas ABC para colorir e imprimir grátis. Escolha uma letra para um grande contorno nítido para colorir, imprima todo o alfabeto de uma vez, ou veja qualquer letra na prévia — sem cadastro.

Escolha uma letra para colorir

Toque em qualquer letra A–Z para ver seu grande contorno para colorir, imprimi-lo ou baixar um PNG.

Quer o alfabeto completo? Imprima os 26 contornos para colorir de uma vez — em uma única folha, ou como livro com uma página por letra.

Como usar o alfabeto para colorir

  • Aprender Diga a letra e o som dela em voz alta durante o colorir — uma forma simples de ligar as letras aos sons.
  • Colorir Os contornos finos deixam bastante espaço para lápis, canetinhas e lápis de cor.
  • Na sala de aula Imprima todo o alfabeto para uma oficina, ou uma única letra para a letra da semana.

Prefere letras para copiar e colar em vez de colorir?

Estes contornos são feitos para o papel. Se você quer letras bonitas para colar em uma bio ou legenda, use os geradores de fonte. Para outros estilos para imprimir, experimente as letras bolha.

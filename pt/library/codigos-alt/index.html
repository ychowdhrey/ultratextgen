Códigos Alt

Todos os códigos da tecla Alt do Windows mais comuns com o caractere que cada um digita — e é só clicar para copiar se você preferir pular o teclado numérico. Clique em qualquer caractere para copiar na hora.

Os códigos Alt permitem que usuários do Windows digitem caracteres especiais segurando a tecla Alt e digitando um número no teclado numérico — Alt+0169 produz ©, Alt+3 produz ♥. Esta referência reúne os códigos Alt mais úteis agrupados por categoria, com cada caractere identificado pelo seu código e nome. Não tem teclado numérico? Sem problema: todo caractere desta página também é copiável com um clique, então funciona em notebooks, Macs e celulares também.

Tabela ASCII

Caracteres ASCII imprimíveis de 33 a 126 com seus códigos decimal, hexadecimal, binário e octal. Clique em qualquer caractere para copiar na hora.

A tabela ASCII mapeia os 128 caracteres do American Standard Code for Information Interchange para os números de 0 a 127 — a base da codificação de texto moderna e os primeiros 128 pontos de código do Unicode. Esta referência cobre a faixa imprimível (33–126) agrupada por tipo, com cada caractere identificado pelo seu código decimal, hexadecimal, binário e octal. Os códigos de 0 a 31 são caracteres de controle não imprimíveis (como o 10, o line feed), e o 32 é o espaço. Precisa converter uma palavra ou mensagem inteira em vez de procurar caractere por caractere? Use o conversor ASCII interativo para transformar texto em código decimal, hexadecimal, binário ou octal (e de volta) na hora.

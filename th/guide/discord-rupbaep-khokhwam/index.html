ถอดรหัสการจัดรูปแบบข้อความ Discord

คุณไม่ได้มีปัญหาเรื่อง "ฟอนต์" — คุณมีปัญหาเรื่องสามระบบ Discord ใช้ Markdown อักขระ Unicode และสไตล์ Nitro สำหรับงานที่ต่างกันสิ้นเชิง พอรู้ว่าช่องไหนใช้ระบบไหน ทุกคำถาม "ทำไมอันนี้ไม่ได้ผล?" จะตอบตัวมันเอง

เชี่ยวชาญแพลตฟอร์ม ⏱ อ่าน 8 นาที โมเดลสามระบบ

ประเด็นสำคัญ

  • Discord มีระบบข้อความที่ไม่เกี่ยวกันสามระบบ: Markdown (ข้อความแชต), "ฟอนต์" Unicode (ชื่อทุกที่) และ Nitro (สไตล์ชื่อที่แสดงแบบเสียเงิน)
  • Markdown อย่าง **bold** แสดงผลได้เฉพาะในข้อความแชตเท่านั้น — ไม่เคยใช้ได้ในชื่อผู้ใช้ ชื่อเล่น หรือชื่อเซิร์ฟเวอร์/ช่อง
  • "ฟอนต์" Unicode ใช้ได้ในทุกช่องชื่อ แต่บนบางเครื่องอาจแสดงเป็นกล่องและทำให้โปรแกรมอ่านหน้าจอสะดุด
  • Nitro เพิ่มสีและเอฟเฟกต์จริงให้ชื่อที่แสดงของคุณ — แต่ภายในเซิร์ฟเวอร์ สีบทบาทของคุณชนะ เหลือให้เห็นแค่ฟอนต์
มองใหม่

มันไม่ใช่เรื่องฟอนต์ — แต่เป็นสามระบบที่ต่างกัน

คำถาม "ทำไมข้อความของฉันไม่ได้ผล" ใน Discord เกือบทั้งหมดมาจากการเอาสามสิ่งที่ไม่เกี่ยวกันเลยมาปนกัน Discord สอน Markdown ให้คุณในแชต คุณจึงเข้าใจว่าลูกเล่นเดียวกันน่าจะใช้ตกแต่งชื่อได้ แต่มันไม่ได้ — ชื่อรันคนละระบบไปเลย

นี่คือภาพรวมทั้งหมดในกรอบเดียว เรียนรู้ว่าแต่ละช่องใช้ระบบไหน แล้วคุณจะไม่มีวันแปลกใจอีก

ระบบมันคืออะไรใช้ได้ที่ไหนข้อควรระวัง
Markdownสัญลักษณ์ที่ Discord แสดงผลให้ (**bold**, *italic*, ~~strike~~, สี ANSI)เฉพาะข้อความแชตตายในทุกช่องชื่อ; สี ANSI ใช้ได้บนเดสก์ท็อปเท่านั้น
"ฟอนต์" Unicodeอักขระทดแทนที่หน้าตาถูกตกแต่งอยู่แล้ว (𝗯𝗼𝗹𝗱, 𝓬𝓾𝓻𝓼𝓲𝓿𝓮)ชื่อที่แสดง ชื่อเล่น ชื่อเซิร์ฟเวอร์/ช่อง/บทบาท ไบโอ ข้อความอาจแสดงเป็นกล่อง; ทำให้โปรแกรมอ่านหน้าจอสะดุด; ถูกปฏิเสธในชื่อผู้ใช้ @
สไตล์ NitroDisplay Name Styles แบบเสียเงิน: ฟอนต์จริง + สี + เอฟเฟกต์ชื่อที่แสดงของคุณสี/เอฟเฟกต์ไม่แสดงภายในเซิร์ฟเวอร์ (สีบทบาทชนะ); เสียเงิน
ระบบที่ 1

Markdown — สำหรับข้อความแชต

Markdown คือการจัดรูปแบบที่ Discord ใส่ให้ตอนมัน แสดง ข้อความของคุณ คุณพิมพ์สัญลักษณ์คร่อมคำ แล้ว Discord ก็สลับมันเป็นสไตล์จริงให้

  • **bold** → ตัวหนา
  • *italic* → ตัวเอียง
  • ~~strikethrough~~ → ขีดฆ่า
  • __underline__ → ขีดเส้นใต้
  • ||spoiler|| → ซ่อนไว้จนกว่าจะคลิก
  • > quote คำพูด และ `code` โค้ด

นี่คือวิธี ที่ถูกต้อง ในการจัดรูปแบบข้อความ — มันยังเป็นข้อความจริง จึงค้นหาได้และเข้าถึงได้ ข้อควรระวังคือสองความผิดพลาดที่ทำให้มัน "ไม่ได้ผล":

ไม่เป็นตัวหนา

** text ** — เว้นวรรคด้านในดอกจันทำให้มันไม่ทำงาน ใช้ **text**

ไม่เป็นตัวหนา

ภายใน `บล็อกโค้ด` backtick จะปิด Markdown ย้ายการตกแต่งออกไปข้างนอก

และข้อใหญ่ที่สุด: Markdown ไม่ทำอะไรเลยในชื่อผู้ใช้ ชื่อเล่น ชื่อเซิร์ฟเวอร์ หรือชื่อช่อง สิ่งเหล่านั้นไม่ใช่ข้อความแชต Discord จึงไม่เคยรัน Markdown กับมัน

ระบบที่ 2

"ฟอนต์" Unicode — สำหรับชื่อ

ถ้าจะตกแต่ง ชื่อ คุณจะขอให้ Discord แสดงผลอะไรไม่ได้ — คุณจึงใช้อักขระที่หน้าตาถูกตกแต่งอยู่แล้ว ตัวสร้างจะเปลี่ยน "Nova" เป็น 𝗡𝗼𝘃𝗮 หรือ 𝓝𝓸𝓿𝓪 โดยใช้ อักขระ Unicode พิเศษ แล้วคุณก็วางผลลัพธ์สำเร็จลงในช่องได้เลย ไม่ต้องอาศัยการแสดงผล มันจึงอยู่รอดในที่ที่ Markdown ทำไม่ได้

วิธีนี้ใช้ได้ในชื่อที่แสดง ชื่อเล่นในเซิร์ฟเวอร์ ชื่อเซิร์ฟเวอร์และช่อง ชื่อบทบาท ไบโอ และข้อความแชต มีอยู่ที่เดียวเป๊ะๆ ที่มันถูกบล็อก:

ชื่อผู้ใช้ @ ปฏิเสธมัน ชื่อไม่ซ้ำของคุณ (ตัวพิมพ์เล็กหลัง @) อนุญาตแค่ a–z, 0–9, _ และ . เท่านั้น — เพื่อการกล่าวถึง การค้นหา และการนำทาง วางฟอนต์สวยๆ ลงตรงนั้นแล้ว Discord จะไม่ยอมบันทึก ตกแต่ง ชื่อที่แสดง ของคุณแทน

ข้อควรระวังจริงสองอย่างที่ครอบคลุมโดยละเอียดในที่อื่น: ชื่อ Unicode อาจแสดงเป็นกล่องบนบางเครื่อง (โดยเฉพาะ Android รุ่นเก่า) และมันอ่านยากสำหรับโปรแกรมอ่านหน้าจอ เลือกสไตล์ที่ปลอดภัย (ตัวหนา ตัวเอียง small caps) และเก็บให้ดูมีรสนิยม — เซิร์ฟเวอร์ใหญ่หลายแห่งดูแลลบชื่อที่อ่านยากหรือ Zalgo อย่างเข้มงวด

ระบบที่ 3

Nitro Display Name Styles — เสียเงิน และแคบกว่าที่คิด

Nitro ระดับเสียเงินของ Discord มี Display Name Styles ฟีเจอร์ที่เพิ่มเข้ามาปลายปี 2025: ฟอนต์จริง สี และแม้แต่เอฟเฟกต์เคลื่อนไหวที่ใส่ให้ชื่อที่แสดงของคุณ มันดูดีมากบนการ์ดโปรไฟล์ แต่มีข้อควรระวังที่คนมักรู้แบบเจ็บตัว:

ภายในเซิร์ฟเวอร์ สีบทบาท ของคุณจะทับสีของ Nitro และเอฟเฟกต์ถูกถอดออก — คนอื่นจึงมักเห็นแค่ ฟอนต์ ไม่ใช่สีหรือแอนิเมชัน เอฟเฟกต์เต็มๆ จะแสดงหลักๆ บนโปรไฟล์ของคุณ ไม่ใช่ในรายชื่อสมาชิกหรือแชต

บัญชีฟรีเปิดเมนูและ ดูตัวอย่าง สไตล์ได้ แต่การบันทึกต้องใช้ Nitro เท่านั้น — การให้ดูตัวอย่างแล้วติดกำแพงจ่ายเงินนี่แหละคือเหตุผลที่คนจำนวนมากถามว่าจำเป็นต้องมี Nitro ถึงจะใช้ฟอนต์ได้ไหม เป็นคำถามที่สมเหตุสมผลเกี่ยวกับฟีเจอร์เฉพาะตัวนี้ แต่มันไม่ได้เปลี่ยนแปลงการตกแต่งด้วย Unicode ซึ่งยังฟรีอยู่เหมือนเดิม

ดังนั้น Nitro คุ้มถ้าคุณอยากได้การ์ดโปรไฟล์ที่ดูเนี้ยบและฟอนต์ชื่อที่แสดงเฉพาะตัวทุกที่ แต่มัน ไม่ใช่ วิธีทำข้อความสีในบทสนทนา — นั่นเป็นเครื่องมือคนละอย่าง (หัวข้อถัดไป)

คำถามเรื่องสี

แล้วข้อความสีในข้อความแชตล่ะ?

ข้อความสีในข้อความแชตเป็นลูกเล่นที่สี่ซึ่งแคบกว่า: บล็อกโค้ด ANSI คุณครอบข้อความด้วยบล็อก triple-backtick ที่กำกับว่า ansi แล้วเติมโค้ด escape สำหรับสี ต้องมองข้อจำกัดให้ชัด:

  • มีแค่ แปดสีตายตัว — ไม่มีเลขฐานสิบหก (hex) กำหนดเอง
  • เฉพาะในบล็อกโค้ด — ทำสีให้ประโยคปกติแบบแทรกในบรรทัดไม่ได้
  • ไม่น่าเชื่อถือบนมือถือ — มักแสดงเป็นข้อความธรรมดาสำหรับผู้ใช้โทรศัพท์

มีประโยชน์สำหรับคำเตือนหรือ log ในเซิร์ฟเวอร์ที่เน้นเดสก์ท็อป แต่ไม่ใช่เครื่องมือตกแต่งทั่วไป ถ้าสมาชิกครึ่งหนึ่งของคุณอยู่บนมือถือ ให้สันนิษฐานว่าพวกเขาจะไม่เห็นสี

คำถามที่พบบ่อย

เพราะมันใช้คนละระบบ ในแชต **bold** คือ Markdown — Discord แสดงผลให้เมื่อมันแสดงข้อความของคุณ ส่วนชื่อ (ชื่อผู้ใช้ ชื่อเล่น เซิร์ฟเวอร์ ช่อง บทบาท) ไม่รัน Markdown ดอกจันจึงแสดงตรงๆ ตามที่พิมพ์ ถ้าอยากตกแต่งชื่อ ต้องใช้ "ฟอนต์" Unicode — อักขระพิเศษที่หน้าตาเป็นตัวหนาอยู่แล้ว — วางลงในช่องโดยตรง

ไม่เหมือน "ฟอนต์" Unicode คืออักขระทดแทนที่ใช้ฟรี วางได้ทุกที่ที่อนุญาตให้ใส่ชื่อ ใช้ได้กับทุกคน แต่บนบางเครื่องอาจแสดงเป็นกล่องและทำให้โปรแกรมอ่านหน้าจอสะดุด ส่วน Nitro Display Name Styles เป็นฟีเจอร์เสียเงินที่ใส่ฟอนต์จริง สี และเอฟเฟกต์ให้ชื่อที่แสดงของคุณ — แต่สีและเอฟเฟกต์จะไม่แสดงภายในเซิร์ฟเวอร์ ตรงนั้นสีบทบาทของคุณชนะ มีแต่ฟอนต์เท่านั้นที่ติดไปด้วย

ด้วยบล็อกโค้ด ANSI: ครอบข้อความด้วยบล็อก triple-backtick ที่กำกับว่า "ansi" แล้วเติมโค้ด escape สำหรับสี มันจำกัดอยู่ที่แปดสีตายตัว ใช้ได้เฉพาะในบล็อกโค้ด และไม่น่าเชื่อถือบนมือถือ (มักแสดงเป็นข้อความธรรมดา) มันใช้กับข้อความ ไม่ใช่ชื่อ

มีสองสาเหตุที่พบบ่อย: มีเว้นวรรคระหว่างดอกจันกับคำ (** text ** จะไม่เป็นตัวหนา — **text** ถึงจะได้) หรือข้อความอยู่ในบล็อกโค้ด (backtick ปิด Markdown) และอย่าลืมว่า Markdown ใช้ได้เฉพาะในข้อความเท่านั้น ไม่เคยใช้ได้ในชื่อ

สัญลักษณ์ Discord

คัดลอกและวางสัญลักษณ์สไตล์เก๋สำหรับชื่อผู้ใช้ ไบโอ และชื่อเซิร์ฟเวอร์ Discord อักขระทุกตัวแสดงผลได้ไม่มีปัญหาในระบบข้อความของ Discord — คลิกสัญลักษณ์ใดก็ได้เพื่อคัดลอกทันที

Discord รองรับอักขระ Unicode ส่วนใหญ่ในชื่อผู้ใช้ ไบโอ และชื่อเซิร์ฟเวอร์ แต่การแสดงผลอาจต่างกันไปตามแพลตฟอร์มและเวอร์ชันอิโมจิ สัญลักษณ์ด้านล่างนี้รวมตัวตกแต่งสไตล์เก๋ที่พบบ่อยที่สุดในคอมมูนิตี้ Discord ทั้งจุดประกาย เส้นคั่น วงเล็บสไตล์ญี่ปุ่น และชุดหัวใจ ทุกกล่องคัดลอกสัญลักษณ์เดียวหรือชุดพร้อมวางได้ทันที

คำถามที่พบบ่อย

คำถามที่พบบ่อยเกี่ยวกับสัญลักษณ์ Discord

ต้องมี Nitro ถึงจะใช้สัญลักษณ์ Discord ได้ไหม?

ไม่ต้อง สัญลักษณ์ในหน้านี้เป็นอักขระ Unicode มาตรฐาน จึงใช้ได้กับทุกบัญชี Discord ทั้งแบบฟรีและ Nitro Nitro จะเพิ่มอิโมจิกำหนดเองและอิโมจิเคลื่อนไหว อัปโหลดไฟล์ขนาดใหญ่ขึ้น และของตกแต่งโปรไฟล์ แต่สัญลักษณ์ข้อความและฟอนต์ Unicode ไม่จำเป็นต้องใช้ Nitro เลย (ดู ฟอนต์สวยๆ ใช้ได้ตรงไหนบ้างใน Discord สำหรับกฎแบบช่องต่อช่อง)

ใส่สัญลักษณ์ลงในชื่อหรือไบโอ Discord ยังไง?

คลิกสัญลักษณ์ใดก็ได้เพื่อคัดลอก แล้วนำไปวางในชื่อที่แสดง (Display Name) ช่อง About Me ชื่อเล่นในเซิร์ฟเวอร์ ชื่อเซิร์ฟเวอร์ หรือข้อความ ข้อควรระวังคือช่องชื่อผู้ใช้สำหรับล็อกอิน (username) รับได้แค่ตัวพิมพ์เล็ก ตัวเลข ขีดล่าง และจุดเท่านั้น สัญลักษณ์จึงต้องใส่ในชื่อที่แสดง ไม่ใช่ในชื่อผู้ใช้

ใช้สัญลักษณ์ในชื่อช่อง Discord ได้ไหม?

ได้บางส่วน ชื่อช่องจะถูกแปลงเป็นตัวพิมพ์เล็กและเปลี่ยนช่องว่างเป็นขีดกลาง แต่สัญลักษณ์ Unicode และเส้นคั่นหลายตัว (เช่น ⊹, ➤, │ และ ⌗) ยังใช้เป็นคำนำหน้าหรือตัวคั่นเพื่อจัดระเบียบรายชื่อช่องและหมวดหมู่ในเซิร์ฟเวอร์ได้ ลองทดสอบทั้งบนคอมพิวเตอร์และมือถือ เพราะการรองรับอาจแตกต่างกัน

ทำไมสัญลักษณ์ Discord บางตัวถึงขึ้นเป็นกล่องว่าง?

กล่องว่างหมายความว่าอุปกรณ์หรือเวอร์ชันแอปของผู้ดูไม่มีกลิฟสำหรับอักขระนั้น สัญลักษณ์ที่รองรับกว้างขวาง (ดาว หัวใจ จุด เส้นคั่นแบบ box-drawing) จะแสดงผลได้เกือบทุกที่ ส่วนอักขระที่หายากอาจไม่แสดง ถ้าสัญลักษณ์ดูเหมือนพังสำหรับคนอื่น ให้เปลี่ยนเป็นตัวเลือกที่พบได้ทั่วไปกว่า

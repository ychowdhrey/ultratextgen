คาโอโมจิ (ตัวอักษรหน้าตาน่ารัก คัดลอกวางได้เลย)

รวมคาโอโมจิน่ารักแยกตามอารมณ์ ตั้งแต่แบบเรียบง่ายยอดฮิต ไปจนถึงดีใจ ร้องไห้ เขินอาย ความรัก สัตว์ และกอด — แค่คลิกก็คัดลอกได้ วางลงไลน์ อินสตาแกรม X ได้ทันที

คาโอโมจิคือการแสดงออกด้วยข้อความที่เกิดในญี่ปุ่น โดยนำสัญลักษณ์และตัวอักษรมาประกอบกันเป็นสีหน้า ต่างจากอิโมจิตรงที่ไม่มีความต่างของภาพตามเครื่องหรือแอป และถ่ายทอดอารมณ์ละเอียดอ่อนได้ดี — เขินนิดๆ ร้องไห้ซึมๆ หรืออารมณ์ดีสุดๆ ไม่ว่าจะในแชต โปรไฟล์ หรือคอมเมนต์ แค่เติมสักตัวเดียวก็ส่งอารมณ์ของข้อความออกมาได้

คาโอโมจิบนหน้านี้ทำจากอักขระ Unicode มาตรฐานล้วนๆ ไม่ต้องบันทึกคำหรือลงแอปใดๆ แค่คลิก (หรือแตะ) ก็คัดลอกเสร็จ ใช้ได้แทบทุกที่ที่มีช่องกรอกข้อความ ทั้งแชตไลน์ ข้อความแนะนำตัวในอินสตาแกรม โพสต์บน X แชต Discord ไปจนถึงแชตในเกม

เลือกจากหมวดด้านล่างให้เข้ากับอารมณ์ได้เลย มีครบทั้งแบบเรียบง่ายยอดฮิต แบบดีใจ แบบร้องไห้ แบบเขินอาย แบบความรัก แบบสัตว์ และ Lenny face ที่ฮิตในแชตต่างประเทศ

FAQ

คำถามที่พบบ่อยเกี่ยวกับคาโอโมจิ

คัดลอกคาโอโมจิยังไง?

แค่คลิก (หรือแตะ) คาโอโมจิบนหน้านี้ก็คัดลอกได้เลย จากนั้นวางลงในแชตไลน์ โปรไฟล์อินสตาแกรม โพสต์บน X หรือที่ไหนก็ได้ตามใจ ไม่ต้องใช้แอปพิเศษหรือบันทึกคำใดๆ

คาโอโมจิที่คัดลอกไปใช้ที่ไหนได้บ้าง?

ใช้ได้กับช่องกรอกข้อความเกือบทุกที่ ทั้งไลน์ อินสตาแกรม X (ทวิตเตอร์เดิม) TikTok Discord คอมเมนต์ YouTube ไปจนถึงแชตในเกม เพราะทำจากอักขระ Unicode มาตรฐานล้วนๆ จึงแสดงผลเหมือนกันแม้ใช้เครื่องต่างรุ่น

คาโอโมจิจะกลายเป็นตัวอักษรเพี้ยนไหม?

โดยทั่วไปไม่เพี้ยน แต่คาโอโมจิบางแบบที่ซับซ้อนอาจดูต่างไปเล็กน้อยบนเครื่องเก่าหรือฟอนต์บางตัว ส่วนคาโอโมจิเรียบง่าย (เช่น (^^) หรือ (T_T)) แสดงผลได้สวยงามแน่นอนแทบทุกสภาพแวดล้อม

ใช้ฟรีไหม?

ใช้ฟรีเต็มรูปแบบ ไม่ต้องสมัครสมาชิก คัดลอกกี่ครั้งก็ได้ คาโอโมจิเป็นแค่ข้อความ จึงใช้ได้อย่างอิสระโดยไม่ต้องกังวลเรื่องลิขสิทธิ์

แปลงฟอนต์

คาโอโมจิมาแล้ว จับตัวอักษรให้เก๋ไปด้วยกันไหม?

คาโอโมจิดูแลเรื่องสีหน้า ส่วนชื่อหรือวลีลองแปลงเป็นฟอนต์เก๋ๆ อย่าง 𝓒𝓾𝓽𝓮 หรือ 𝗕𝗼𝗹𝗱 แล้วจับคู่กับคาโอโมจิ โปรไฟล์ก็จะดูสมบูรณ์ขึ้นอีกเยอะ

ใช้เครื่องมือแปลงฟอนต์

แปลงตัวอักษรและตัวเลขเป็นฟอนต์ Unicode เก๋ๆ กว่า 100 แบบในพริบตา ฟรี ไม่ต้องสมัคร และเข้ากับคาโอโมจิได้อย่างลงตัว

สัญลักษณ์ Roblox

รวมสัญลักษณ์เท่ ๆ สำหรับ Display Name ไบโอ และกลุ่มใน Roblox ทุกตัวผ่านการทดสอบกับตัวกรองชื่อมาแล้ว คลิกเพื่อคัดลอกได้ทันที

Roblox เปิดให้ใส่อักขระ Unicode ในชื่อที่แสดง (Display Name) และไบโอได้ แต่บางสัญลักษณ์อาจโดนตัวกรองเนื้อหาบล็อกไปดื้อ ๆ หน้านี้รวมสัญลักษณ์ที่ผ่านการทดสอบแล้วว่าใช้ได้จริง ทั้งดาว หัวใจ ดอกไม้ และตัวตกแต่งน่ารักที่เห็นได้บ่อยในคลิปแต่งชื่อ Roblox บน TikTok และ Lemon8 ไม่ว่าจะอยากได้สัญลักษณ์ Roblox แค่ตัวเดียวสำหรับ clan tag หรือทั้งชุดตกแต่งเต็มรูปแบบ ทุกตัวอักษรด้านล่างนี้ผ่านการตรวจสอบกับตัวกรองล่าสุดแล้วทั้งหมด

แค่คลิกสัญลักษณ์ที่ต้องการก็คัดลอกได้ทันที นำไปวางใน Display Name ไบโอ หรือคำอธิบายกลุ่มของคุณได้เลย

คัดลอกวางไอคอน Robux, Premium หรือ Verified ตัวจริงได้ไหม?

ไม่ได้ — และเรื่องนี้ทำให้หลายคนค้นหาผิดทาง ไอคอน Robux, Premium และ Verified ตัวจริงของ Roblox ไม่ใช่ตัวอักษร Unicode เลย ตามข้อมูลอย่างเป็นทางการจาก Roblox Developer Forum ไอคอนเหล่านี้อยู่ใน Private Use Area codepoints ชุดเล็ก ๆ (U+E000–U+E003) ที่แม็ปกับกลิฟใน client icon font ของ Roblox เอง ไอคอนจะแสดงผลได้เฉพาะในหน้า UI ของเกม — เช่น TextLabel ที่นักพัฒนาสร้างใน Roblox Studio เท่านั้น ไม่แสดงใน Display Name ไบโอ หรือข้อความแชท และไม่แสดงบนเว็บไซต์หรือแอปอื่นใดด้วย ถ้าคัดลอกไปวางที่อื่น จะกลายเป็นช่องว่างเปล่า ๆ ถ้าแค่อยากได้ลุคใกล้เคียง สัญลักษณ์มงกุฎ เครื่องหมายถูก และเพชรด้านบนคือตัวเลือกที่ปลอดภัยที่สุดสำหรับคัดลอกวาง — เพียงแต่จะไม่ถูกเข้าใจผิดว่าเป็นแบดจ์ Premium หรือ Verified ตัวจริง

เกี่ยวกับตัวกรองเนื้อหาของ Roblox

Roblox ใช้ระบบกรองเนื้อหาอัตโนมัติที่อาจบล็อกอักขระ Unicode บางตัวในชื่อที่แสดงและไบโอ สัญลักษณ์เดี่ยวอย่าง ★ ♡ ✦ ❀ ⋆ ปลอดภัยที่สุด ส่วนชุดสัญลักษณ์หลายตัวต่อกันหรืออักขระหายากมีโอกาสถูกบล็อกหรือลบออกมากกว่า หากสัญลักษณ์ที่เลือกบันทึกไม่ได้ ลองเปลี่ยนเป็นสัญลักษณ์เดี่ยวที่เรียบง่ายกว่าจากหมวด “สัญลักษณ์ที่ผ่านตัวกรอง” ด้านบน

Display Name ว่างเปล่า

ชื่อ Roblox แบบล่องหนและว่างเปล่า

อยากให้ Display Name ของ Roblox ดูเหมือนว่างเปล่าไหม? มีอักขระ Unicode ตัวจริง (แต่มองไม่เห็น) ที่ทำแบบนี้ได้ — เพราะช่องว่างจริง ๆ จะถูกตัดออกแล้วระบบมองว่าช่องว่างเปล่าจึงปฏิเสธ แต่อักขระสองตัวนี้ไม่ถูกจัดเป็นช่องว่าง จึงบันทึกได้ ตัวกรองของ Roblox จัดการอักขระทั้งสองไม่สม่ำเสมอ ถ้าตัวหนึ่งโดนปฏิเสธ ให้ลองอีกตัวแทน

Hangul Filler (U+3164)
Braille Pattern Blank (U+2800)

คำถามที่พบบ่อย

คำถามที่พบบ่อยเกี่ยวกับสัญลักษณ์ Roblox

สัญลักษณ์แบบไหนใช้ได้กับชื่อ Roblox บ้าง?

สัญลักษณ์ Unicode ตัวเดียวอย่าง ★ ♡ ✦ ❀ ⋆ ✧ ปลอดภัยที่สุด เพราะผ่านตัวกรองชื่อของ Roblox และแสดงผลถูกต้องในเกม ส่วนอักขระหายากหรือชุดสัญลักษณ์หลายตัวต่อกันมีโอกาสถูกบล็อกมากกว่า ทุกตัวในหมวด “สัญลักษณ์ที่ผ่านตัวกรอง” ด้านบนผ่านการทดสอบแล้วว่าบันทึกได้จริง

ทำไม Roblox ถึงบล็อกสัญลักษณ์บางตัว?

Roblox มีระบบกรองชื่อและเนื้อหาอัตโนมัติ เพื่อให้ชื่อผู้เล่นอ่านง่ายและปลอดภัย ระบบจะปฏิเสธอักขระที่ตรวจสอบไม่ได้ ทั้งสัญลักษณ์ตกแต่งแปลก ๆ อักขระที่มองไม่เห็น และบางชุดสัญลักษณ์ ถ้าสัญลักษณ์ที่เลือกบันทึกไม่ได้ ให้ลองเปลี่ยนเป็นสัญลักษณ์เดี่ยวที่เรียบง่ายกว่าแทน

ใส่สัญลักษณ์ลงในชื่อที่แสดง (Display Name) ของ Roblox ยังไง?

คลิกสัญลักษณ์บนหน้านี้เพื่อคัดลอก แล้วนำไปวางที่ Settings → Account Info → Display Name (หรือช่องไบโอ/กลุ่มของคุณ) ช่อง Display Name ใส่สัญลักษณ์ได้ แต่ @username จริงใส่ไม่ได้ เพราะรับเฉพาะตัวอักษร ตัวเลข และขีดล่างหนึ่งตัวเท่านั้น

สัญลักษณ์เหล่านี้ใช้แล้วโดนแบนไหม?

ไม่ต้องกังวล เพราะเป็นอักขระ Unicode ธรรมดาที่ใช้ตกแต่ง ไม่ใช่การโกงหรือช่องโหว่ใด ๆ การใส่ในชื่อหรือไบโอจึงไม่ผิดกฎของ Roblox แค่คุมเนื้อหาข้อความโดยรวมให้เหมาะสม เพราะตัวกรองเนื้อหายังตรวจสอบคำรอบ ๆ สัญลักษณ์อยู่เหมือนเดิม

คัดลอกวางไอคอน Robux, Premium หรือ Verified ตัวจริงได้ไหม?

ไม่ได้ ไอคอนเหล่านี้เป็น Unicode ในกลุ่ม private-use codepoints (U+E000–U+E003) ที่แม็ปกับกลิฟใน client icon font ของ Roblox เอง ตามข้อมูลที่มีอยู่ใน Roblox Developer Forum อย่างเป็นทางการ ไอคอนจะแสดงผลได้เฉพาะในหน้า UI ของเกมที่นักพัฒนาสร้างใน Roblox Studio เท่านั้น ไม่แสดงใน Display Name ไบโอ แชท หรือที่ใดนอกแพลตฟอร์ม ถ้าคัดลอกไปวางที่อื่นจะกลายเป็นช่องว่างเปล่า ๆ สัญลักษณ์มงกุฎ เครื่องหมายถูก และเพชรในหน้านี้คือลุคที่ใกล้เคียงที่สุดสำหรับคัดลอกวาง โดยไม่ได้อ้างว่าเป็นแบดจ์ทางการ

ทำไมสัญลักษณ์บางตัวใช้ได้กับคนอื่น แต่ของเรากลับขึ้นว่า "unsupported characters"?

ตัวกรองชื่อของ Roblox ทำงานไม่สม่ำเสมอเป๊ะ ๆ เสมอไป อาจแตกต่างกันไปตามภูมิภาคบัญชี เวอร์ชันแอป หรืออักขระที่อยู่รอบ ๆ สัญลักษณ์นั้น ถ้าชุดสัญลักษณ์ใช้ไม่ได้ ให้ลองวางสัญลักษณ์เดี่ยวตัวเดียวก่อน แล้วค่อย ๆ ต่อทีละตัวเพื่อประกอบชุดใหม่ สัญลักษณ์เดี่ยวจากหมวด “สัญลักษณ์ที่ผ่านตัวกรอง” ด้านบนคือจุดเริ่มต้นที่น่าเชื่อถือที่สุด

Roblox รองรับอักขระแบบไหนใน Display Name บ้าง?

ช่อง Display Name ของ Roblox รองรับอักขระ Unicode หลากหลาย ทั้งตัวอักษร ตัวเลข และสัญลักษณ์อีกมาก แต่ผ่านการกรอง ไม่ได้เปิดกว้างทั้งหมด เพราะไม่มีรายการอนุญาตอย่างเป็นทางการที่เผยแพร่ไว้ คำว่า “รองรับ” ในทางปฏิบัติจึงหมายถึง “ผ่านตัวกรองปัจจุบัน” ซึ่งเปลี่ยนแปลงได้ตลอดเวลา ทางเลือกที่ปลอดภัยที่สุดคือสัญลักษณ์เดี่ยวในหมวด “สัญลักษณ์ที่ผ่านตัวกรอง” ด้านบน ส่วนชุดสัญลักษณ์หลายตัวต่อกันหรืออักขระจากบล็อก Unicode หายากมีโอกาสถูกปฏิเสธมากกว่า

อักษรญี่ปุ่น จีน หรือเกาหลี ใช้ใน Display Name ของ Roblox ได้ไหม?

โดยทั่วไปใช้ได้ — ชื่อที่เป็นอักษร CJK ล้วน ๆ อย่าง こんにちは หรือ 안녕하세요 มักผ่านตัวกรองของ Roblox ตามรายงานใน Developer Forum อย่างเป็นทางการ กลับกันตัวอักษรละตินที่มีเครื่องหมายเสริม (é, ü, ł และอักขระเน้นเสียงลักษณะนี้) มีโอกาสถูกปฏิเสธมากกว่า ซึ่งหลายคนคาดไม่ถึงเพราะคิดว่าจะเป็นไปในทางตรงข้าม พฤติกรรมนี้ไม่ได้การันตีว่าจะเหมือนกันทุกบัญชี จึงควรทดสอบก่อนตั้งชื่อจริงจัง

Roblox จะตัดช่องว่างจริงที่อยู่หน้าและหลัง Display Name ออก แล้วปฏิเสธช่องที่ว่างเปล่าหลังตัดออกแล้ว ดังนั้นใส่แค่ช่องว่างเฉย ๆ จะบันทึกไม่ได้ ให้ใช้อักขระที่มองไม่เห็นแทน — Hangul Filler (ㅤ) หรือ Braille Pattern Blank (⠀) จากหมวด “ชื่อ Roblox แบบล่องหนและว่างเปล่า” ที่ไม่ถูกจัดเป็นช่องว่าง จึงคงช่องว่างที่มองเห็นได้โดยไม่ถูกตัดออก

ต้องการชื่อผู้ใช้ Roblox ใหม่ (ไม่ใช่แค่สัญลักษณ์)?

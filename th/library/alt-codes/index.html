Alt Code ทั้งหมด

รวม Alt Code ที่ใช้บ่อยที่สุดบน Windows พร้อมสัญลักษณ์ที่ได้ — ตั้งแต่ Alt+0169 สำหรับ © ไปจนถึงสัญลักษณ์สกุลเงิน คณิตศาสตร์ และเครื่องหมายวรรคตอน ไม่มีคีย์แพดตัวเลข? ไม่เป็นไร แตะสัญลักษณ์ไหนบนหน้านี้ก็คัดลอกได้ทันที

Alt Code คือวิธีพิมพ์สัญลักษณ์พิเศษบน Windows ด้วยการกดปุ่ม Alt ค้างไว้แล้วพิมพ์ตัวเลขบนคีย์แพดตัวเลข (Numpad) — Alt+0169 ได้ ©, Alt+3 ได้ ♥ หน้านี้รวมรหัสที่มีประโยชน์ที่สุดจัดตามหมวดหมู่ พร้อมชื่อและรหัสกำกับทุกตัว ตัวอักษรไทยเองไม่ได้พิมพ์ด้วย Alt Code (ใช้การสลับภาษาคีย์บอร์ดแทน) แต่รหัสเหล่านี้ยังจำเป็นเวลาต้องพิมพ์เครื่องหมายลิขสิทธิ์ สกุลเงิน และสัญลักษณ์คณิตศาสตร์ ไม่มีคีย์แพด? ไม่มีปัญหา สัญลักษณ์ทุกตัวในหน้านี้แตะเพื่อคัดลอกได้เลย ใช้ได้ทั้งโน้ตบุ๊ก แมค และมือถือ

คำถามที่พบบ่อย

คำถามที่พบบ่อยเกี่ยวกับ Alt Code

Alt Code คืออะไร?

Alt Code คือวิธีพิมพ์สัญลักษณ์พิเศษบน Windows ที่ไม่มีปุ่มตรงบนคีย์บอร์ด ด้วยการกดปุ่ม Alt ค้างไว้แล้วพิมพ์ตัวเลขบนคีย์แพดตัวเลข (Numpad) — เช่น Alt+0169 ได้ © และ Alt+3 ได้ ♥ หน้านี้รวมรหัสที่มีประโยชน์ที่สุดจัดตามหมวดหมู่พร้อมชื่อสัญลักษณ์กำกับ

พิมพ์ Alt Code บน Windows ยังไง?

ตรวจสอบก่อนว่า Num Lock เปิดอยู่ จากนั้นกดปุ่ม Alt ค้างไว้ พิมพ์ตัวเลขให้ครบบนคีย์แพดตัวเลข (ไม่ใช่แถวตัวเลขด้านบน) แล้วปล่อยปุ่ม Alt สัญลักษณ์จะปรากฏตรงตำแหน่งเคอร์เซอร์ทันที

Alt Code ใช้ได้บน Mac หรือโน้ตบุ๊กที่ไม่มีคีย์แพดตัวเลขไหม?

ไม่ได้ — Alt Code เป็นฟีเจอร์เฉพาะของ Windows และต้องใช้คีย์แพดตัวเลข ไม่ว่าจะเป็นแบบจริงหรือเปิดผ่านปุ่ม Fn บนโน้ตบุ๊ก บน Mac ใช้ทางลัดคนละแบบ (ปุ่ม Option) ถ้าไม่มีคีย์แพด แค่แตะสัญลักษณ์ที่ต้องการในหน้านี้เพื่อคัดลอก ใช้ได้ทุกอุปกรณ์ ทั้งโน้ตบุ๊ก Mac หรือแม้แต่มือถือ

ทำไม Alt Code ที่พิมพ์ไม่ขึ้น?

สาเหตุที่พบบ่อยสามข้อ: Num Lock ไม่ได้เปิด, พิมพ์ตัวเลขจากแถวด้านบนแทนที่จะเป็นคีย์แพดตัวเลข, หรือคีย์แพดตัวเลขของโน้ตบุ๊กยังไม่ได้เปิดผ่าน Fn นอกจากนี้ต้องระวังเลข 0 นำหน้าในรหัส 0nnn (Alt+0169 ไม่เหมือนกับ Alt+169) ถ้ายังไม่ได้ผล สัญลักษณ์ทุกตัวในหน้านี้แตะเพื่อคัดลอกได้เลย

Alt+0169 กับ Alt+169 ต่างกันยังไง?

รหัสที่มีเลข 0 นำหน้า (Alt+0nnn) ใช้ตารางอักขระของ Windows สมัยใหม่ (Windows-1252) ซึ่งแม่นยำกว่าสำหรับสกุลเงิน ตัวอักษรมีเครื่องหมาย และเครื่องหมายวรรคตอน ส่วนรหัสที่ไม่มีเลข 0 นำหน้า (Alt+nnn) จะอิงตารางอักขระ DOS แบบเก่า (CP437) ซึ่งอาจให้สัญลักษณ์คนละตัวสำหรับเลขเดียวกัน หากไม่แน่ใจ ลองแบบมีเลข 0 นำหน้าก่อน

พิมพ์ตัวอักษรไทยด้วย Alt Code ได้ไหม?

ไม่ได้ — ตัวอักษรไทยไม่ได้อยู่ในตารางอักขระคลาสสิกที่ Alt Code ใช้งาน (Windows-1252 และ CP437) การพิมพ์ภาษาไทยต้องสลับภาษาคีย์บอร์ดเป็นไทยแทน แต่ Alt Code ในหน้านี้ยังมีประโยชน์เวลาต้องพิมพ์ © สัญลักษณ์สกุลเงิน หรือเครื่องหมายทางคณิตศาสตร์ที่ไม่มีปุ่มตรงบนคีย์บอร์ด

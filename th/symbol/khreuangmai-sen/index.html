เครื่องหมายเซนต์ (¢)

¢ ที่ใช้ตั้งราคาเศษหนึ่งส่วนของดอลลาร์ — และเป็นสัญลักษณ์สกุลเงินทั่วไปตัวเดียวที่ไม่มีปุ่มเฉพาะบนแป้นพิมพ์เกือบทุกแบบ คลิกสัญลักษณ์ไหนก็ได้เพื่อคัดลอกทันที

เครื่องหมายเซนต์ (¢, ยูนิโค้ด U+00A2) ใช้แทนหน่วยย่อยของสกุลเงิน คือหนึ่งในร้อยของดอลลาร์ อย่างที่เห็นใน 99¢ เป็นหนึ่งในสัญลักษณ์สกุลเงินที่เก่าแก่ที่สุดในบล็อก Latin-1 Supplement ของยูนิโค้ด สืบทอดมาจากการเข้ารหัสแบบ 8-บิตรุ่นเก่า ซึ่งเป็นเหตุผลว่าทำไมมันถึงพิมพ์ได้ง่ายผ่านรหัส Alt แม้แป้นพิมพ์เกือบทุกแบบจะไม่มีปุ่มเฉพาะให้แบบที่ $ มีก็ตาม

เครื่องหมายเซนต์มาจากไหน

¢ ย่อมาจาก "cent" จากภาษาละติน centum ("ร้อย") — เซนต์คือหนึ่งในร้อยของดอลลาร์ ตัวสัญลักษณ์เอง คือตัว c พิมพ์เล็กที่มีเส้นขีดพาดแนวตั้งหรือแนวทแยง เกิดขึ้นในวงการพิมพ์เชิงพาณิชย์และเครื่องพิมพ์ดีดของอเมริกาในศตวรรษที่ 19 เป็นวิธีย่อบอกราคาต่ำกว่าหนึ่งดอลลาร์โดยไม่ต้องเขียนคำว่า "cents" เต็มๆ

¢ เข้าสู่ยูนิโค้ดผ่านทางบล็อก Latin-1 Supplement (U+00A2) ซึ่งยูนิโค้ดสืบทอดมาทั้งหมดจาก ISO 8859-1 และก่อนหน้านั้นจากรหัสหน้า Windows-1252 และรหัสหน้า 8-บิตรุ่นเก่าที่หลายระบบใช้อยู่แล้ว ตำแหน่งที่สืบทอดมานี้เองคือเหตุผลที่ ¢ มีรหัส Alt ใช้งานได้ (Alt+0162) บน Windows มานานหลายสิบปีแล้ว — มีมาก่อนยูนิโค้ดเสียอีก แม้จะไม่เคยได้รับปุ่มเฉพาะบนแป้นพิมพ์มาตรฐานเหมือนที่ $ มีก็ตาม

ทำไมแป้นพิมพ์ของฉันไม่มีปุ่มเซนต์

แป้นพิมพ์เครื่องพิมพ์ดีดและคอมพิวเตอร์ถูกออกแบบมาโดยจำกัดจำนวนปุ่ม และ ¢ ก็แพ้ให้กับเครื่องหมายวรรคตอนที่ใช้บ่อยกว่า แม้การตั้งราคาแบบเซนต์ (99¢) จะเป็นเรื่องที่ใช้กันทุกวัน แต่ ¢ ก็ไม่เคยมีปุ่มเฉพาะบนแป้นพิมพ์มาตรฐานของสหรัฐฯ เหมือนที่ $ มี

พิมพ์ ¢ บน Mac กับ Windows ยังไง

Mac กด Option+4 Windows กด Alt ค้างแล้วพิมพ์ 0162 บนแป้นตัวเลข หรือพิมพ์ 00A2 แล้วกด Alt+X ใน Word แป้นพิมพ์มือถือส่วนใหญ่จะซ่อนไว้ในเมนูกดค้างที่ปุ่ม $

¢ เหมือนกับการเขียน "c" ต่อท้ายตัวเลขไหม

ความหมายไม่เป็นทางการเหมือนกัน (50c กับ 50¢) แต่ ¢ คือสัญลักษณ์สกุลเงินมาตรฐานที่ใช้ในสิ่งพิมพ์ การเงิน และงานจัดพิมพ์ ส่วนตัวอักษร c ธรรมดาเป็นแค่ทางลัดบนแป้นพิมพ์เวลาหา ¢ ไม่สะดวก

¢ ยังใช้อยู่ไหม หรือเลิกใช้ไปแล้ว

ยังเป็นมาตรฐานอยู่ในการตั้งราคาขายปลีก ใบเสร็จ และเอกสารทางการเงินของสหรัฐฯ และแคนาดา พบน้อยลงในบริบทดิจิทัลที่นิยมเขียนราคาแบบทศนิยม ($0.99) แทน แต่ก็ยังไม่ได้ถูกยกเลิกหรือแทนที่แต่อย่างใด

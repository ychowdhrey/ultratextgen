หน้าแรก › ชื่อผู้ใช้ กับ ชื่อที่แสดง

ชื่อผู้ใช้ หรือ ชื่อที่แสดง — ฟอนต์สวยๆ ใช้ตรงไหน?

วางชื่อสวยๆ ลงไปแล้วโดนปฏิเสธว่า “invalid characters” เลยคิดว่าแอปนี้ใช้ฟอนต์สวยๆ ไม่ได้ ความจริงใช้ได้ — แค่ใส่ผิดช่องเท่านั้นเอง

คำตอบสั้นๆ

Unicode สวยๆ ต้องใส่ใน ชื่อที่แสดง (display name) / นิกเนม / ไบโอ ไม่ใช่ @ชื่อผู้ใช้ (username/handle) เพราะ handle คือที่อยู่ที่คนใช้ค้นหาและแท็กคุณ แอปเกือบทุกตัวจึงจำกัดให้เป็น ASCII ธรรมดา — ตัวพิมพ์เล็ก ตัวเลข จุด และขีดล่าง — และปฏิเสธฟอนต์ที่วางเข้าไปด้วยข้อความ “invalid characters” ส่วนชื่อที่แสดงเป็นแค่ป้ายชื่อ จึงรองรับ Unicode สไตล์ต่างๆ ได้ ให้ใส่ความสวยงามในช่องชื่อที่แสดง แล้วปล่อยให้ handle เป็นตัวอักษรธรรมดาไว้

@ชื่อผู้ใช้ = ASCII ธรรมดา (ปฏิเสธฟอนต์สวย) ชื่อที่แสดง / ไบโอ = Unicode สไตล์ต่างๆ (ใช้ได้)
กฎง่ายๆ

สองช่อง สองกฎที่ต่างกันมาก

เกือบทุกโปรไฟล์มีช่องชื่อ 2 แบบ:

  • @ชื่อผู้ใช้ / handle — ไม่ซ้ำใคร ใช้เป็น URL และในการแท็ก (@) จำกัดเฉพาะตัวอักษร ตัวเลข . และ _ วางฟอนต์ลงไปจะเจอข้อความ “username ใช้ได้แค่ตัวอักษร ตัวเลข ขีดล่าง และจุดเท่านั้น”
  • ชื่อที่แสดง / นิกเนม / ไบโอ — เป็นป้ายชื่อให้คนอ่าน ไม่ใช่ที่อยู่ รองรับ Unicode สไตล์ต่างๆ อีโมจิ และการเว้นวรรค

ดังนั้นทางแก้ของ “invalid characters” เกือบทุกครั้งคือ ย้ายตัวอักษรสวยๆ ออกจาก handle ไปใส่ในชื่อที่แสดงแทน

แยกตามแพลตฟอร์ม

ฟอนต์สวยๆ ใส่ตรงไหนของแต่ละแพลตฟอร์ม

รูปแบบเหมือนกันแทบทุกที่ — จัดสไตล์ช่องด้านขวา ปล่อย handle ให้เป็นตัวธรรมดา:

  • Instagram / TikTok — handle เป็นตัวธรรมดา จัดสไตล์ที่ช่อง Name / Nickname และไบโอ
  • Discord — username เป็นตัวธรรมดา จัดสไตล์ที่ display name และนิกเนมในเซิร์ฟเวอร์
  • WhatsApp — จัดสไตล์ที่ชื่อโปรไฟล์และ About (ส่วน @username ใหม่ยังต้องเป็นตัวธรรมดา)
  • X / YouTube / Telegram — handle เป็นตัวธรรมดา จัดสไตล์ที่ display name / ชื่อช่อง / ชื่อจริง

ชื่อในเกมก็ใช้รูปแบบเดียวกัน — จัดสไตล์ที่ display name แล้วปล่อยแท็กให้เป็นตัวธรรมดา ดูกฎตัวอักษรของแต่ละเกมแบบละเอียดได้ที่ allowed characters in game usernames (หน้าภาษาอังกฤษ) และ ทำไมชื่อในเกมถึงโดนปฏิเสธ

ข้อยกเว้น

จุดที่ฟอนต์สวยๆ ใช้ไม่ได้จริงๆ

มีบางช่องที่ปฏิเสธตัวอักษรสไตล์ต่างๆ แม้จะเป็นชื่อที่แสดงก็ตาม:

  • Facebook — ช่องชื่อจริงบล็อกสัญลักษณ์ ตัวพิมพ์แปลกๆ และการผสมภาษาตามนโยบาย (ไบโอกับโพสต์ใช้ได้ปกติ)
  • Twitch — ชื่อที่แสดงแบบละติน เปลี่ยนได้แค่ตัวพิมพ์ใหญ่-เล็ก เปลี่ยนฟอนต์ไม่ได้
  • LinkedIn — ช่อง headline เลิกรับ Unicode สไตล์ต่างๆ แล้ว และชื่อที่จัดสไตล์อาจทำให้คุณหายไปจากการค้นหาของฝ่ายสรรหาบุคลากร

จัดสไตล์ช่องที่ถูกต้อง

สร้างชื่อในสไตล์ที่ใช้ได้กับชื่อที่แสดงและไบโอ แล้วคัดลอกไปวาง — เก็บ @handle ไว้เป็นตัวธรรมดา

คำถามที่พบบ่อย

เพราะวางลงในช่อง @ชื่อผู้ใช้ / handle ซึ่งรับได้แค่ตัวอักษร ตัวเลข จุด และขีดล่างเท่านั้น ให้ใส่ตัวอักษรจัดสไตล์ในชื่อที่แสดง นิกเนม หรือไบโอแทน ช่องเหล่านั้นรองรับ Unicode

ชื่อผู้ใช้ (handle) คือที่อยู่เฉพาะของคุณ ใช้ใน URL และการแท็ก (@) ถูกจำกัดให้เป็น ASCII ธรรมดา ส่วนชื่อที่แสดงคือป้ายชื่อที่แสดงเหนือโพสต์ของคุณ อ่านง่าย และรองรับ Unicode จัดสไตล์ อีโมจิ รวมถึงการเว้นวรรค

ไม่ได้ handle ของ Instagram และ TikTok จำกัดให้เป็นตัวพิมพ์เล็ก ตัวเลข จุด และขีดล่างเท่านั้น ให้จัดสไตล์ที่ช่อง Name / Nickname และไบโอแทน ช่องนั้นรองรับ Unicode สวยๆ

Facebook บล็อกสัญลักษณ์และรูปแบบตัวอักษรแปลกๆ ในช่องชื่อจริงตามนโยบาย Twitch ให้เปลี่ยนได้แค่ตัวพิมพ์ใหญ่-เล็กของชื่อแบบละติน และ LinkedIn เลิกรับ Unicode จัดสไตล์ในช่อง headline แล้ว ส่วนไบโอกับโพสต์บนแพลตฟอร์มเหล่านี้มักใช้ได้ตามปกติ

การค้นหาและการแท็ก (@) ทำงานผ่าน handle ซึ่งเป็นตัวธรรมดาอยู่แล้ว จึงไม่ได้รับผลกระทบ แต่ชื่อที่แสดงที่จัดสไตล์หนักมากอาจอ่านยากสำหรับโปรแกรมอ่านหน้าจอและการค้นหาชื่อ ถ้าอยากให้คนหาคุณเจอง่าย ควรเลือกสไตล์ที่ยังอ่านออก

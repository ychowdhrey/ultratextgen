Dirham Sign

The UAE Central Bank's new currency symbol, assigned U+20C3 and frozen for publication in Unicode 18.0 — more locked-in than this release's draft emoji, but still not typeable on any keyboard yet.

The dirham sign (⃃, U+20C3) is the United Arab Emirates Central Bank's new currency symbol, unveiled in March 2025 alongside a companion digital-dirham mark. It was submitted to the Unicode Consortium for encoding, approved, and published in the Unicode 18.0 public beta on May 27, 2026, alongside the Omani rial and Maldivian rufiyaa signs. As of this writing it carries "white" status in Unicode's own pipeline documentation — meaning it's frozen for publication, pending only ISO approval, which is actually a more locked-in state than this same release's draft emoji candidates (several of which still carry pending name-change flags). Unicode 18.0 itself is expected to publish as final in September 2026. Publication alone doesn't put it on a keyboard, though — no operating system, font, or input method currently ships native support, and the UAE Central Bank's own style guide recommendation (the number-6 key) is only a recommendation until device makers act on it. In the meantime, developers have already built real tooling around the confirmed codepoint: an open-source npm package, web font, and CSS/React/Vue/Angular/Svelte components (published as "dirham" on npm and GitHub) let you encode the correct character today via a temporary rendering layer, designed to be dropped the moment native OS support ships.

History & Context

Where the diameter sign comes from

The diameter sign (⌀) is a graphical symbol standardized by ISO 7000 for engineering drawings, machining specs, and manufacturing callouts. Convention places it immediately before the numeric value — ⌀12 reads as "twelve millimeter diameter," not "radius twelve." That ordering is a hard rule in geometric dimensioning and tolerancing (GD&T); a radius uses the plain letter R instead, so swapping the two changes what a part actually measures.

Because ⌀ sits in the Miscellaneous Technical block rather than any legacy 8-bit character set, older CAD software and typewriter-era documentation often couldn't produce it directly. The workaround that stuck was substituting the visually similar empty set symbol ∅ (U+2205) instead — technically wrong, since ∅ means "no elements" in mathematics, but common enough that it still turns up on manufacturing drawings today.
